1단계 : 성취기준 분해하기

성취기준을 선택하면 최소 문장 단위로 분해된 카드가 생성됩니다. 카드를 드래그하여 순서를 바꾸고 평가 방식을 체크하세요.

💡 이 분해는 정답이 아니라 예시입니다. 문장을 직접 고치거나, 지우거나(✕), ＋ 문장 추가로 늘려서 우리 수업에 맞게 다듬으세요. Enter 로 아래에 새 문장이 생깁니다.

3단계 : 수업 설계하기

학습 목표별 수업 과정안입니다. AI 로 생성하거나 직접 편집한 뒤 Markdown 으로 저장하세요.

4단계 : 학습 활동지 생성

차시별로 문항·루브릭을 AI 로 생성하고, 학생 배부용 / 교사용을 각각 인쇄(PDF)하거나 .hwp 로 받습니다.

5단계 : 학습 도움 자료 제작하기

학생이 직접 만져 보며 핵심 개념을 이해하는 시뮬레이터를 만듭니다. 파일 하나(HTML)로 받아 전자칠판·태블릿에서 인터넷 없이 바로 엽니다.
