에듀폼2 · 교내 서버판

학교 안 컴퓨터 한 대에서 운영합니다. 학생 자료가 학교 밖으로 나가지 않습니다.

서버로 쓸 PC에서 · 관리자 PowerShell
irm https://raw.githubusercontent.com/dadaschool/eduform2/main/install.ps1 -OutFile "$env:TEMP\install.ps1" powershell -ExecutionPolicy Bypass -File "$env:TEMP\install.ps1" -ServerIp 192.168.0.10
노란 글씨 192.168.0.10 를 이 서버 컴퓨터의 실제 IP로 바꾸세요.
교사·학생 브라우저가 이 주소로 직접 접속합니다. 틀리면 다른 기기에서 로그인이 안 됩니다.
이 컴퓨터의 IP 확인: PowerShell 에 ipconfig → "IPv4 주소".
⬇ install.ps1 직접 받기 설치 안내서 (손으로 하기) GitHub 저장소

📌무엇을 하나요?

에듀폼은 교사가 평가·과제·관찰기록·배지·쪽지·생활기록부 초안을 한 곳에서 다루는 앱입니다. 에듀폼2는 그것을 학교 안 컴퓨터에서 직접 돌리는 판입니다. 학생 정보가 외부 클라우드로 나가지 않고, 교내망에서만 접속됩니다.

클라우드로 쓰실 거면 이 페이지가 아니라 에듀폼(온라인판) 을 보세요.

🚀설치가 하는 일

위 명령 한 줄이 아래를 순서대로 처리합니다. 처음이면 20~30분 걸립니다.

  1. 사양·프로그램 확인 — 메모리, 디스크, 포트(3000·3001·5432)를 봅니다.
  2. Git · Node.js · PostgreSQL 설치 — 없으면 winget 으로 받습니다. 이미 있으면 건너뜁니다.
  3. PostgREST 내려받기 — 데이터 API. 공식 윈도우 실행 파일입니다.
  4. 소스 받기 · 키 생성 — 접속 키를 만들어 되읽어 대조합니다. AI 키 암호화용 AI_KEY_SECRET 도 이때 자동 생성됩니다.
  5. 표와 보안정책 만들기 — 데이터베이스를 세웁니다.
  6. 빌드 · 서비스 등록 · 방화벽 — 재부팅해도 자동으로 켜지게 하고, 서버 IP와 같은 대역(예: 192.168.x)의 학교 내부망만 열립니다.
  7. 응답 점검 — 화면·로그인·데이터 API가 뜨는지 확인합니다.
설치 중 두 번 물어봅니다 ① PostgreSQL 설치 때 정한 비밀번호   ② 첫 관리자 계정의 이메일·이름·비밀번호. 화면에 보이지 않고 파일에 남지 않습니다.
멈추면 그 자리에서 이유를 알려줍니다. -CheckOnly 를 붙이면 아무것도 바꾸지 않고 사양만 점검합니다.

🧰필요한 것

운영체제Windows 10 · 11 또는 Windows Server (모두 됩니다)
메모리4GB (Postgres·PostgREST 는 수십 MB 수준)
디스크C드라이브 여유 5GB + 자료
권한관리자 PowerShell (설치·방화벽 규칙에 필요)
포트3000 하나만 교내망에 엽니다. 3001·5432 는 이 컴퓨터 안에서만 씁니다
서버 PC수업일에 켜 두어야 다른 분이 접속합니다
인터넷설치 때 한 번만. 그 뒤로는 AI 기능만 바깥 인터넷을 씁니다
리눅스도 Docker 도 WSL 도 쓰지 않습니다. 전부 윈도우 프로그램이고 전부 무료입니다.

🔁온라인판과 무엇이 다른가요?

기능은 같습니다 — 평가·과제·관찰기록·배지·쪽지·생활기록부 초안, 여러 교사·관리자 운영까지. 다른 것은 어디서 돌아가느냐뿐입니다.

  • 학생 정보가 학교 안에 남습니다 — 이 컴퓨터의 데이터베이스에만 저장되고 외부 클라우드로 나가지 않습니다.
  • 교내망에서만 접속 — 학교 밖에서는 열리지 않습니다(사설 IP).
  • 바깥 인터넷은 AI 기능만 씁니다 — 평가 항목 추천·생활기록부 초안. 막혀 있으면 그 두 기능만 안 됩니다. AI는 교사가 [내 계정]에서 자기 API 키를 등록해 씁니다.
  • 쪽지 알림이 15초 간격 — 실시간 알림 서버는 윈도우 빌드가 없어 주기적으로 확인합니다.

✅설치가 끝나면

  1. 브라우저에서 http://<서버IP>:3000 을 엽니다. 로그인 화면이 뜨면 정상입니다.
  2. 설치 때 만든 관리자 계정으로 로그인 → 반·교사·학생을 등록합니다(명단 엑셀).
  3. 교사들에게 접속 주소를 알립니다. 교사·학생은 아무것도 설치하지 않고 주소만 누르면 됩니다.
  4. 점검이 필요하면 서버에서 npm run doctor.
자료는 이 컴퓨터 한 대에만 있습니다. 설치가 매일 백업 작업을 등록해 둡니다(비밀번호 한 줄만 채우면 동작). 만들어진 백업 폴더를 주 1회 학교 공용 폴더나 외부 디스크로 복사하세요. 같은 디스크에만 둔 백업은 디스크가 죽을 때 같이 죽습니다.
