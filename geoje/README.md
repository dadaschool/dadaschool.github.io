# geoje — 비노출 디렉터리

이 디렉터리의 페이지는 **루트 사이트(`dadaschool.github.io`)에서 보이지 않는다.**

- 루트의 목록·네비게이션·링크에 여기 있는 페이지를 추가하지 말 것.
- 노출이 필요하다고 판단되면 직접 반영하지 말고 **먼저 물어볼 것.**

전체 규칙은 저장소 루트의 [`CLAUDE.md`](../CLAUDE.md) 참고.

| 파일 | 용도 | 대상 |
