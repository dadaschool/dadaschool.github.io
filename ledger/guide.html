가계부 안내

혼자 쓰는 가계부 — 데이터는 내 휴대폰에만

가계부 열기

어떤 앱인가요

  • 수입 · 지출 · 저축을 적고, 예산에서 얼마 남았는지 · 하루에 얼마 쓸 수 있는지 보여 줘요.
  • 월세 · 통신비 같은 반복 항목, 신용카드 결제 예정액 · 할부, 목돈 마련 계산(예금 · 적금)이 들어 있어요.
  • 가계부를 여러 개 만들 수 있어요 (내 가계부 · 생활비 · 모임 회비 등 — 서로 따로).
  • 입력한 내역은 인터넷으로 나가지 않아요. 서버가 없고, 이 휴대폰 크롬 안에만 저장돼요.

휴대폰에 설치하기 (안드로이드 크롬)

  1. 크롬으로 이 주소의 가계부를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치.
  3. 홈 화면에 생긴 «가계부» 아이콘으로 엽니다. 인터넷이 없어도 열려요.
  4. 아이콘을 길게 누르면 «지출 입력» 바로가기가 있어요.

처음 할 일: 설정에서 한 달 시작일(월급날)을 정하고, 쓰는 카드를 등록하세요.

⚠ 데이터가 사라지는 경우

  • 크롬 «인터넷 사용 기록 삭제» 에서 쿠키 및 사이트 데이터를 지웠을 때
  • 휴대폰 설정에서 크롬의 저장 공간 · 데이터를 지웠거나 크롬을 다시 설치했을 때
  • 휴대폰을 바꿨을 때
  • 가계부 주소가 바뀌었을 때 (주소가 다르면 서로 다른 앱으로 취급돼요 — 백업 파일로 옮기세요)

그래서 백업 파일을 휴대폰 밖에도 한 부 두세요.

백업 · 옮기기

  • ⚙ 설정 → 백업 · 가져오기 → [💾 백업 파일 저장] — «다운로드» 폴더에 저장돼요.
  • [📤 공유로 백업] — 구글 드라이브 · 카카오톡 «나와의 채팅» · 메일로 바로 보내요.
  • 새 휴대폰(또는 새 주소)에서는 [📥 백업 파일 가져오기] 로 그대로 이어서 써요. 백업 파일 하나에 모든 가계부가 들어 있어요.
  • 마지막 백업 뒤 정한 날이 지나면 홈 아래에 알려 줘요 (기본 7일).
  • 엑셀로 보고 싶으면 [📊 CSV 내보내기].

잠금

⚙ 설정 → 잠금 에서 PIN 또는 지문 + PIN 을 고를 수 있어요. PIN 을 정할 때 보여 주는 12자리 복구 코드를 꼭 적어 두세요. 잠금은 화면을 가리는 것이지 데이터를 암호화하는 것은 아니에요.

업그레이드 — 내가 누를 때만 바뀌어요

  1. 새 판이 있으면 ⚙ 설정 아이콘에 빨간 점이 찍혀요 (하루 한 번 확인만 해요).
  2. ⚙ 설정 맨 아래 ⬆ 업그레이드 → [🔎 새 판이 있는지 확인] → [⬆ 지금 받기].
  3. 받기 전에 휴대폰 안에 자동 백업해요. 다 받으면 [🔄 새 판으로 다시 시작].
  4. 새 판이 이상하면 [↩ 이전 판으로 되돌리기]. 기록은 그대로예요.
