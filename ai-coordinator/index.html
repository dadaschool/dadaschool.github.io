📌어떤 프로그램인가요?

학교에 채용한 AI교육 코디네이터(디지털튜터)의 업무를 관리하는 프로그램입니다. 선생님이 작업을 요청하면 코디네이터가 처리하고, 정보부장님이 점검·서명하면 활동일지 · 출근기록부 · 결과보고서 및 정산서가 교육청 서식대로 자동으로 만들어집니다.

  • 선생님 — 수업 지원·자료 제작 등을 요청하고 진행 상황을 봅니다
  • 코디네이터 — 요청을 수락·조절하고, 그날의 활동과 출퇴근을 기록합니다
  • 정보부장 — 기록을 점검·서명하고, 예산 집행과 제출 서식을 관리합니다
주 15시간 미만 원칙을 프로그램이 지켜 줍니다 업무편람의 근로시간 규정(타 학교 근무시간 합산)을 넘기면 저장 자체가 되지 않습니다. 수행 제한 범위(단독 수업·평가·생활지도 등)도 접수되지 않습니다.

🚀설치하고 시작하기

  1. 위 [설치 파일 내려받기] 를 눌러 받은 파일을 더블클릭합니다.
    서버로 쓸 PC 한 대에만 설치하면 됩니다. (보통 정보부장 선생님 PC)
  2. 설치가 끝나면 브라우저가 저절로 열립니다.
    [관리자 코드 정하기] 칸에 쓰고 싶은 숫자 4~12자리를 넣고 [시작하기].
    미리 정해진 비밀번호가 없습니다. 지금 넣은 숫자가 코드가 되니 적어 두세요.
  3. 프로그램 폴더의 방화벽_허용.bat 을 마우스 오른쪽 클릭 → [관리자 권한으로 실행] 합니다.
    다른 선생님 PC에서 접속할 수 있게 하는 단계입니다. (처음 한 번만)
  4. [설정] 탭에서 ① 명단 엑셀 올리기 ② 학교명·계약정보·업무시간 ③ 예산 편성 을 넣습니다.
    명단 서식은 프로그램 안에서 내려받을 수 있습니다.
  5. 검은 창에 나온 접속 주소를 선생님들께 알립니다.
    폴더에 만들어진 선생님께_보낼_바로가기.url 파일을 보내시면 더 쉽습니다.
선생님들은 아무것도 설치하지 않습니다 주소만 누르면 됩니다. 휴대폰·태블릿에서도 됩니다. 무선에서 접속할 때는 컴퓨터 이름이 아니라 IP 주소를 쓰셔야 합니다.

🔒개인정보와 자료 보관

모든 자료는 설치한 그 PC의 data 폴더에만 저장됩니다. 인터넷이나 클라우드로 아무것도 보내지 않고, 학교 내부망에서만 접속됩니다.

  • 인증코드는 암호화(pbkdf2 12만 회)되어 저장되며 다시 볼 수 없습니다
  • 학생 개인정보는 저장하지 않습니다 (학급명만 받습니다)
  • [설정] → 자료 백업 에서 파일 하나로 백업하고, 새 PC에서 되돌릴 수 있습니다
다른 PC로 옮기실 때 옮기기 전에 [설정] → [자료 백업] → [백업 파일 내려받기] 로 .zip 을 받아 두시고, 새 PC에 설치한 뒤 [백업에서 되돌리기] 하시면 명단·기록·예산이 그대로 이어집니다.
