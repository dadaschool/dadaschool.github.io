무엇으로 돌아가나

  • 윈도우 프로그램만 씁니다. Postgres · PostgREST · Node.js — 리눅스도 Docker 도 필요 없습니다.
  • 전부 무료입니다. 라이선스 비용이 없습니다.
  • 상시 켜두는 컴퓨터 한 대로 충분합니다. 메모리 4GB 면 됩니다.

에듀폼과 무엇이 다른가

  • 기능은 같습니다. 평가 · 과제 · 관찰기록 · 배지 · 쪽지 · 생활기록부 초안.
  • 학생 정보가 학교 안에 남습니다. 외부 클라우드에 저장하지 않습니다.
  • 교내망에서만 접속합니다. 외부에서는 열리지 않습니다.
  • 여러 교사가 함께 씁니다. 전체 관리자가 교사 계정을 만들고 관리합니다.
  • AI 기능만 바깥 인터넷을 씁니다. 막혀 있으면 그 기능만 안 됩니다.
  • 쪽지 알림이 15초 간격입니다. 실시간 알림 서버는 윈도우 빌드가 없습니다.
