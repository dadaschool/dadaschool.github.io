# 스마트하우스, 선 없이 잇기

micro:bit 무선통신 수업용 웹앱입니다. **중등 영재반 정보** 5차시 프로젝트.

👉 **https://dadaschool.github.io/mb-bluetooth/**

## 무엇인가

micro:bit 공식 프로젝트 3개를 실습으로 하기 **전에**, 그 원리를 화면에서 먼저 겪게 하는 시뮬레이터입니다.
시뮬레이터 3개와 실습 3개가 1:1로 붙어 있습니다.

| 시뮬레이터 | 무엇을 알게 되나 | 이어지는 실습 |
|---|---|---|
| ① 명령이 누구에게 가는가 | 무선은 확성기다 — 그룹과 주소 | [그룹 텔레포트](https://microbit.org/ko/projects/make-it-code-it/group-teleporting-duck/) |
| ② 기기를 어떻게 찾는가 | 가까울수록 자주 뜬다 — 신호 세기와 송신 출력 | [보물찾기](https://microbit.org/ko/projects/make-it-code-it/treasure-hunt/) |
| ③ 가까이 가면 반응한다 | 비례 변환(map)과 임계값 | [근접 비콘](https://microbit.org/ko/projects/make-it-code-it/proximity-beacon/) |

## 개인정보

- 학년·반·학번·이름은 **PDF를 만드는 순간에만** 입력받아 **PDF 안(과 파일 이름)에만** 들어갑니다.
- 이 사이트는 학생 정보를 **서버로 보내지 않고 기기에도 저장하지 않습니다.**
- 센서 조사는 **모둠 번호만** 받습니다. 이름을 받지 않습니다.

## 정답은 어떻게 잠겨 있나

GitHub Pages 에는 서버가 없어서, 코드를 검사만 하는 잠금은 소스를 보면 뚫립니다.
그래서 **정답과 해설을 AES-GCM 암호문으로만** 넣어 두었습니다(`js/locked.js`).
코드를 모르면 소스를 아무리 봐도 읽을 수 없습니다.

그 대신 **제출 시점에는 채점이 되지 않습니다.** 수업 중에 선생님이 정답 코드를 알려 주면
그때 채점 결과와 해설이 열립니다. 반 전체가 동시에 확인하는 방식입니다.

## 만든 것

외부 라이브러리 **0개**. 캔버스·Web Crypto 등 브라우저에 이미 있는 것만 씁니다.
빌드 과정이 없어 이 폴더를 그대로 올리면 동작하고, `index.html` 을 더블클릭해도 열립니다.
