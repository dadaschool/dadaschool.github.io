나만의 학습지 스킬 만들기

«우리 학교 학습지 양식»을 스킬로 만들어, 학습지를 부탁할 때마다 양식을 설명하지 않아도 같은 모양의 Word 학습지가 나오게 합니다. 만든 스킬은 zip 하나로 동료와 나눕니다.

도구 · 코워크 (데스크톱 앱) + claude.ai 계정 핵심 기법 · 클로드가 묻게 하기(설계 인터뷰), 결과 말고 스킬을 고치기
과업
목표
학교에서 쓰는 학습지 양식을 스킬로 만들고, 양식을 한 줄도 말하지 않은 요청으로 학습지를 만들어 시험한다 (예시: 중학교 1학년 국어 — «우리 학교 학습지 양식» 스킬로 만든 «품사의 종류» 학습지)
준비물
클로드연수 안에 만든 빈 12차시 폴더, (있으면) 학교에서 쓰는 학습지 한 장(개인정보 없는 것)
결과물
① school-worksheet 스킬 폴더 — SKILL.md 와 서식 견본 template.docx ② 나눠 줄 school-worksheet.zip ③ 스킬로 만든 학습지·정답지 docx
주의
견본 학습지에 학생 이름·사진이 없게 · 학교 이름을 넣은 스킬은 학교 밖으로 나눌 때 한 번 더 확인

1차시에서 정리 기준을 정리규칙.md 로 남겼고, 11차시에서 남이 만든 스킬을 설치해 썼습니다. 이번에는 내가 자주 하는 일을 스킬로 만듭니다. 학습지를 만들 때마다 «머리말에 학년·반·번호·이름 칸, 위에 학습 목표 상자, 끝에 오늘 배운 점…»을 설명하고 있다면 스킬로 만들 때입니다. 핵심은 둘입니다. 양식을 혼자 쓰지 말고 클로드가 묻게 하는 것(설계 인터뷰), 그리고 결과가 틀리면 학습지가 아니라 스킬을 고치는 것입니다.

# 우리 학교 학습지 양식

학습지·활동지를 Word(docx)로 만들 때 이 양식을 따른다. 같은 폴더의 `template.docx` 가 견본이다. 견본을 열어 서식을 그대로 쓰고 내용만 채운다.

## 만들기 전에

- 교과, 학년, 단원(주제), 학습 목표, 문항 수를 확인한다. 빠진 것이 있으면 만들기 전에 묻는다.
- 교과 내용은 교사가 준 자료를 먼저 쓴다. 사실과 계산은 다시 확인하고, 확실하지 않은 것은 교사에게 «확인 필요»로 알린다.
- 파일 이름: `교과_학년_주제_학습지.docx` (예: `국어_1학년_품사_학습지.docx`)

## 0. 쪽 설정

- A4 세로, 여백 위·아래 15mm, 왼쪽·오른쪽 18mm
- 글꼴: 맑은 고딕 (영어·숫자도 같은 글꼴), 줄 간격 1.3

## 1. 머리말 (첫 쪽 맨 위)

- 첫 줄: 왼쪽에 학교 이름 «○○중학교», 오른쪽에 «교과 · 학년» (10pt, 회색)
- 제목: 16pt 굵게, 가운데. 형식 «[단원 이름] 제목»
- 그 아래 1행 4칸 표: «   학년» | «   반» | «   번» | «이름:» — 이름 칸을 가장 넓게

## 2. 학습 목표 상자

- 머리말 아래에 테두리 있는 1칸 표, 옅은 파랑 바탕(#EEF4FB)
- 첫머리에 굵게 «학습 목표», 목표는 «~할 수 있다.»로 끝나는 문장 1~2개, 12pt

## 3. 문항

- 묶음 제목: «Ⅰ. 개념 확인», «Ⅱ. 문제 풀기»처럼 로마 숫자, 13pt 굵게
- 문항 번호: «1.», «2.» … **처음부터 끝까지 이어서** 매긴다. 묶음이 바뀌어도 1부터 다시 시작하지 않는다.
- 하위 문항: «(1)», «(2)» / 보기: ①②③④⑤
- 본문 11pt, 문항마다 답을 쓸 밑줄이나 빈칸을 둔다.

## 4. 오늘 배운 점 (마지막)

- 마지막 문항 다음에 테두리 있는 상자, 첫 줄 굵게 «오늘 배운 점»
- 그 아래 쓸 줄 3줄
- 상자 아래 오른쪽에 9pt로 «스스로 평가: ☆☆☆☆☆»

## 5. 바닥글

- 쪽 번호를 가운데에 «- 1 -» 형식으로

## 6. 정답지

- 정답과 풀이는 `…_학습지_정답.docx` 로 따로 만든다. 학생용 파일에는 정답을 넣지 않는다.

## 하지 말 것

- 학생 이름·사진 같은 개인정보를 넣지 않는다.
- 교과서 지문·그림을 그대로 옮기지 않는다. 그림이 필요하면 단순한 그림을 직접 그리거나 «[그림 자리]»로 비워 둔다.

- 위 0~6을 하나씩 점검한 목록을 교사에게 보여 준다. 지키지 못한 것이 있으면 까닭을 쓴다.

SKILL.md·template.docx 는 프롬프트 1의 인터뷰에서 «답할 때 참고»처럼 답했다고 보고 연수자료를 만들면서 직접 작성했고, 학습지·정답지 docx 는 그 규칙대로 만든 뒤 화면에 띄워 찍었습니다(코워크 화면에서 받은 결과가 아닙니다). 학습지 내용(9품사의 기능별 분류, «하나»는 수사·«한»은 관형사, 형용사는 ②④, «-는다»로 동사·형용사 구별, «아주»는 «빨리»를·«빨리»는 «달린다»를 꾸밈)은 학교 문법 기준으로 확인했습니다. 실제 코워크 결과는 글꼴·간격·문항이 조금씩 다를 수 있으니 규칙과 대조해 보세요.

4 검증 포인트

① 양식 없이도 양식대로 — 프롬프트 3처럼 양식을 말하지 않은 요청에서 머리말·학습 목표 상자·오늘 배운 점이 모두 나왔는지 봅니다. 말해야만 나온다면 description 이나 규칙이 흐린 것입니다.
② 규칙 하나하나 — 문항 번호를 이어 매겼는지, 글꼴 크기·여백·쪽 번호가 맞는지 Word 에서 확인합니다(글자를 눌러 크기 확인, 레이아웃 → 여백).
③ 정답 분리 — 학생용 파일에 정답이 들어가지 않았는지, 정답지의 답이 맞는지 교사가 풀어 봅니다.
④ 교과 내용 — 스킬은 양식을 맞춰 줄 뿐 내용의 정확성은 보장하지 않습니다. 문항과 정답을 교사가 검토합니다(11차시 검수 스킬을 함께 써도 좋습니다).
⑤ SKILL.md 가 읽히는지 — 동료가 읽어도 무엇을 하는 스킬인지 알 수 있는지, 500줄을 넘지 않는지 봅니다. 길어지면 자세한 내용을 다른 파일로 나눕니다.
⑥ 나누기 전에 — zip 안에 학생 자료나 개인정보가 든 견본이 섞이지 않았는지, zip 을 열면 맨 위에 school-worksheet 폴더가 있는지 봅니다.

핵심 원리
스킬은 «매번 하던 설명»을 파일로 굳힌 것입니다. 양식은 혼자 쓰지 말고 클로드가 묻게 해서 빠짐없이 정하고, 정리 표를 그대로 SKILL.md 로 만듭니다. 시험할 때는 양식을 말하지 않고 부탁해 스킬만으로 양식이 지켜지는지 보고, 틀리면 결과물이 아니라 스킬을 고칩니다. 그렇게 다듬은 스킬은 zip 하나로 동료와 나눌 수 있습니다.
문제 해결
· 스킬을 쓰지 않고 평범한 학습지가 나온다 — Customize → Skills 에서 켜져 있는지 봅니다. description 에 «학습지», «활동지», «docx» 처럼 실제로 부탁할 때 쓰는 낱말이 들어 있는지 보고, 급하면 «school-worksheet 스킬로»를 붙입니다.
· zip 을 올리면 오류가 난다 — zip 맨 위에 school-worksheet 폴더가 있는지, 폴더 이름과 name 이 같은지, 맨 위 YAML 에 name·description 말고 다른 항목이 없는지, description 이 200자를 넘지 않는지 봅니다.
· template.docx 서식이 무시된다 — SKILL.md 에 «같은 폴더의 template.docx 를 열어 서식을 그대로 쓰고 내용만 채운다»는 문장이 있는지 봅니다.
· 한글(HWPX) 학습지로 받고 싶다 — 한글 파일은 4차시 방법을 함께 씁니다. 이 차시의 스킬은 Word(docx) 기준입니다.
· 스킬을 더 체계적으로 다듬고 싶다 — Code 탭에서는 Anthropic 공식 마켓플레이스의 skill-creator 플러그인으로 시험 문항을 만들어 스킬이 있을 때와 없을 때를 비교하며 다듬을 수 있습니다(11차시 (다) 플러그인 설치 방법).
