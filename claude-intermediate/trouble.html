문제 해결

연수 중에 자주 막히는 곳을 모았습니다. 차시마다 맨 아래 «문제 해결»에 그 차시만의 내용이 더 있습니다.

먼저 · 화면에 뜬 오류 문구를 그대로 확인 막히면 · 오류 문구를 클로드에게 붙여넣고 물어보기
가장 빠른 방법
오류가 뜨면 그 문구를 복사해 클로드에게 «이 오류가 왜 났고 어떻게 고치나요? 저는 윈도우(또는 맥)를 씁니다»라고 묻습니다. Code 탭이라면 클로드가 직접 원인을 찾아 고칠 수도 있습니다. 단, 고치기 전에 무엇을 할지 먼저 설명해 달라고 합니다.
말로 설명하기 어려우면 화면을 보여 줍니다. 윈도우 ⊞ Win+Shift+S(맥 ⌘+Shift+4)로 문제가 보이는 부분을 캡처하고, 캡처 도구의 펜으로 문제 부분에 동그라미를 친 뒤 메시지 상자에 붙여 넣어 «빨간 동그라미 부분이 왜 이렇게 되나요?»라고 묻습니다. 학생 이름·개인정보가 화면에 보이면 가린 뒤 보냅니다.

1 앱 · 로그인 · Code 탭

이럴 때이렇게
Code 탭을 누르면 업그레이드 안내가 뜬다유료 플랜이 아닌 계정입니다. 플랜별로 되는 것을 봅니다.
온라인 로그인 안내가 뜬다로그인을 마친 뒤 앱을 다시 시작합니다.
Code 탭에서 403 오류로그인(인증) 문제입니다. Claude Code 문서의 인증 오류 해결을 봅니다.
환경 목록의 내 컴퓨터 항목이 회색, «Disabled by your organization»기관 관리자가 막은 것입니다. 관리자에게 문의하거나 개인 계정을 씁니다.
프롬프트 상자 아래에 환경 단추가 없다앱이 예전 배치입니다. 폴더를 고르는 단추에서 바로 차시 폴더를 고릅니다. 앱을 최신판으로 업데이트해도 됩니다.
앱 안 브라우저 창이 열리지 않는다파일 탐색기(맥은 Finder)에서 HTML 파일을 더블클릭해 크롬·엣지로 엽니다.

2 코워크

이럴 때이렇게
폴더를 연결하는 단추가 없다웹(claude.ai)이 아니라 데스크톱 앱인지 확인합니다. 내 컴퓨터 폴더는 데스크톱 앱에서만 연결합니다.
내 파일 작업이 중간에 멈췄다내 컴퓨터의 파일을 다루는 동안에는 데스크톱 앱이 켜져 있어야 합니다. 노트북 덮개를 닫거나 앱을 끄지 않습니다.
메시지 상자에 Chat · Cowork 단추가 있다예전 화면입니다. 코워크 차시에서는 Cowork 를 고른 뒤 요청합니다. 연수 전 점검 3번.
파일 이름의 한글이 깨졌다예시 압축 파일을 반디집 같은 압축 프로그램으로 다시 풉니다.
결과가 마음에 들지 않는다기록 파일(정리기록 등)을 보여 주며 되돌려 달라고 하거나, 시작 전에 만든 복사본으로 바꿉니다.

3 한글 파일

이럴 때이렇게
클로드가 hwp 파일을 읽지 못한다옛 형식 .hwp 는 읽지 못할 수 있습니다. 한글에서 파일 → 다른 이름으로 저장으로 PDF(표·모양까지 볼 때)나 HWPX 로 바꿔 넣습니다. 급하면 전체 선택·복사해 붙여 넣습니다(표 모양은 깨질 수 있음). 자주 다루면 부록 · 한글 MCP(옛 .hwp 는 글 읽기만, 표·고치기는 HWPX 사본으로).
«바꾼 곳 0개», «찾지 못함»한글 문서 속 문구가 글꼴·색이 바뀐 곳에서 여러 조각으로 나뉘어 있을 수 있습니다. 더 짧은 낱말로 다시 부탁하거나 한글에서 직접 고칩니다.
고친 뒤 원본이 비었거나 깨졌다미리 둔 사본으로 되돌리고, «원본은 그대로 두고 새 이름으로 저장»을 넣어 다시 부탁합니다.
클로드가 만든 hwpx 가 한글에서 깨져 보인다한글을 최신판으로 업데이트한 뒤 다시 엽니다. 그래도 깨지면 워드(docx)로 만들어 한글에서 HWPX 로 저장합니다(4차시 (가) 길).

4 명령줄 설치 (5차시 «선택»)

이럴 때이렇게
설치는 끝났는데 claude 를 찾을 수 없다고 한다
('claude' is not recognized…, command not found: claude)		터미널 창을 닫고 새로 열어 다시 해 봅니다. 그래도 안 되면 PATH 설정 문제입니다. 공식 문서의 Verify your PATH를 따릅니다.
'irm' is not recognizedCMD(명령 프롬프트)에서 PowerShell 명령을 넣은 것입니다. 시작 메뉴에서 PowerShell 을 열어 다시 넣거나, CMD 용 설치 명령을 씁니다.
The token '&&' is not a valid statement separatorPowerShell 에서 CMD 용 명령을 넣은 것입니다. PowerShell 용 명령 irm https://claude.ai/install.ps1 | iex 를 씁니다.
설치 명령이 HTML 오류(<!DOCTYPE html>)를 낸다설치 파일 대신 다른 웹페이지를 받은 것입니다. 학교망의 차단·보안 프로그램 때문일 수 있으니 다른 네트워크(휴대폰 테더링 등)에서 해 보거나 정보 담당 선생님께 문의합니다.
TLS·SSL 연결 오류보안 연결이 막힌 것입니다. 학교 보안 프로그램·인증서 문제일 수 있어 정보 담당 선생님께 문의하고, 공식 문서의 TLS or SSL connection errors를 봅니다.
윈도우에서 claude 를 치면 데스크톱 앱이 열린다옛 데스크톱 앱이 명령을 가로챈 것입니다. 데스크톱 앱을 최신판으로 업데이트합니다.

출처: Claude Code 문서 Troubleshoot installation and login · Advanced setup (2026-11-11 확인)

5 웹페이지 · 인터넷에 올리기

이럴 때이렇게
교실 PC에서 그림·글꼴이 안 나온다인터넷에서 불러오는 파일을 쓴 것입니다. «외부 파일 없이 한 파일로 다시 만들어 주세요»라고 요청합니다.
한글이 이상한 글자로 보인다«파일을 UTF-8 로 저장하고 HTML 맨 위에 charset 을 넣어 주세요»라고 요청합니다.
GitHub Pages 주소가 404설정 뒤 반영까지 몇 분 걸릴 수 있습니다. 첫 화면 파일 이름이 index.html 인지, 주소의 저장소 이름 대소문자가 맞는지 봅니다. 8차시.

6 영상 · 소리

이럴 때이렇게
«node» 나 «npm» 을 찾을 수 없다고 한다Node.js 가 없는 것입니다. nodejs.org 에서 LTS 판을 설치하고 앱을 다시 시작합니다. 학교 PC는 설치가 막혀 있을 수 있습니다.
«ffmpeg» 를 찾을 수 없다고 한다클로드에게 «내 컴퓨터에 ffmpeg 를 설치하는 방법을 안내해 주세요»라고 묻고, 설치 명령을 실행하기 전에 무엇을 하는지 확인합니다.
만든 영상에 소리가 없다«소리 트랙이 들어갔는지 확인하고, 없으면 넣어 주세요»라고 요청합니다.
한국어 음성이 영어처럼 읽힌다컴퓨터에 한국어 음성이 깔려 있지 않은 것입니다. 17차시의 확인 방법을 봅니다.

7 캡처 올리기 (강사용)

이럴 때이렇게
«토큰이 틀렸거나 만료됐습니다»GitHub 에서 토큰을 새로 만들어 다시 넣습니다. 캡처 올리기 2번.
«토큰에 이 저장소의 Contents 쓰기 권한이 없습니다»토큰을 만들 때 저장소를 고르고 Contents 를 Read and write 로 했는지 확인합니다.
올렸는데 다른 사람에게 안 보인다1~2분 기다립니다. 계속 그대로면 Cloudflare(점검 사이트) 빌드가 멈췄는지 확인합니다.
