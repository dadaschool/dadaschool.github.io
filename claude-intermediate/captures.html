캡처 올리기

앱 화면 캡처는 강사가 이 연수자료에서 직접 올립니다. 연수생에게는 올린 그림만 보이고, «캡처 넣을 곳» 상자와 올리기 단추는 보이지 않습니다.

필요한 것 · GitHub 토큰 (처음 한 번) 반영 · 올리고 1~2분 뒤 모두에게

1 어떻게 동작하나

① 편집 모드
주소 끝에 ?edit
→
② 토큰
처음 한 번 붙여넣기
→
③ 올리기
붙여넣고 빨간 상자·번호 표시
→
④ 저장
그림이 저장소에 바로 커밋됨
→
⑤ 반영
1~2분 뒤 모두에게 보임

따로 서버를 두지 않고, 그림과 그림 목록(captures/captures.json)을 이 연수자료가 들어 있는 GitHub 저장소에 직접 넣습니다. 그래서 저장소에 쓸 권한이 있는 토큰을 가진 사람만 올릴 수 있고, 나머지 사람은 올라간 그림만 봅니다.

2 GitHub 토큰 만들기 (처음 한 번)

  1. github.com 에 로그인하고 오른쪽 위 프로필 사진 → Settings → 왼쪽 맨 아래 Developer settings 로 갑니다.
  2. Personal access tokens → Fine-grained tokens → Generate new token 을 누릅니다.
  3. 이름(예: 연수자료 캡처)을 쓰고, 만료 기간을 고릅니다. 연수 기간에 맞춰 짧게 둘수록 안전합니다.
  4. Resource owner 는 dadaschool 를 고릅니다.
  5. Repository access 에서 Only select repositories 를 고르고 geoje 를 고릅니다. 메인 사이트로 옮긴 뒤에는 dadaschool.github.io 도 더합니다.
  6. Permissions 의 저장소 권한에서 Contents 를 Read and write 로 바꿉니다. 다른 권한은 건드리지 않습니다.
  7. Generate token 을 누르고, 나온 토큰을 바로 복사해 둡니다. 토큰은 이때 한 번만 보입니다.

화면 문구는 GitHub 화면을 따릅니다. 출처: GitHub Docs Managing your personal access tokens

3 편집 모드 켜기

  1. 아무 쪽이나 주소 끝에 ?edit 를 붙여 엽니다. 아래 단추를 눌러도 됩니다.
  2. 화면 아래에 검은 막대가 나오면 토큰을 붙여넣고 토큰 저장을 누릅니다. 토큰 연결됨 ✓ 이 보이면 준비가 끝났습니다.
  3. 한 번 켜면 이 브라우저에서는 다른 쪽으로 옮겨도 편집 모드가 계속 켜져 있습니다. 끌 때는 막대의 편집 끝내기를 누릅니다.

이 브라우저에서 편집 모드 켜고 «연수 전 점검»으로 →

4 캡처 올리기

  1. 편집 모드에서는 쪽마다 노란 «캡처 넣을 곳» 상자가 보입니다. 상자에 적힌 대로 화면을 캡처합니다.
    윈도우 ⊞ Win+Shift+S · 맥 ⌘+Shift+4
  2. 상자의 캡처 올리기를 누르고, 열린 창에서 Ctrl+V(맥 ⌘+V)로 붙여넣습니다. 파일을 끌어다 놓거나 파일 고르기로 골라도 됩니다.
  3. □ 빨간 상자를 고른 채 그림 위를 끌면 빨간 상자가, ① 번호를 고르고 누르면 ①②③ 번호가 찍힙니다. 잘못 그렸으면 되돌리기.
  4. 그림 아래 설명을 확인합니다. 기본 문장이 들어 있으니 필요하면 고칩니다. 이 글은 그림을 못 보는 사람에게 읽어 주는 글로도 쓰입니다.
  5. 올리기를 누릅니다. 내 화면에는 바로 그림이 나오고, 다른 사람에게는 1~2분 뒤에 보입니다.

올린 그림은 상자의 그림 바꾸기로 바꾸거나 그림 지우기로 지웁니다. 그림은 너비 1600픽셀 이하로 줄여 저장합니다.

5 주의

공용 PC에서는 토큰을 넣지 않습니다. 토큰은 이 브라우저에만 저장됩니다. 다 쓰면 편집 끝내기에서 토큰도 지웁니다.
토큰이 새어 나갔다면 GitHub의 Fine-grained tokens 화면에서 그 토큰을 바로 지웁니다(Delete).
캡처에 학생 이름·연락처, 다른 사람의 대화가 보이지 않게 찍습니다. 빨간 상자는 가리는 도구가 아닙니다.
올릴 때마다 저장소에 커밋이 하나씩 생깁니다(«claude-intermediate: 캡처 P-1 올림»).
메인 사이트로 옮긴 뒤 거기서 올리면 공개 저장소에 바로 들어가 곧바로 공개됩니다.
반영이 안 될 때 — 점검 사이트는 Cloudflare 가 새 판을 만들어야 보입니다. 몇 분이 지나도 그대로면 Cloudflare 대시보드에서 빌드가 멈췄는지 봅니다. 올린 사람 화면에서 그림이 사라졌다면 새로고침 전에 반영이 끝나지 않은 것이니 잠시 뒤 다시 엽니다.
