연수 전 점검

첫 차시 전에 구독·데스크톱 앱·실습 폴더를 준비합니다. 학교 PC에서 막히는 부분도 여기서 미리 확인합니다.

준비물 · 유료 플랜 클로드 계정, 윈도우 또는 맥 컴퓨터 끝나면 · 체크리스트 6개 모두 표시

1 구독 플랜 확인

이 연수에서 쓰는 코워크와 클로드 코드는 유료 플랜 기능입니다. 무료 계정으로는 1차시부터 실습할 수 없습니다. claude.ai에 로그인해 설정에서 지금 요금제를 확인합니다.

2 데스크톱 앱 설치

웹(claude.ai)에서도 코워크를 쓸 수 있지만, 내 컴퓨터의 폴더를 다루는 차시와 Code 탭 차시는 데스크톱 앱이 있어야 합니다. 이 연수는 모두 데스크톱 앱으로 진행합니다.

  1. claude.com/download 에서 내 컴퓨터에 맞는 설치 파일을 받습니다.
    윈도우는 보통 x64용, 윈도우 ARM 노트북은 ARM64용입니다. 맥은 인텔·애플 실리콘 공용 파일 하나입니다.
  2. 받은 설치 파일을 실행해 설치합니다.
  3. 윈도우는 시작 메뉴, 맥은 응용 프로그램 폴더에서 Claude 를 열고 클로드 계정으로 로그인합니다.
  4. 왼쪽 사이드바 맨 위의 탭을 봅니다. 아이콘만 보이면 마우스를 올려 이름을 확인합니다. Code 탭을 눌렀을 때 업그레이드 안내가 뜨면 유료 플랜 계정이 아닙니다.

데스크톱 앱에 로그인한 첫 화면.
  • 빨간 상자: 사이드바 맨 위 탭 줄, 그중 Code 탭

Code 탭은 따로 설치하지 않습니다. 데스크톱 앱 안에 클로드 코드가 들어 있어서 Node.js 나 명령줄 프로그램을 깔지 않아도 Code 탭을 쓸 수 있습니다. 명령줄(터미널) 설치는 5차시에서 원하는 분만 합니다.

3 내 화면은 새 화면? 예전 화면?

2026년 10월 무렵부터 채팅과 코워크가 한 대화로 합쳐진 새 화면이 계정마다 차례로 적용되고 있습니다. 같은 플랜이어도 바뀌는 시점이 다르고, 한 번 바뀌면 예전 화면으로 돌아갈 수 없습니다. 이 연수자료는 두 화면을 모두 안내합니다.

새 화면
  • 메시지 상자에 모드를 고르는 단추가 없습니다.
  • 요청만 하면 클로드가 대화로 답할지, 작업(코워크)으로 처리할지 스스로 고릅니다.
예전 화면
  • 메시지 상자에 Chat · Cowork 를 고르는 단추가 있습니다.
  • 코워크 차시에서는 Cowork 를 고른 뒤 요청합니다.

4 학교 PC 점검

개인 노트북이면 이 단계는 건너뛰어도 됩니다. 학교 PC는 연수 하루 전에 한 번 열어 보는 것이 가장 확실합니다.

점검확인 방법안 될 때
프로그램 설치설치 파일이 실행되는지학교 PC는 설치가 막혀 있을 수 있습니다. 정보 담당 선생님께 설치를 부탁하거나 개인 노트북을 씁니다.
클로드 접속claude.ai 에 로그인되는지학교 인터넷에서 막혀 있는지 정보 담당 선생님께 문의합니다.
저장 유지재부팅해도 바탕화면 파일이 남는지재부팅하면 초기화되는 복원 프로그램이 깔린 PC는 결과물이 사라집니다. 차시가 끝날 때마다 USB나 클라우드에 옮깁니다.
기관 계정 제한Code 탭의 환경 목록에서 내 컴퓨터 항목이 회색이고 «Disabled by your organization» 이 뜨는지기관 관리자가 막은 것입니다. 관리자에게 문의하거나 개인 계정을 씁니다.
화면 배치클로드 앱과 이 연수자료를 나란히 띄울 수 있는지창을 반씩 나누거나(윈도우 ⊞ Win+←/→) 연수자료를 휴대폰으로 엽니다.

5 실습 폴더와 예시 파일

  1. 문서 폴더(또는 바탕화면)에 클로드연수 폴더를 만듭니다. 이 연수의 모든 결과물은 이 안에만 둡니다.
  2. 1차시 예시 파일 l01-class-files.zip 을 받아 클로드연수 안에 압축을 풉니다. 1차시 폴더가 생깁니다.

예시 파일은 모두 연수용으로 지어낸 가상 자료입니다. 압축을 풀었을 때 파일 이름의 한글이 깨지면 반디집 같은 압축 프로그램으로 다시 풉니다.

학생 개인정보가 든 파일은 실습 폴더에 넣지 않습니다. 코워크가 연 파일은 Anthropic 서버에서 처리됩니다. 자세한 것은 안전하게 쓰기를 봅니다.

6 연수 전 체크리스트

  • 유료 플랜 계정으로 로그인했다
  • 데스크톱 앱을 설치하고 Code 탭을 눌러 봤다
  • 내 화면이 새 화면 인지 예전 화면 인지 확인했다
  • 클로드연수 폴더를 만들었다
  • 1차시 예시 파일의 압축을 풀어 두었다
  • 학생 개인정보가 든 파일은 실습 폴더에 없다
