## 목표
중학교 3학년 학생이 a, p, q 값을 슬라이더로 바꾸며 y = a(x − p)² + q 그래프의 모양과 위치가 어떻게 바뀌는지 스스로 찾아보는 웹 도구 한 개.

## 대상과 조건
- 대상: 중학교 3학년 학생 (수업 중 교실 TV 시연 + 학생 태블릿)
- 기한: 다음 주 수업 전
- 환경과 도구: 학교 PC 크롬·엣지, 학생 태블릿 브라우저
- 꼭 지킬 것: 학생 정보를 저장하지 않기, 태블릿 세로 화면에서도 슬라이더를 손가락으로 움직일 수 있게

## 정한 방향
슬라이더 3개(a, p, q)와 좌표평면 하나로 된 "한 화면 탐구 도구"를 고름. 기준 그래프 y = x²를 옅은 선으로 함께 보여 주어 평행이동을 눈으로 비교하게 한다. 문제 풀이형 퀴즈(검토했지만 고르지 않음)는 다음에 따로 만든다.

## 하지 않을 것
- 학생 답 저장·점수 기록
- y = ax² + bx + c 일반형 입력 (이번 범위는 표준형만)
- 로그인, 인터넷에 올리기

## 단계별 계획
- [ ] **1단계. 좌표평면과 기준 그래프**
  - 할 일: x, y 모두 −10~10인 좌표평면(눈금 1)과 y = x² 그래프를 그린다.
  - 완료 확인: 브라우저에서 열었을 때 (0, 0), (1, 1), (2, 4), (−2, 4)를 지나는 포물선이 보인다. (선생님 확인: 교실 TV에서 눈금 숫자가 읽힌다)
- [ ] **2단계. a, p, q 슬라이더**
  - 할 일: a(−3~3, 0.5 간격, 0 제외), p(−5~5), q(−5~5) 슬라이더와 현재 식 표시를 넣는다.
  - 완료 확인: a=2, p=1, q=−3이면 식이 y = 2(x − 1)² − 3으로 보이고 그래프가 (1, −3)을 꼭짓점으로 하고 아래로 볼록하다(a > 0).
- [ ] **3단계. 꼭짓점과 축 표시**
  - 할 일: 꼭짓점 좌표를 점과 글자로, 축의 방정식 x = p를 점선으로 보여 준다.
  - 완료 확인: p=−2, q=4일 때 꼭짓점이 (−2, 4), 점선이 x = −2에 있다.
- [ ] **4단계. 탐구 질문 3개**
  - 할 일: 화면 아래에 질문 3개(a의 부호와 볼록한 방향, |a|와 폭, p·q와 평행이동)와 «답 보기» 단추를 넣는다.
  - 완료 확인: 답 보기를 누르기 전에는 답이 보이지 않는다. (선생님 확인: 질문 표현이 교과서와 맞다)
- [ ] **5단계. 태블릿 점검과 마무리**
  - 할 일: 세로 화면 배치를 다듬고, 글자 크기를 키운다.
  - 완료 확인: 폭 390px 화면에서 가로 스크롤이 없다. (선생님 확인: 실제 태블릿에서 슬라이더가 잘 움직인다)

## 전체 완료 기준
- 학생이 설명 없이도 슬라이더를 움직여 a, p, q의 역할을 말할 수 있다.
- 식, 꼭짓점, 축이 언제나 서로 맞게 바뀐다.
