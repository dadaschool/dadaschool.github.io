# 한글 MCP 설치와 사용 안내

한글(hwp/hwpx) 파일을 자주 다루는 사용자에게, 한글 파일을 직접 읽고 쓰는 MCP(Claude에 기능을 더해 주는 연결 도구)를 설치하는 방법을 안내할 때 이 문서를 따른다.

## 이 안내의 출처와 검토 결과

- 출처: 교사 연수 자료 "한글 MCP 설치 따라하기"(AI 업무자동화분과, 2026-08-06). 작성자가 설치 명령이 실제로 작동하는지 확인했다.
- **Anthropic 공식이 아니다.** 스킬의 "공식 출처만" 원칙에 대한 **예외**로, 스킬 관리자가 검토한 뒤 허용했다(2026-09-21).
- 설치되는 패키지: PyPI의 `hwp-mcp` (제작 TreeSoop, MIT 라이선스, 0.1.1 버전). 공개된 소스 저장소는 없다.
- 0.1.1 버전 코드 검토 결과:
  - 인터넷 접속 코드, 다른 프로그램을 실행하는 코드, 파일을 지우는 코드가 없다.
  - 의존 패키지는 `mcp`, `olefile` 두 개뿐이다.
  - 파일을 쓰는 곳은 결과 파일 저장과 이미지 추출 폴더뿐이다.
- 검토한 것은 **0.1.1 버전뿐**이다. 그래서 아래 명령은 버전을 `hwp-mcp==0.1.1`로 고정했다. 연수 자료의 원래 명령에는 버전 고정이 없는데, 그대로 쓰면 나중에 검토하지 않은 새 버전이 자동으로 설치될 수 있다.

사용자에게 안내할 때는 "교사 연수 자료를 바탕으로 한, Anthropic 공식이 아닌 도구"라고 밝힌다.

## 언제 안내하나

- 한글 파일을 읽지 못했고, 사용자가 앞으로도 한글 파일을 자주 다룰 것 같을 때 안내한다.
- 파일은 읽었더라도, 계획에 **한글 파일을 만들거나 고치는 단계**가 있으면 선택지로 안내할 수 있다. 나중에 작업할 Claude Code에는 한글 도구가 없을 수 있기 때문이다.
- **한 번만 쓸 거라면** 설치보다 "한글에서 PDF나 hwpx로 저장해서 보내 주세요"가 더 간단하다. 두 방법을 나란히 보여 주고, 사용자가 고르게 한다.
- 이 MCP는 **Claude Code**(Claude 데스크톱 앱의 Code 탭 포함)에서만 설치할 수 있고, 그곳에서만 쓸 수 있다. 채팅 화면만 쓰는 사용자에게는 형식 바꾸기를 안내한다.
- 학교나 회사 PC는 보안 프로그램 때문에 1번 명령이 막힐 수 있다. 막히면 억지로 우회하지 말고 형식 바꾸기로 돌아가거나, 전산 담당자에게 문의하라고 안내한다.

## 설치를 나중에 하기로 했을 때

사용자가 "나중에 Claude Code에서 설치할게요"라고 하면, 설치를 계획의 **선택 단계**(예: 0단계)로 넣고 CLAUDE.md 끝의 부록에 아래 설치 순서를 적는다.
- 그 단계에는 "**(선생님이 결정)** 설치 명령은 선생님이 원한다고 말할 때만 실행한다. 실행 전에 무엇을 내려받는지 설명하고 승인을 받는다"라는 규칙을 붙인다. CLAUDE.md는 자동으로 읽히는 파일이라, 이런 규칙이 없으면 Claude Code가 설치를 작업의 일부로 여기고 먼저 진행하려 할 수 있다.
- 설치하지 않아도 진행할 수 있게 다른 경로를 함께 적는다. 예: "설치하지 않으면 PDF나 hwpx로 저장한 파일로 진행"

## 설치 안내 (사용자에게 그대로 보여 줄 수 있는 순서)

> 한글 프로그램이 깔려 있지 않아도 됩니다. 한글을 실행하는 게 아니라 파일을 직접 읽는 방식이에요.
>
> **1. 클로드 코드 열기**
> 클로드 앱을 켜고 왼쪽에서 **Code**를 누르세요. 폴더를 고르라고 하면 **바탕화면**을 고르시면 돼요.
>
> **2. 첫 번째 명령 붙여 넣기**: 준비 도구(uv) 설치
> 아래 내용을 통째로 복사해서 입력창에 붙여 넣고 엔터를 누르세요.
> ```
> 아래 명령어 실행해줘
> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
> ```
> Claude가 "이 명령을 실행할까요?"라고 물어보면 **예**를 누르세요.
> (uv를 만든 Astral이라는 회사의 공식 설치 명령이에요. 이 명령을 실행하는 동안만 보안 설정을 잠깐 풀고, 컴퓨터 설정을 바꾸지는 않아요.)
>
> **3. 두 번째 명령 붙여 넣기**: 한글 MCP 연결
> ```
> 아래 명령어 실행해줘
> claude mcp add hwp -s user -- uvx --with "mcp==1.29.0" hwp-mcp==0.1.1
> ```
> 여기서도 물어보면 **예**를 누르세요. `"mcp==1.29.0"`과 `hwp-mcp==0.1.1` 부분이 빠지면 안 되니 꼭 통째로 복사해 주세요.
>
> **4. 앱을 완전히 껐다 켜기** (가장 많이 빠뜨리는 단계예요)
> 창만 닫지 말고 프로그램을 **완전히 종료**했다가 다시 켜세요. Claude는 켤 때만 새 도구를 알아봐요.
>
> **5. 잘 됐는지 확인**
> 클로드 코드에서 "한글 MCP 도구 뭐 있는지 알려줘"라고 입력하세요. 아래 8개가 나오면 성공이에요.
> `read_hwp`, `read_hwp_text`, `read_hwp_tables`, `list_hwp_images`, `extract_hwp_images`, `fill_hwp_template`, `replace_hwp_text`, `create_hwpx_document`

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 도구 8개가 안 나옴 | 4단계를 다시 한다. 앱을 완전히 종료한 뒤 다시 켠다 |
| `uvx를 찾을 수 없습니다` | 앱을 껐다 켠 다음 3번 명령부터 다시 한다 |
| `ModuleNotFoundError: mcp.server.fastmcp` | 명령 일부가 빠진 것이다. 3번 명령을 통째로 다시 붙여 넣는다 |
| 1번 명령이 보안 프로그램에 막힘 | 우회하지 않는다. 형식 바꾸기로 진행하거나 전산 담당자에게 문의한다 |

## 사용할 때 지킬 것 (Claude와 CLAUDE.md 규칙)

검토 중에 원본 파일을 망가뜨릴 수 있는 함정을 발견했다. 한글 파일을 다루는 작업이면 아래 규칙을 CLAUDE.md의 작업 규칙에도 넣는다.

- **원본 파일에 덮어쓰지 않는다.** `replace_hwp_text`나 `fill_hwp_template`에서 결과 저장 경로(`output_path`)를 원본과 같은 경로로 지정하면, 원본을 읽기도 전에 파일이 비워져서 **원본이 깨진다.**
  - 결과 저장 경로를 비워 두거나(자동으로 `_modified`/`_filled`가 붙은 새 파일이 생긴다) 다른 이름을 준다.
  - 여러 번 고칠 때는 매번 **직전 결과 파일**을 입력으로 쓰고, 출력은 또 다른 새 이름으로 저장한다.
- 작업을 시작하기 전에 원본의 **사본**을 만들어 두라고 사용자에게 권한다.
- 바꾸려는 문구가 문서 안에서 서식 때문에 여러 조각으로 나뉘어 있으면 찾지 못할 수 있다. 바꾼 개수가 0이면 "못 찾았어요"라고 알리고 다른 방법을 제안한다.
- 결과 파일이 한글에서 제대로 열리는지는 Claude가 확인할 수 없다. 완료 확인에 **(선생님 확인)**으로 표시한다.
