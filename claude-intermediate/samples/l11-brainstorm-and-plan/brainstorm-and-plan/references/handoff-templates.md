# 작업 파일 양식 (CLAUDE.md 하나)

승인된 계획을 아래 양식의 `CLAUDE.md` 파일 하나로 만든다. `[ ]` 안은 실제 내용으로 채우고, 해당 없는 항목은 지운다.

내용은 사용자가 읽고 이해할 수 있는 쉬운 한국어로 쓴다. 이 파일은 Claude Code뿐 아니라 사용자 본인도 읽기 때문이다.

**작업 규칙은 위에 짧게** 두고, **계획은 그 아래에** 둔다. Claude Code가 매번 읽는 파일이라, 규칙이 길거나 계획 속에 묻히면 잘 지켜지지 않는다.

## 목차
- 전달 방법 (다운로드 + 복사)
- CLAUDE.md 양식
- 시작 안내

---

## 전달 방법 (다운로드 + 복사)

**항상 두 가지를 함께 준다.** 초보자의 환경은 제각각이라 한 가지 방법이 막힐 수 있다. 학교나 회사 PC에서는 다운로드가 막히기도 하고, 다운로드하면서 파일 이름이 `CLAUDE (1).md`로 바뀌기도 한다. 파일 이름이 정확히 `CLAUDE.md`여야 자동으로 읽히므로 안내할 때 한 번 짚어 준다.

1. **다운로드용 파일**
   - 파일을 쓸 수 있는 환경이면 `CLAUDE.md`로 저장한다. 사용자에게 작업 폴더를 확인하고, 폴더가 없으면 새 폴더 이름을 제안한다. 같은 이름의 파일이 이미 있으면 덮어쓰기 전에 알린다.
   - 지금 대화가 이미 Claude Code 안에서 작업할 폴더를 열어 둔 상태라면 그 폴더에 바로 저장한다.
   - 파일 전달 도구가 있으면(예: 채팅 앱의 파일 첨부, SendUserFile) 그 파일을 건네서 내려받을 수 있게 한다.
   - 파일을 만들 방법이 전혀 없는 환경이면 다운로드는 안 된다고 짧게 알리고 2번으로 안내한다.
2. **복사용 코드 블록**
   - 파일 내용 전체를 ` ```markdown ` 코드 블록 하나에 그대로 넣는다. 채팅 화면의 복사 버튼으로 한 번에 복사할 수 있다.
   - 내용을 줄이거나 "…"로 생략하지 않는다. 복사한 내용이 곧 파일이 된다.
   - 파일 안에 ` ``` ` 코드 블록이 들어 있으면(예: 설치 명령) 바깥 블록은 백틱 4개(` ```` `)로 감싼다. 그래야 중간에서 블록이 끊기지 않는다.
   - 붙여 넣어서 파일로 만드는 방법은 아래 "시작 안내"를 따른다. 메모장은 저장할 때 `.txt`를 몰래 붙이므로 `CLAUDE.md.txt`가 되지 않게 짚어 준다.

**Claude Code를 처음 쓰는 사용자**: 써 본 적이 있는지 모르면 한 번 묻는다. 처음이라고 하면 시작 안내 끝에 짧게 덧붙인다.
- Claude Code는 Claude 데스크톱 앱의 Code 탭이나 터미널 프로그램에서 쓸 수 있다.
- 작업할 때는 먼저 폴더를 고른다.
- 학교나 회사 PC는 설치에 관리자 권한이 필요할 수 있다.

설치 메뉴의 정확한 위치처럼 확실하지 않은 내용은 지어내지 않는다. 모르면 공식 안내(claude.com)를 참고하라고 한다.

- 아래 "단계별 계획"에서 체크되지 않은 첫 단계부터, **한 번에 한 단계만** 진행한다.

## 시작 안내 (파일을 만든 뒤 사용자에게)

> **CLAUDE.md** 파일 하나를 만들었어요. 계획과 작업 규칙이 모두 들어 있어요. 아래 두 방법 중 편한 쪽으로 가져가세요.
>
> **방법 1. 다운로드** (더 쉬워요)
> - [파일을 첨부했으면: 첨부한 `CLAUDE.md` 파일을 내려받아 작업할 폴더에 넣어요.]
>   [폴더에 저장했으면: `[저장한 경로]`에 저장해 두었어요. 다른 곳에서 작업하려면 이 파일을 작업할 폴더로 옮기세요.]
> - 이름이 `CLAUDE (1).md`처럼 바뀌었으면 `CLAUDE.md`로 고쳐 주세요. 이름이 정확해야 Claude Code가 자동으로 읽어요.
>
> **방법 2. 복사해서 붙여 넣기** (다운로드가 안 될 때)
> 1. 아래 코드 블록 오른쪽 위의 **복사** 버튼을 눌러요.
> 2. 메모장을 열고 붙여 넣어요.
> 3. **파일 → 다른 이름으로 저장**을 눌러요.
>    - 파일 형식: **모든 파일 (\*.\*)**로 바꿔요. 안 바꾸면 `CLAUDE.md.txt`가 돼서 작동하지 않아요.
>    - 파일 이름: `CLAUDE.md`
>    - 인코딩: **UTF-8**
> 4. 작업할 폴더에 저장해요.
>
> [참고 자료를 받았으면: 주신 자료 파일(`[파일 이름들]`)도 `CLAUDE.md`와 **같은 폴더**에 넣어 주세요. Claude Code는 그 폴더 안의 파일만 볼 수 있어요.]
> [자료에 개인정보가 있었으면: 넣기 전에 [어디]의 이름과 연락처를 지운 사본을 만들어서 그 사본을 넣어 주세요.]
>
> **Claude Code에서 이어서 하는 방법**
> 1. Claude Code에서 그 폴더를 열고 "1단계부터 시작해 줘"라고 입력해요.
> 2. 단계가 끝날 때마다 결과를 확인하고 "다음 단계 진행해"라고 말하면 돼요.
>
> 다음 날 이어서 할 때도 폴더만 열고 "이어서 해 줘"라고 하면 돼요. 계획을 바꾸고 싶으면 언제든 "계획 수정하자"라고 하세요.

안내 다음에 파일 내용 전체를 ` ```markdown ` 코드 블록으로 붙인다.

작업 폴더에 이미 저장했다면 "작업 폴더에 저장해 두었어요"라고 알리고, 다운로드와 붙여 넣기 설명은 줄인다. 코드 블록은 그대로 붙인다. 다른 PC에서 쓰거나 다른 사람에게 줄 때 필요할 수 있기 때문이다.
