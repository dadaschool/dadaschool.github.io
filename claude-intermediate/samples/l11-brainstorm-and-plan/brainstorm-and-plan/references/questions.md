# 분야별 질문 목록

아래는 **고를 수 있는 재료**다. 전부 묻지 말고 이 작업의 결과를 바꿀 질문만 고른다. 가능하면 선택지와 추천 기본값을 함께 제시한다.

## 목차
- 수업 설계
- 문서 작성
- 앱·프로그램·코드 제작
- 그 밖의 작업

---

## 수업 설계

수업, 차시 계획, 활동, 평가, 학습지, 프로젝트 수업 등.

| 알아낼 것 | 질문 예시 | 기본값 제안 |
|---|---|---|
| 대상 | 몇 학년, 몇 명인가요? 수준 차이가 큰 편인가요? | 수준 차이가 있다고 보고 기본·도전 과제를 나눈다 |
| 성취기준 | 연결할 교과와 성취기준(또는 단원)이 있나요? | 단원명만 받아도 된다 |
| 분량 | 몇 차시, 한 차시 몇 분인가요? | 중학교 45분, 고등학교 50분, 초등학교 40분 |
| 형태 | 강의, 모둠 활동, 실습, 프로젝트 중 무엇에 가까운가요? | 도입·전개·정리 3단 구성 |
| 환경 | 학생 기기(태블릿, 노트북)와 인터넷을 쓸 수 있나요? | 기기 없이도 되는 대안을 함께 준비한다 |
| 평가 | 이 수업에서 평가를 하나요? 수행평가인가요? | 형성평가(간단한 확인 질문) 정도 |
| 결과물 | 무엇이 필요하세요? 교수학습 과정안, 학습지, 슬라이드, 루브릭 등 | 과정안과 학습지 |

## 문서 작성

보고서, 계획서, 가정통신문, 공문, 안내문, 발표 자료, 설명서 등.

| 알아낼 것 | 질문 예시 | 기본값 제안 |
|---|---|---|
| 독자 | 누가 읽나요? (관리자, 동료, 학부모, 학생, 외부 기관) | — (결과를 크게 바꾸므로 꼭 확인) |
| 목적 | 읽은 사람이 무엇을 하게 되길 바라나요? (알기, 승인하기, 참여하기, 제출하기) | 알리기 |
| 양식 | 정해진 양식이나 참고할 예전 문서가 있나요? | 없으면 일반적인 구성을 제안한다 |
| 분량 | 몇 쪽 정도인가요? | A4 1~2쪽 |
| 파일 형식 | 한글(hwp/hwpx), 워드, PDF, 구글 문서 중 무엇이 필요하세요? | 학교 문서라면 hwpx |
| 말투 | 공식적인 문체인가요, 친근한 문체인가요? | 독자에 맞춘다 (학부모: 정중·친근, 공문: 개조식) |
| 들어갈 내용 | 꼭 들어가야 할 날짜, 숫자, 이름이 있나요? | 모르는 값은 [빈칸]으로 표시한다 |

## 앱·프로그램·코드 제작

웹앱, 수업용 도구, 퀴즈, 자동화 스크립트, 구글 앱스 스크립트, 게임, 챗봇 등.

| 알아낼 것 | 질문 예시 | 기본값 제안 |
|---|---|---|
| 해결할 문제 | 지금 이 일을 어떻게 하고 있고, 뭐가 불편한가요? | 첫 요청에서 분명하면 묻지 않는다 |
| 사용자 | 누가 쓰나요? 나 혼자, 우리 반 학생, 다른 선생님들 | 나 혼자 먼저 써 본다 |
| 핵심 기능 | 딱 하나만 된다면 무엇이 되어야 하나요? | 그 하나를 1단계로 삼는다 |
| 실행 환경 | 어디서 쓰나요? 브라우저, 휴대폰, 학교 PC, 구글 시트 | 설치 없이 브라우저에서 열리는 HTML 파일 한 개 |
| 데이터 | 저장해야 하는 정보가 있나요? 학생 개인정보가 들어가나요? | 저장하지 않는다. 개인정보가 있으면 반드시 먼저 짚는다 |
| 공유 | 다른 사람이 접속해야 하나요? | 처음에는 공유 없이 파일로 만든다. 학생이 각자 기기로 써야 하면 인터넷에 올리는 일을 **마지막 단계**로 두고 계정이 필요하면 "(선생님이 직접)"으로 표시 |
| 경험 | 코드를 직접 고쳐 본 적이 있나요? | 없다고 보고, 사용자가 코드를 몰라도 되게 설계한다 |

초보자용 앱은 **설치가 필요 없고, 파일 하나로 열리고, 서버가 없는 것**부터 시작하는 게 거의 항상 낫다. 더 필요해지면 나중 단계에서 늘린다.

## 그 밖의 작업

행사 기획, 자료 정리, 연구 주제 잡기, 공부 계획 등 위에 해당하지 않으면 공통 네 가지(목표, 대상, 조건, 완료 기준)를 중심으로 묻고, 그 작업에서 가장 결과를 크게 바꿀 질문 한두 개를 더한다.
