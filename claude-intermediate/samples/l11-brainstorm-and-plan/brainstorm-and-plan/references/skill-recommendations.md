# 스킬·플러그인 추천 규칙

계획의 어떤 단계에 도움이 되는 스킬이 있으면 추천한다. 초보자는 무엇이 있는지 모르기 때문에 알려 주는 것만으로도 도움이 된다.

다만 스킬과 플러그인은 Claude의 행동을 바꾸고, 때로는 PC에서 실행되는 코드를 포함한다. 그래서 **출처를 Anthropic 공식으로 제한하고, 설치는 반드시 사용자가 결정**하게 한다.

## 언제 추천하나

- 3단계(계획)에서 단계별 계획을 세운 뒤, **특정 단계를 분명히 쉽게 만들어 주는 것**이 있을 때만 추천한다.
- 많아야 **3개**까지. 해당하는 게 없으면 추천하지 않고 넘어간다. 억지로 찾지 않는다.
- 계획은 스킬이 **없어도 진행할 수 있게** 짠다. 추천 스킬은 "있으면 더 편한 것"이다. 학교나 회사 PC에서는 설치가 막힐 수 있기 때문이다.

## 찾는 순서

1. **지금 환경에 이미 있는 스킬**을 먼저 확인한다. 설치할 필요가 없으므로 가장 좋다. 이미 켜져 있는 스킬은 사용자가 설치한 것이므로 출처 제한 대상이 아니다. 다만 "이미 있는 스킬"이라고 구분해서 말한다.
   - 계획을 세우는 이 환경(예: 채팅 앱)과 나중에 작업할 Claude Code는 설치된 스킬이 다를 수 있다. 그러니 "여기에는 있지만 Claude Code에는 없을 수 있어요. 없으면 없는 대로 진행돼요"라고 덧붙인다.
2. 새로 설치할 것이 필요하면 **아래 공식 출처에서만** 찾는다.

## 허용하는 공식 출처

| 출처 | 주소 | 설치 방법 |
|---|---|---|
| Anthropic 공식 플러그인 (Anthropic 제작분만) | https://github.com/anthropics/claude-plugins-official 의 `plugins/` 폴더 | `/plugin install <이름>@claude-plugins-official` 또는 앱의 플러그인 화면 |
| Anthropic 공식 스킬 | https://github.com/anthropics/skills | `/plugin marketplace add anthropics/skills` 후 `/plugin install document-skills@anthropic-agent-skills` 등, 또는 앱의 플러그인 화면 |
| 앱 안의 공식 카탈로그 | 스킬·플러그인 추천 도구(SuggestSkills, SearchPlugins 등)가 있을 때 | 도구가 띄우는 설치 카드. 단, 결과 중 **Anthropic이 만든 것만** 추천한다 |

## 파일 형식 때문에 도구가 필요할 때

자료 파일(한글 hwp/hwpx 등)을 읽지 못해서 도구가 필요한 경우에도 같은 규칙을 적용한다.
- 설치 없이 되는 방법(형식 바꿔 저장, 복사해서 붙여 넣기)을 먼저 안내한다. 자세한 순서는 `materials.md`의 "파일을 읽지 못할 때"에 있다.
- 한글 파일을 읽는 도구는 2026년 9월 확인 시점에 Anthropic 공식 출처(위 표)와 앱의 공식 커넥터 목록 어디에도 없었다.
- 사용자의 환경에 이미 한글용 MCP가 연결되어 있으면 그것을 쓴다. 사용자가 스스로 설치한 것이기 때문이다.

## 검토를 거친 예외 (공식이 아니지만 안내 가능)

아래 항목만 예외다. 스킬 관리자가 코드를 검토한 뒤 허용했다. 목록에 없는 비공식 도구는 여전히 추천하지 않는다.

| 도구 | 버전 | 검토일 | 안내 문서 |
|---|---|---|---|
| 한글 MCP (PyPI `hwp-mcp`, 제작 TreeSoop) | 0.1.1로 고정 | 2026-09-21 | `references/hwp-mcp.md` |

- 안내할 때는 "Anthropic 공식이 아니고, 교사 연수 자료를 바탕으로 검토된 도구"라고 밝힌다.
- 검토한 버전으로 고정한 명령만 안내한다. 새 버전을 쓰려면 다시 검토해야 한다.

## 추천하지 않는 것

- `claude-plugins-official`의 **`external_plugins/` 폴더**. 공식 목록에 올라 있지만 제3자가 만들었고, Anthropic이 내용을 통제하지 않는다고 저장소에 명시돼 있다.
- 커뮤니티 저장소, 블로그, 개인 GitHub, 스타 수가 많은 인기 저장소. 유명해도 공식이 아니면 제외한다.
- 출처 저장소가 `github.com/anthropics/` 아래가 아닌 것.

사용자가 이런 것을 직접 물어보면 "이 스킬은 공식 출처만 추천하도록 되어 있어요"라고 알린다. 원하면 따로 안전성 검토를 도와줄 수 있다고 덧붙인다.

## 추천 전에 반드시 확인

- 추천할 이름이 공식 출처에 **지금 실제로 있는지** 확인한다. 가능하면 웹에서 해당 폴더나 목록을 연다. 목록은 수시로 바뀌므로 기억만으로 추천하지 않는다.
- 웹을 볼 수 없는 환경이면 확인하지 못했다고 밝힌다. 그리고 앱의 플러그인 화면에서 직접 찾아보라고 안내한다. 이름을 지어내지 않는다.

## 추천하는 방법

스킬마다 아래를 쉬운 말로 알린다.

- **이름**과 **출처**(공식 저장소 링크)
- **어느 단계에 어떻게 도움이 되는지** 한 줄
- **필수인지 선택인지** (거의 항상 선택)
- **설치 방법**: 앱의 플러그인 화면에서 설치하는 방법을 먼저 안내하고, 명령어는 그다음에
- 설치할 때 인터넷에서 내려받는다는 점. 학교나 회사 PC에서는 막힐 수 있다.

**설치는 직접 실행하지 않는다.** 사용자가 설치하겠다고 하면 방법을 안내하거나, 설치 카드 도구가 있으면 카드를 띄워 사용자가 누르게 한다. 명령으로 대신 설치해야 하는 상황이면 무엇을 어디서 내려받는지 말하고 명시적인 승인을 받은 뒤에만 진행한다.

추천한 스킬은 CLAUDE.md의 "사용할 스킬" 항목에 설치 여부와 함께 적는다.
