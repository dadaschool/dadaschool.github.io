15차시 · Ⅳ. 영상과 소리

발표자료를 영상으로 바꾸기

HTML 발표자료의 슬라이드 한 장을 장면 하나로, 발표자 노트를 자막으로 바꿔 MP4 영상을 만듭니다. 결석한 학생의 복습용이나 사전 학습용으로 올리기 좋습니다.

도구 · 클로드 코드 (Code 탭) + HyperFrames (무료 오픈소스) 핵심 기법 · 슬라이드 한 장 = 장면 하나, 발표자 노트 = 자막
과업
목표
4장짜리 HTML 발표자료를 자막과 장면 전환이 들어간 40초 안팎의 영상으로 바꾼다 (예시: 중학교 영어 «Asking for Directions — 길 묻고 답하기»)
준비물
9차시에서 만든 발표자료의 복사본, 또는 연습용 발표자료 slides.html(4장, 발표자 노트 포함, 연수용 가상 자료)을 넣은 15차시 폴더 · Node.js 와 FFmpeg (14차시 4단계에서 점검)
결과물
길묻기_영상.mp4 (1280×720) + 장면별 시작·끝 시각표
주의
원본 발표자료는 고치지 않기 · 영어 문장과 자막은 교사가 검수 · 교과서 지문·그림은 넣지 않기

14차시는 영상을 처음부터 새로 짰다면, 이번에는 이미 검수한 발표자료를 재료로 씁니다. 화면에 들어갈 글과 그림, 교사가 할 말(발표자 노트)이 이미 정해져 있으니 장면표를 새로 쓸 필요가 거의 없습니다. 핵심은 둘입니다. 슬라이드 한 장을 장면 하나로 옮기고, 발표자 노트를 그대로 자막으로 쓰는 것입니다. 그러면 화면의 글과 자막이 서로 다른 말을 하지 않습니다.

1 준비

  1. 클로드연수 안에 빈 폴더 15차시 를 만듭니다.
  2. 9차시에서 만든 발표자료 index.html 을 복사해 15차시 에 넣습니다. 9차시를 하지 않았다면 연습용 slides.html 을 받아 넣습니다. 브라우저로 열어 → 로 넘기고 N 으로 발표자 노트를 볼 수 있습니다.
  3. 14차시를 하지 않았다면 14차시 따라 하기 4단계(내 컴퓨터 점검)를 먼저 합니다. Node.js 와 FFmpeg 가 필요합니다.

2 따라 하기

번호 순서대로 진행합니다. 프롬프트가 필요한 단계에는 바로 아래에 복사 단추가 있습니다.

  1. 데스크톱 앱 사이드바 맨 위의 Code 탭을 누릅니다.
  2. 프롬프트 상자 아래 줄의 환경 단추에서 Local 묶음의 맨 위 항목(내 컴퓨터)을 고르고, 폴더 단추의 Open folder… 로 클로드연수/15차시 를 고릅니다.
  3. 같은 줄의 권한 모드 단추를 Plan 으로 바꿉니다.
  4. 장면 계획을 받습니다. 연습용이 아닌 9차시 발표자료를 쓴다면 프롬프트의 slides.html 을 index.html 로 바꿉니다.
    프롬프트 1 · Plan 모드에서 장면 계획 받기
    이 폴더의 발표자료(slides.html)를 HyperFrames 로 MP4 영상으로 바꾸려고 합니다. 먼저 계획만 세워 주세요.

요구 사항
- 슬라이드 한 장 = 장면 하나. 화면 구성과 글은 발표자료 그대로
- 각 슬라이드의 발표자 노트를 자막으로 (노트 한 문장 = 자막 하나, 한 줄 30자 안팎)
- 장면 안의 글과 그림은 자막에 맞춰 하나씩 나타나게
- 장면 사이 전환은 0.6초 밀어내기
- 확인 문제 슬라이드는 문제를 보여 주고 5초 뒤 정답 공개
- 1280×720, 전체 40초 안팎, 소리 없음
- 원본 slides.html 은 고치지 않고, 영상용 파일은 video 폴더에 따로

계획은 표로 보여 주세요: 장면 | 시간 | 화면에 나타나는 순서 | 자막(발표자 노트)

    «노트 한 문장 = 자막 하나»로 정하면 자막이 교사가 수업에서 하는 말과 같아지고, 클로드가 문장을 새로 지어내지 않습니다. «원본은 고치지 않고 video 폴더에 따로»는 9차시 결과물을 지키는 문장입니다. 영상용으로 바꾸다 보면 글자 크기나 배치를 고치게 되는데, 그 변경이 원본 발표자료에 섞이지 않게 합니다.

4 검증 포인트

① 자막 = 발표자 노트 — 자막과 발표자 노트를 나란히 놓고 빠지거나 바뀐 문장이 없는지 봅니다. 클로드가 «더 자연스럽게» 고쳐 쓴 문장도 찾아냅니다.
② 화면 글 — 영어 철자·대소문자·문장 부호가 발표자료와 같은지 봅니다. 영상으로 옮기며 글자를 다시 입력하는 과정에서 틀리기 쉽습니다.
③ 시간 — 자막을 읽을 시간, 확인 문제를 생각할 시간이 충분한지 학생 입장에서 봅니다.
④ 전환 — 전환 효과가 너무 화려하거나 빨라 어지럽지 않은지 봅니다. 0.5~0.8초의 단순한 전환이 무난합니다.
⑤ 원본 보존 — 원본 발표자료 파일의 수정한 날짜가 바뀌지 않았는지 파일 탐색기에서 봅니다.
⑥ 재생 — 학교 PC와 휴대폰에서 모두 재생되는지 봅니다.
⑦ 저작권 — 교과서 지문·그림, 음원이 들어가지 않았는지 봅니다.

핵심 원리
발표자료를 영상으로 바꿀 때는 새로 만들지 않고 옮기는 것이 원칙입니다. 슬라이드 한 장은 장면 하나, 발표자 노트는 자막이 되므로 이미 검수한 내용이 그대로 영상에 들어갑니다. 원본은 고치지 않고 영상용 파일을 따로 두면, 발표자료와 영상을 각각 고치고 다시 만들 수 있습니다.
문제 해결
· 발표자 노트가 없는 발표자료다 — 먼저 «슬라이드마다 내가 할 말을 두 문장씩 발표자 노트로 써 주세요. 원본은 고치지 말고 노트만 표로 보여 주세요»라고 요청해 검수한 뒤 진행합니다.
· 슬라이드 글이 영상에서 작아 보인다 — 영상 화면(1280×720)이 발표 화면보다 작을 수 있습니다. «영상용 파일에서만 글자를 1.2배로 키워 주세요»라고 요청합니다.
· 파워포인트 파일만 있다 — Code 탭에서 «이 pptx 의 슬라이드는 그림으로, 노트는 글로 뽑아 영상 재료로 써 주세요»라고 요청해 봅니다. 컴퓨터에 따라 LibreOffice 같은 무료 프로그램을 설치해야 할 수 있으니, 설치 전에 묻게 합니다.
· Node.js·FFmpeg 오류 — 14차시의 문제 해결을 봅니다.
· 영상에 소리를 넣고 싶다 — 17차시에서 발표자 노트를 내레이션으로 읽게 하고 배경음악을 넣습니다.
