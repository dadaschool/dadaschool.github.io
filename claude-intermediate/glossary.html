용어 정리

이 연수자료에 나오는 말을 쉬운 말로 풀었습니다. «처음 나오는 곳»을 누르면 그 차시로 갑니다.

1 클로드

용어뜻처음 나오는 곳
코워크 (Cowork)여러 단계의 일을 맡기면 클로드가 끝까지 처리해 완성된 파일로 돌려주는 방식. 데스크톱 앱에서 내 컴퓨터 폴더를 연결해 파일을 읽고 만들 수 있습니다.바뀐 클로드 한 장
새 화면 · 예전 화면채팅과 코워크가 한 대화로 합쳐진 화면이 «새 화면», 메시지 상자에서 Chat·Cowork 를 고르는 화면이 «예전 화면»입니다. 계정마다 차례로 바뀝니다.연수 전 점검
클로드 코드 · Code 탭폴더 안의 파일을 직접 만들고 고치며 명령을 실행하는 클로드. 데스크톱 앱 사이드바 맨 위 Code 탭에서 따로 설치 없이 씁니다.5차시
세션클로드와 하나의 일을 두고 나누는 대화 한 묶음. 세션마다 맥락과 바뀐 내용을 따로 기억합니다.5차시
환경 (Local)Code 탭에서 작업이 실행되는 곳. «Local»을 고르면 내 컴퓨터에서 실행됩니다. 클라우드·SSH 를 고를 수도 있습니다.6차시
권한 모드클로드가 무엇을 묻고 무엇을 바로 할지 정하는 설정. Code 탭은 Plan(계획만) · Manual(하나씩 허락) · Accept edits(파일 수정 자동 수락) · Auto(위험한 행동은 막고 진행). 대화(코워크)는 Auto · Manual.안전하게 쓰기
아티팩트대화 옆에 만들어지는 결과물(문서·그림·작은 웹페이지 등). 클로드 디자인처럼 템플릿에서 시작할 수도 있고, 처음에는 나만 보이며 «공유»로 나눕니다. 이 연수는 진짜 파일을 만드는 코워크·Code 탭을 주로 씁니다.6차시
스킬 (SKILL.md)어떤 일을 어떤 순서로 하는지 적어 둔 작업 설명서. 클로드는 관련된 일이 나오면 그 순서를 따르고, Code 에서는 /스킬이름으로 직접 부를 수도 있습니다.11차시
CLAUDE.md작업 폴더에 두는 메모 파일. Code 탭은 세션을 시작할 때 이 파일을 저절로 읽어, 적어 둔 규칙과 계획을 다음 날에도 이어서 따릅니다. 파일 이름이 정확히 CLAUDE.md 여야 합니다.11차시 (마)
예시 스킬 · 공식 스킬 저장소Anthropic 이 만들어 공개한 스킬 모음(github.com/anthropics/skills). claude.ai 의 Customize → Skills 에서 켜서 씁니다.11차시 (라)
클로드 디자인 (Claude Design)대화로 활동지·포스터·원페이저 같은 한 장 디자인을 만들고, 대화 옆 캔버스에서 다듬어 PDF·PPTX·HTML 등으로 내보내는 아티팩트 템플릿. 모든 플랜에서 씁니다(Enterprise 는 관리 설정에 따름).18차시
디자인 시스템색·글꼴·구성 요소·규칙을 한 번 정해 두면 새 디자인에 저절로 적용되는 설정. 유료 플랜의 베타 기능입니다.18차시
캔버스 · 인라인 댓글클로드 디자인에서 결과물이 놓이는 작업판. 고칠 곳을 눌러 댓글로 바로 부탁합니다.18차시
커넥터구글 드라이브·지메일·Microsoft 365 같은 앱을 클로드에 연결해 작업 중에 자료를 가져오게 하는 기능.바뀐 클로드 한 장
MCP클로드와 바깥 도구를 잇는 연결 방식. 커넥터의 상당수가 이 방식으로 동작합니다.바뀐 클로드 한 장
MCP 서버클로드에 도구를 붙여 주는 작은 프로그램. 내 컴퓨터에서 실행되는 것(예: 한글 MCP)과 인터넷 서비스로 연결되는 것이 있습니다.부록 · 한글 MCP
플러그인스킬·커넥터 등을 한데 묶은 꾸러미.11차시
프롬프트 인젝션클로드가 읽는 웹페이지·문서 속에 숨겨 둔 명령으로 클로드를 속이려는 공격.안전하게 쓰기

2 웹과 파일

용어뜻처음 나오는 곳
HTML · 한 파일 HTML웹페이지를 만드는 언어. 그림·글꼴·스크립트를 한 파일에 모두 담으면 인터넷 없이 더블클릭만으로 열리고, USB로 옮기기도 쉽습니다.5차시
브라우저 창 (앱 안)Code 탭 대화창의 HTML·PDF·영상 경로를 누르면 열리는, 앱 안의 미리보기 창.6차시
GitHub · 저장소파일을 올려 두고 바뀐 기록을 남기는 서비스. 저장소는 한 프로젝트의 파일을 모아 두는 곳입니다.8차시
GitHub PagesGitHub 저장소의 HTML 파일을 인터넷 주소로 공개해 주는 기능. 공개 저장소는 누구나 볼 수 있습니다.8차시
QR 코드휴대폰 카메라로 비추면 주소가 열리는 네모 무늬. 인쇄해서 교실에 붙이기 좋습니다.8차시
CSV쉼표로 칸을 나눈 표 파일. 엑셀로 만들고 «CSV로 저장»할 수 있고, 문제 목록·자료 목록을 클로드에게 줄 때 씁니다.7차시
docx · xlsx · pptx워드 문서, 엑셀 표, 파워포인트 발표자료 파일 형식.2차시
HWPX한글 프로그램의 문서 형식. 안쪽은 여러 XML 파일을 묶은 압축 파일입니다.4차시
명도 대비 (대비 비율)글자색과 바탕색의 밝기 차이. 웹 접근성 기준(WCAG)은 본문 글자에 4.5:1 이상을 권합니다. 흑백 인쇄·교실 TV에서 읽히는지와도 이어집니다.18차시
오픈 폰트 라이선스 (OFL)글꼴을 무료로 쓰고, 고치고, 다시 나눌 수 있게 한 라이선스. 상업적 사용도 되지만 글꼴 파일만 따로 파는 것은 안 됩니다. Pretendard·나눔고딕이 이 라이선스입니다.안전하게 쓰기
대체 텍스트그림을 볼 수 없는 사람에게 화면 읽기 프로그램이 읽어 주는 그림 설명.캡처 올리기

3 프로그램과 영상·소리

용어뜻처음 나오는 곳
터미널 · PowerShell글자로 명령을 입력해 컴퓨터를 다루는 창. 윈도우에는 PowerShell 과 명령 프롬프트(CMD)가, 맥에는 «터미널»이 있습니다.5차시
PATH명령 이름만 쳐도 프로그램을 찾을 수 있게 컴퓨터가 뒤지는 폴더 목록. 설치 뒤 «명령을 찾을 수 없음»이 뜨면 대개 이 설정 문제입니다.5차시
Node.js · npm자바스크립트 프로그램을 내 컴퓨터에서 실행하는 도구와, 그 도구로 쓰는 꾸러미를 내려받는 프로그램. 코드로 영상을 만드는 도구들이 필요로 합니다.14차시
HyperFrames · RemotionHTML·코드로 장면을 만들어 MP4 영상으로 내보내는 오픈소스 도구. Remotion 은 기관 규모에 따라 유료 라이선스가 필요할 수 있습니다.14차시
uv · uvx파이썬으로 만든 프로그램을 내려받아 다른 프로그램과 섞이지 않게 따로 실행해 주는 무료 도구(Astral 제작). uvx 는 그 실행 명령입니다.부록 · 한글 MCP
PyPI파이썬 프로그램을 올리고 내려받는 공개 저장소. 누구나 올릴 수 있어 공식 도구인지 따로 확인해야 합니다.부록 · 한글 MCP
ffmpeg영상·소리를 자르고 붙이고 바꾸는 무료 명령줄 프로그램.16차시
SRT자막 파일 형식. 시작·끝 시각과 자막 글이 차례로 들어 있습니다.16차시
TTS글을 소리로 읽어 주는 음성 합성. 운영체제에 들어 있는 음성이나 오픈소스 프로그램을 쓸 수 있습니다.17차시
WAV · MP3 · MP4소리 파일(WAV는 압축하지 않은 원음, MP3는 압축한 소리)과 영상 파일 형식.17차시
