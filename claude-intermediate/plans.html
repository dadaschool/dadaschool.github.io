claude.ai 에서 스킬을 쓰려면 코드 실행이 켜져 있어야 합니다. 개인 플랜(Free·Pro·Max·Ultra)은 Settings → Capabilities 의 «Code execution and file creation»(새 설정 화면에서는 «Create and edit files»)을 켜고 Customize → Skills 에서 스킬을 켜거나 올립니다. Team 은 기관에서 기본으로 켜져 있고, Enterprise 는 소유자가 조직 설정에서 켜야 합니다.

«—» 는 해당 없음이거나 공식 문서에서 따로 적지 않은 것입니다. 플랜마다 쓸 수 있는 양(사용 한도)은 다릅니다.

2 차시별로 필요한 것

차시필요한 것무료 계정이라면
시작하기데스크톱 앱 설치, 클로드 계정읽기만 가능
Ⅰ 코워크 (1~4)유료 플랜 + 데스크톱 앱실습 불가 — 강사 화면 시연을 봄
Ⅱ 클로드 코드 (5~10)유료 플랜 + 데스크톱 앱 Code 탭실습 불가
Ⅲ 스킬 (11~12)Code 탭(유료) 또는 claude.ai 스킬claude.ai 스킬 올리기·켜기는 가능, Code 탭 실습은 불가
Ⅳ 영상과 소리 (13~17)Code 탭(유료). 영상 도구에 Node.js·ffmpeg 같은 무료 프로그램 설치가 필요할 수 있음. 13차시의 «모션»은 Team·Enterprise 베타실습 불가
Ⅴ 클로드 디자인 (18)클로드 계정 + 코드 실행 기능 켜기. 디자인 시스템은 유료 플랜(베타)디자인 만들기는 가능. 디자인 시스템이 없으니 색·글꼴을 프롬프트에 직접 적음. 링크로 나누기는 안 됨
Ⅵ 단원 프로젝트코워크와 Code 탭 모두(유료)실습 불가
부록 · 한글 MCPCode 탭(유료) + 명령줄 클로드 코드 + uv 설치사용 불가

3 이 연수에서 다루지 않는 것

Claude Slides · Docs — 클로드 디자인과 같은 자리(메시지 상자의 출력, 아티팩트 탭)에서 시작하는 템플릿이지만 이 연수에서는 다루지 않습니다. 쓸 수 있는 플랜은 Claude 도움말에서 확인합니다.
학교·기관 계정(Team · Enterprise)은 관리자 설정에 따라 일부 기능이 꺼져 있을 수 있습니다. 예를 들어 Code 탭의 환경 목록에서 내 컴퓨터 항목이 회색이고 «Disabled by your organization» 이 뜨면 관리자가 막은 것입니다.
