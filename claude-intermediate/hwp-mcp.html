한글 MCP로 한글 파일 읽고 쓰기

한글 프로그램 없이 hwp·hwpx 파일의 글·표·그림을 읽고, 작년 문서의 연도 바꾸기나 양식 채우기를 새 파일로 하게 해 주는 외부 도구를 Code 탭에 붙입니다. Anthropic 공식 도구가 아니므로 연수자료에서 직접 검토한 판만, 지킬 것과 함께 씁니다.

도구 · Code 탭 + 한글 MCP (비공식) 검토한 판 · hwp-mcp 0.1.1 고정 (2026-11-15)
한눈에
무엇
PyPI(파이썬 프로그램 저장소)의 hwp-mcp 0.1.1 — 클로드에 한글 파일 도구 8개를 붙이는 MCP 서버
어디서
데스크톱 앱 Code 탭(환경 Local)과 명령줄 클로드 코드. 코워크와 채팅에서는 쓰이지 않습니다
준비물
Code 탭을 쓰는 유료 플랜, 명령줄 클로드 코드(5차시 선택 과정), 인터넷, 개인정보가 없는 한글 파일 사본
주의
hwpx 사본으로 작업 · 원본은 그대로 두고 새 이름으로 저장 · 결과는 한글에서 직접 열어 확인

MCP는 클로드에 새 도구를 붙이는 연결 방식입니다. 커넥터가 인터넷 서비스를 붙인다면, 이 한글 MCP는 내 컴퓨터에서 작은 프로그램을 띄워 한글 파일을 직접 엽니다. 4차시에서 본 것처럼 클로드 도움말의 «올릴 수 있는 문서» 목록에는 한글 파일이 없습니다. 받은 공문이나 작년 계획서처럼 한글 파일을 자주 다룬다면 이 도구가 옮겨 적는 일을 줄여 줍니다. 다만 고치는 기능에는 함정이 있어서, 이 부록의 핵심은 원본을 지키는 프롬프트와 결과를 한글에서 직접 확인하는 습관입니다.

① 공식 도구가 아닙니다 — Treesoop 이라는 곳이 PyPI 에 올린 무료(MIT 라이선스) 패키지입니다. PyPI 페이지에 홈페이지나 소스 저장소 주소가 없습니다. 연수자료에서 0.1.1 판의 코드를 모두 읽고 실제로 돌려 본 결과를 8. 검토한 내용에 적었습니다.
② 0.1.1 판만 씁니다 — 설치 명령에 판 번호를 고정했습니다. 패키지 설명에 나오는 다른 설치 명령(hangul-mcp)이나 판 번호를 뺀 명령은 쓰지 않습니다. 새 판이 나와도 검토하기 전에는 바꾸지 않습니다.
③ 학교 PC에서 막히면 우회하지 않습니다 — 보안 프로그램이나 학교망이 설치를 막으면 정보 담당 선생님께 문의합니다.
④ 파일 내용은 클로드에게 갑니다 — 파일은 내 컴퓨터에서 열지만, 읽은 글은 다른 Code 탭 작업처럼 클로드(Anthropic 서버)로 전달됩니다. 학생 이름·연락처·성적이 든 문서는 그 부분을 지운 사본으로만 씁니다.
⑤ 고치는 일은 hwpx 로만 — 검토해 보니 옛 형식 .hwp 파일은 고친 결과 파일이 규격과 맞지 않게 바뀌었고, 표도 제대로 읽히지 않았습니다. 한글에서 hwpx 로 저장한 사본으로 작업합니다.

2 설치 (한 번만)

처음 한 번만 합니다. 학교 PC는 설치해도 되는지 정보 담당 선생님께 먼저 확인합니다. 명령은 복사 단추로 통째로 붙여 넣습니다. 인터넷에서 uv, 필요하면 파이썬, 그리고 한글 MCP 꾸러미를 내려받습니다.

  1. 연습 폴더와 파일을 준비합니다. 클로드연수 안에 한글MCP 폴더를 만듭니다. 한글 프로그램에서 새 문서를 열어 아래 글을 붙여 넣고, 아무 표나 하나 넣은 뒤 다른 이름으로 저장에서 hwpx 형식을 골라 연습_행사안내.hwpx 로 저장합니다. 개인정보가 없는 작년 계획서 사본을 써도 됩니다(.hwp 라면 hwpx 로 저장한 사본).
    연습 문서에 붙여 넣을 글 (연수용 가상 자료)
    2025학년도 과학의 날 행사 안내 (연수용 가상 자료)
일시: {{일시}}
장소: {{장소}}
준비물: {{준비물}}
담당: {{담당자}}
2025학년도 행사 예산은 따로 안내합니다.

    {{일시}} 같은 표시는 «양식 채우기»를 연습하려고 넣었습니다. «2025학년도»는 두 번 나오므로, 문구 바꾸기를 하면 «2건»이 나와야 맞습니다.

  2. 터미널을 엽니다.
    윈도우 — Win+X 를 눌러 Windows PowerShell 또는 터미널을 고릅니다(«관리자»가 붙지 않은 항목).
    맥 — ⌘+Space 로 Spotlight 를 열고 Terminal 을 입력해 Enter.
  3. uv 를 설치합니다. 내 컴퓨터에 맞는 명령 하나만 붙여 넣고 Enter.
    윈도우 · PowerShell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    맥 · 터미널
    curl -LsSf https://astral.sh/uv/install.sh | sh

    uv 는 파이썬으로 만든 프로그램을 내려받아, 다른 프로그램과 섞이지 않게 따로 실행해 주는 무료 도구입니다(Astral 제작). 컴퓨터에 파이썬이 없으면 필요한 파이썬도 알아서 내려받습니다. 윈도우 명령의 -ExecutionPolicy ByPass 는 이 명령을 실행하는 동안만 인터넷에서 받은 설치 스크립트를 실행하도록 허용하는 것으로, uv 공식 설치 문서에 적힌 그대로입니다. 다른 방법으로 윈도우는 winget install --id=astral-sh.uv -e, 맥은 brew install uv 도 됩니다.

  4. 터미널 창을 닫고 새 창을 연 뒤 아래 명령을 입력합니다. uvx 0.13.8 처럼 버전 번호가 나오면 됩니다(숫자는 다를 수 있습니다).
    uv 설치 확인
    uvx --version
    캡처 넣을 곳 · H-1
    uv 설치와 확인 (설치 3~4번).
    • 설치 명령과 설치가 끝났다는 문구(화면 문구를 따릅니다)가 보이게
    • 빨간 상자: 새 창에서 uvx --version 과 버전 번호
  5. 명령줄 클로드 코드가 있는지 봅니다. 아래 명령에 2.1.325 (Claude Code) 처럼 버전이 나오면 다음 단계로 갑니다. «찾을 수 없다»고 나오면 5차시의 «선택 · 명령줄(터미널)에서도 쓰기» 1~4단계로 먼저 설치합니다. 관리자 권한은 필요 없습니다.
    명령줄 클로드 코드 확인
    claude --version
  6. 한글 MCP를 연결합니다. 아래 명령을 붙여 넣고 Enter. Added stdio MCP server hwp with command: uvx --with mcp==1.29.0 hwp-mcp==0.1.1 to user config 가 나오면 설정이 저장된 것입니다.
    한글 MCP 연결 (0.1.1 판 고정)
    claude mcp add hwp -s user -- uvx --with "mcp==1.29.0" hwp-mcp==0.1.1

    hwp 는 이 도구에 붙인 이름입니다. -s user(--scope user)는 «내 계정의 모든 폴더에서 쓰기»라는 뜻으로, 설정이 홈 폴더의 .claude.json 에 저장됩니다. -- 뒤는 클로드가 도구를 켤 때 실행할 명령입니다. "mcp==1.29.0" 을 빼면 안 됩니다. 이 패키지는 MCP 개발 도구의 판을 «1.0.0 이상»으로만 적어 두어서, 빼면 최신 2.x 판이 깔리고 서버가 켜지지 않습니다(연수자료에서 확인). hwp-mcp==0.1.1 을 빼면 검토하지 않은 판이 깔릴 수 있습니다.

  7. 연결을 확인합니다. hwp: … - ✔ Connected 가 나오면 됩니다(창에 따라 √ Connected). 처음에는 내려받는 동안 ✘ Failed to connect 가 나올 수 있으니 10~20초 뒤 한 번 더 실행합니다.
    연결 확인
    claude mcp list
    캡처 넣을 곳 · H-2
    한글 MCP 연결과 확인 (설치 6~7번).
    • 번호 표시: ① Added stdio MCP server hwp … 줄 ② claude mcp list 의 hwp: … Connected 줄
  8. 데스크톱 앱을 완전히 종료했다가 다시 켭니다. 창만 닫지 말고 앱을 끝냅니다(맥은 ⌘+Q). 데스크톱 앱의 Code 탭은 명령줄 클로드 코드와 같은 설정 파일(.claude.json)에서 MCP 서버를 읽습니다. 다만 앱은 켤 때의 PATH(프로그램을 찾는 폴더 목록)를 쓰기 때문에, 새로 깐 uv 를 찾으려면 앱을 다시 시작해야 합니다. 가장 많이 빠뜨리는 단계입니다.
터미널 대신 Code 탭에 시켜도 되나요? Code 탭은 명령을 실행할 수 있어서 위 명령을 «실행해 주세요»라고 부탁할 수도 있습니다. 다만 Code 탭은 명령줄 클로드 코드 없이 돌아가므로, claude 명령은 명령줄 클로드 코드를 따로 깐 컴퓨터에서만 찾을 수 있고 설치 직후에는 앱을 다시 켜야 할 수 있습니다. 공식 문서에 이 방법이 따로 적혀 있지 않아, 이 연수에서는 터미널에서 직접 하는 길을 기본으로 합니다. 부탁할 때는 명령을 실행하기 전에 승인 창의 명령이 위와 글자 하나까지 같은지 확인합니다.

3 확인과 첫 시도

  1. 데스크톱 앱 사이드바 맨 위의 Code 탭에서 환경은 Local 맨 위 항목, 폴더는 Open folder… 로 클로드연수/한글MCP 를 고르고, 권한 모드를 Manual 로 둡니다.
  2. 도구가 붙었는지 묻습니다. 아래 8개가 나오면 성공입니다.
    프롬프트 1 · 설치 확인
    한글 MCP(hwp) 도구가 무엇이 있는지 이름과 하는 일을 표로 알려 주세요.
    캡처 넣을 곳 · H-3
    도구 8개 확인 (확인 2번).
    • 빨간 상자: 답에 나온 도구 이름 8개
    • 화면 아래 줄의 환경 Local 과 폴더 한글MCP 가 함께 보이게
    도구 이름하는 일 (연수자료에서 불러 본 결과)
    read_hwp문서 전체 읽기 — 글, 표(마크다운 표), 그림 목록. hwpx 는 표 안의 글이 줄글로 한두 번 더 나오고, hwp 는 표 안의 글이 빠지거나 표가 비어 나올 수 있습니다.
    read_hwp_text글만 뽑기. 설명에는 «표 제외»라고 되어 있지만 표 칸의 글도 줄글로 섞여 나옵니다.
    read_hwp_tables표만 뽑기. hwpx 는 잘 되고, hwp 는 칸이 비거나 어긋납니다.
    list_hwp_images문서에 든 그림 목록 보기.
    extract_hwp_images그림을 파일로 꺼내기. 폴더를 정하지 않으면 원본 옆 문서이름_images 폴더에 저장합니다.
    fill_hwp_template양식의 표시({{일시}} 등) 여러 개를 한 번에 바꾸기. 저장 이름을 정하지 않으면 원본이름_filled.
    replace_hwp_text문구 하나를 다른 문구로 바꾸기. 바꾼 개수를 알려 줍니다. 저장 이름을 정하지 않으면 원본이름_modified.
    create_hwpx_document새 hwpx 만들기 — 글 줄과 단순한 표만. 같은 이름의 파일이 있으면 묻지 않고 덮어씁니다.
  3. 첫 시도 — 연습 파일을 읽어 봅니다. 한글 프로그램을 켜지 않았는데도 내용을 읽어 내면 준비가 끝난 것입니다. 클로드가 도구를 쓰기 전에 승인 창이 나오면 무엇을 하려는지 읽고 승인합니다.

4 업무에 쓰기

교사 업무에 바로 쓰는 프롬프트입니다. [ ] 부분을 내 파일 이름과 내용으로 바꿉니다. 파일을 만드는 프롬프트에는 모두 «원본은 그대로 두고 새 이름으로 저장»과 «같은 이름이 있으면 먼저 알려 주기»가 들어 있으니 지우지 않습니다. 프롬프트는 hwpx 사본을 기준으로 썼습니다. 받은 공문이 .hwp 라면 한글에서 hwpx 로 저장한 사본을 씁니다(읽기만 할 때도 .hwp 는 표가 빠질 수 있습니다). 눌러 펼친 뒤 복사합니다.

읽기공문 요약 표목적·대상·일정·제출물·마감일 표와 우리 학교가 할 일
읽기 · 공문 요약 표
한글 MCP로 이 폴더의 «[파일이름].hwpx» 공문을 읽고 핵심만 정리해 주세요. 파일은 고치지 마세요.
- 목적, 대상, 일정, 제출물, 마감일을 표로
- 우리 학교에서 해야 할 일은 따로 목록으로
- 날짜·금액·인원·마감일은 문서에 적힌 그대로 옮기고, 문서에 없는 내용은 «(문서에 없음)»으로 쓰기
읽기표만 그대로 뽑기칸의 글자는 바꾸거나 추측하지 않기, hwp 면 먼저 알리기
읽기 · 표만 그대로 뽑기
한글 MCP의 표 읽기 도구로 «[파일이름].hwpx» 의 표만 뽑아 주세요. 파일은 고치지 마세요.

5 꼭 지킬 것

① 결과 저장 경로를 원본과 같게 하지 않습니다 — 0.1.1 은 문구 바꾸기·양식 채우기의 저장 경로가 원본과 같으면 원본을 읽기도 전에 파일을 비워 버립니다. 연수자료에서 사본으로 해 보니 오류(Truncated file header)가 나면서 2KB 파일이 22바이트짜리 빈 파일이 되었고, 그 파일을 다시 읽으면 오류 없이 «문단 0개»로만 나왔습니다. 승인 창에 저장 경로가 보이면 원본 이름과 다른지 확인합니다.
② 같은 이름이 있으면 묻지 않고 덮어씁니다 — 새 문서 만들기는 같은 이름의 파일이 있으면 그대로 덮어썼습니다. 저장 이름을 비우면 _modified·_filled 가 붙은 이름으로 저장되는데, 두 번 하면 앞의 결과를 덮어씁니다. 그래서 프롬프트마다 «같은 이름이 있으면 먼저 알려 주기»를 넣었습니다. 시작하기 전에 원본 사본을 다른 폴더에 둡니다.
③ .hwp 파일은 고치지 않습니다 — hwp 파일의 문구를 바꾼 결과를 검사해 보니, 바꾼 글과 상관없는 문단까지 문단 정보(글자 수 등)가 한글 문서 규격과 다르게 바뀌어 있었습니다. 한글 프로그램에서 열어 보지는 못했지만 깨질 가능성이 큽니다. hwp 의 표도 칸이 비거나 섞여 나왔습니다. 한글에서 hwpx 로 저장한 사본으로 작업합니다.
④ 바꾼 개수가 0이거나 예상보다 적을 때 — 한 낱말 안에서 글자 모양이 다르면(예: «2025»만 굵게) 문서 안에서 조각으로 나뉘어 있어 찾지 못합니다. 두 번 나오는 «2025학년도» 가운데 하나를 이렇게 나눠 두었더니 1건만 바뀌었습니다. 읽기 결과에는 두 곳 모두 보이므로 개수를 꼭 대조하고, 남은 곳은 한글에서 직접 고칩니다.
⑤ 짧은 말과 기호는 바꾸지 않습니다 — hwpx 문구 바꾸기는 화면에 보이는 글자뿐 아니라 파일 안쪽의 서식 정보까지 함께 찾아 바꿉니다. 숫자 «0»을 바꾸게 했더니 보이지 않는 곳까지 88건이 바뀌어 파일이 깨졌습니다. «2025학년도»처럼 충분히 긴 말로 바꾸고, 바꿀 말에 &, <, > 기호를 넣지 않습니다(넣었더니 파일이 깨졌습니다). 찾을 말에 & 가 있으면 0건이 나옵니다.
⑥ 결과는 교사가 한글에서 직접 엽니다 — 클로드는 결과 파일이 한글에서 제대로 열리는지 볼 수 없습니다. 연수자료도 한글 프로그램에서는 열어 보지 못했습니다. 특히 새로 만든 hwpx 는 한글이 저장한 파일보다 구조가 훨씬 단순합니다. 열리지 않거나 모양이 다르면 한글에서 직접 고치거나 4차시 (가) 길로 만듭니다.
⑦ 개인정보 — 연습도 실제 업무도 학생 이름·연락처·성적이 든 부분을 지운 사본으로만 합니다.

이럴 때이렇게

('uvx' is not recognized…, command not found: uvx)		터미널 창을 닫고 새로 열어 다시 해 봅니다. 그래도 같으면 설치 3번의 uv 설치 명령을 다시 실행합니다.
uv 설치가 보안 프로그램·학교망에 막힌다
(HTML 오류, TLS·SSL 오류, 내려받기 실패)		우회하지 않습니다. 정보 담당 선생님께 문의하거나, 이 도구 없이 한글에서 PDF·HWPX 로 저장해 넣는 길로 합니다.
claude 를 찾을 수 없다고 한다명령줄 클로드 코드가 없거나 PATH 문제입니다. 5차시 선택 과정과 문제 해결 3번을 봅니다.
claude mcp list 에 ✘ Failed to connect — ENOENT: Executable not found in $PATH: "uvx"터미널이나 앱이 uv 를 찾지 못하는 것입니다. 새 창에서 uvx --version 부터 확인하고, 데스크톱 앱은 완전히 종료했다가 다시 켭니다.
✘ Failed to connect (CONNECTION_CLOSED 등)처음이라면 10~20초 뒤 claude mcp list 를 다시 실행합니다. 계속 같으면 claude mcp get hwp 로 Args 가 --with mcp==1.29.0 hwp-mcp==0.1.1 인지 봅니다. mcp==1.29.0 이 빠지면 이렇게 켜지지 않습니다. claude mcp remove hwp -s user 로 지운 뒤 설치 6번 명령을 통째로 다시 붙여 넣습니다.
✘ Blocked by enterprise managed policy기관 정책이 막은 것입니다. 관리자에게 문의합니다.
같은 이름의 서버가 이미 있다는 오류claude mcp remove hwp -s user 로 지운 뒤 다시 추가합니다.
Code 탭에서 한글 MCP 도구를 모른다고 한다앱을 완전히 종료했다가 다시 켭니다. 환경이 Local 인지, 코워크·채팅이 아니라 Code 탭인지 봅니다. 터미널의 claude mcp list 에서 Connected 인지 봅니다.
읽은 결과에 표 내용이 두세 번 겹쳐 나온다0.1.1 의 «문서 전체 읽기»는 표 글자를 줄글로도 내보냅니다. 표는 «표만 뽑기» 결과를 기준으로 봅니다.
hwp 파일의 표가 비어 있거나 칸이 어긋난다0.1.1 의 한계입니다. 한글에서 hwpx 로 저장한 사본으로 다시 읽습니다.
고친 뒤 원본이 비었다 / 결과를 다시 읽으니 «(텍스트가 비어있습니다)» 또는 «문단 0개»파일이 깨진 것입니다. 따로 둔 사본으로 되돌리고, 꼭 지킬 것 ①·⑤를 확인합니다.
바꾼 개수가 0이거나 예상보다 적다꼭 지킬 것 ④·⑤를 봅니다. 남은 곳은 한글에서 직접 고칩니다.
만든 hwpx 가 한글에서 열리지 않는다원본 사본을 한글에서 직접 고치거나, 4차시 (가) 길로 만듭니다.

8 검토한 내용

연수자료에서 한 일 (2026-11-15)
  • 받은 파일 — PyPI 의 hwp-mcp 0.1.1 (2026-03-31 올림, 작성자 Treesoop, MIT 라이선스). PyPI 정보에 홈페이지·소스 저장소 주소는 없습니다. 같은 날 0.1.0 과, 같은 작성자의 hangul-mcp 0.1.0 도 올라와 있습니다.
  • 코드 — 파이썬 파일 7개(약 1,700줄)를 모두 읽었습니다. 인터넷에 접속하는 코드, 다른 프로그램을 실행하는 코드, 파일을 지우는 코드는 없습니다. 클로드와는 같은 컴퓨터 안의 표준 입출력(stdio)으로만 주고받습니다.
  • 파일을 쓰는 곳 — 결과 파일, 새 문서, 그림 폴더 세 가지뿐입니다. 다만 클로드가 넘긴 경로면 어디든 쓰고, 같은 이름의 파일은 묻지 않고 덮어씁니다.
  • 함께 깔리는 것 — mcp(MCP 공식 파이썬 개발 도구)와 olefile(hwp 파일을 여는 도구). mcp 는 «1.0.0 이상»으로만 적혀 있어, 판을 고정하지 않으면 2026-11-15 현재 최신인 2.3.0 이 깔리고 서버가 No module named 'mcp.server.fastmcp' 오류로 켜지지 않았습니다. 그래서 mcp==1.29.0 고정이 꼭 필요합니다.
  • 실제로 돌려 본 것 — 리눅스에서 uv 0.13.8 로 이 부록의 명령 그대로 서버를 띄우고, 명령줄 클로드 코드 2.1.325 의 claude mcp add · list · get · remove 로 연결과 삭제를 확인했습니다. 도구 8개를 모두 불러 이 부록의 표와 «꼭 지킬 것»을 확인했습니다. hwp 읽기는 공개된 오픈소스 프로젝트의 시험용 hwp 파일로, hwpx 는 직접 만든 연수용 가상 파일로 확인했습니다.
  • 해 보지 못한 것 — 결과 파일을 한글 프로그램에서 열어 보기, 윈도우·맥에서의 설치, 데스크톱 앱 Code 탭에서 직접 쓰기. Code 탭은 공식 문서로 «명령줄 클로드 코드와 같은 설정 파일(~/.claude.json)의 MCP 서버를 쓴다»는 것만 확인했습니다.
핵심 원리
한글 MCP는 읽기에는 편하고 안전한 편이지만, 고치기는 원본을 망가뜨릴 수 있습니다. 고칠 때는 언제나 hwpx 사본에서, 원본과 다른 새 이름으로 저장하게 하고, 바꾼 개수를 대조한 뒤 한글에서 직접 열어 확인합니다.
