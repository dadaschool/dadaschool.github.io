주의
디자인 시스템은 Pro·Max·Ultra·Team·Enterprise 의 베타 기능입니다. 무료 플랜은 클로드 디자인은 되지만 디자인 시스템이 없으니 색·글꼴을 프롬프트에 직접 적습니다(문제 해결 참고). Enterprise 는 소유자가 디자인 시스템을 켜야 합니다. 기관 계정에서 클로드 디자인이 꺼져 있으면 12차시 학습지 스킬이나 4차시처럼 코워크로 Word·한글 활동지를 만듭니다 · 학생 개인정보 넣지 않기 · 교표 사용은 학교 규정 확인

지금까지 활동지는 코워크로 Word·한글 파일을 만들거나(4·12차시) Code 탭으로 웹페이지를 만들었습니다. 이번에는 보기 좋게 꾸민 한 장을 만드는 클로드 디자인을 씁니다. Claude 도움말에 따르면 클로드 디자인은 대화로 디자인·프로토타입·원페이저 같은 시각 자료를 만드는 도구로, 결과가 대화 옆 캔버스에 나타나고 대화·댓글·직접 편집으로 다듬습니다. 핵심은 둘입니다. 색과 글꼴을 매번 말하지 말고 디자인 시스템으로 한 번 정해 두는 것, 그리고 고칠 곳은 캔버스에서 그 자리를 눌러 콕 집어 말하는 것입니다.

영상마다 찍은 시기가 달라 메뉴 위치가 이 차시와 다를 수 있습니다. 예전의 독립 화면(claude.ai/design)은 2026년 12월 14일에 닫히고, 그 뒤로는 대화와 아티팩트 탭에서 씁니다.

클로드 디자인 한눈에

  • 여는 곳 — 대화에서 «활동지를 디자인해 줘»처럼 부탁하거나, 메시지 상자의 출력(Output) → 디자인(Design) 을 고릅니다. 사이드바 아티팩트(Artifacts) 탭에서 Design 템플릿으로 시작할 수도 있고, Code 탭에서는 /design 으로 부릅니다. 따로 설치하지 않습니다.
  • 넣을 수 있는 것 — 프롬프트, 그림·스크린샷, 본뜨고 싶은 발표자료나 문서. 디자인 시스템은 올린 파일·로고·글꼴·발표자료에서 만들 수 있습니다.
  • 고치는 법 — 전체를 바꾸는 일은 대화로, 한 곳은 캔버스를 눌러 댓글로, 위치·크기는 캔버스에서 직접 끌어 옮깁니다.
  • 내보내기 — 오른쪽 위 내보내기(Export): zip, PDF, PPTX, Google Slides, 단독 HTML, Canva 같은 다른 도구로 보내기, Claude Code 로 넘기기.
  • 사용량 — 따로 정해진 몫 없이 채팅·코워크·Code 와 같은 사용 한도에서 씁니다. 고치는 횟수가 많을수록 많이 씁니다.
  • 아직 안 되는 것 — 버전 기록이 없고, 여럿이 동시에 고치는 것은 아직 불안정하다고 도움말이 밝힙니다.

1 준비

  1. 설정 → Capabilities 에서 «Cloud code execution and file creation»(새 설정 화면 «Create and edit files»)이 켜져 있는지 봅니다. Team·Enterprise 계정에서 이 항목이 없거나 바꿀 수 없으면 기관 관리자에게 묻습니다.
  2. 같은 화면에 Design systems 항목이 있는지 봅니다(없으면 설정 → Design systems). 둘 다 없으면 무료 플랜이거나 기관에서 꺼 둔 것이므로, 아래 «문제 해결»의 첫 항목대로 합니다.
  3. 학교 교표 그림(학교 누리집에 공개된 PNG 등)과 상징색 값을 준비합니다. 없으면 이 차시의 예시 색을 그대로 쓰고, 학교 문서 견본 대신 디자인시스템_견본.pdf 를 받아 둡니다.

핵심 원리
디자인 시스템은 «매번 하던 꾸미기 설명»을 한 번 정해 둔 것입니다. 12차시 스킬이 학습지의 양식을 굳혔다면, 디자인 시스템은 색·글꼴·모양을 굳힙니다. 그래서 활동지를 부탁할 때는 내용만 말합니다. 고칠 때는 큰 변화는 대화로, 한 곳은 댓글로, 작은 위치는 직접 고칩니다. 그리고 «예쁘게»보다 «인쇄했을 때 읽히게»가 먼저입니다 — 흑백, 글자 크기, 쓰기 칸. 내용이 맞는지는 끝까지 교사가 봅니다.
문제 해결
· 디자인 시스템 메뉴가 없다 — 무료 플랜에는 디자인 시스템이 없습니다. 프롬프트 1의 «색»부터 «규칙»까지를 복사해 프롬프트 3의 첫 줄 대신 붙여 넣으면 같은 모양을 부탁할 수 있습니다(다음에도 매번 붙여 넣어야 함). Enterprise 는 소유자가 조직 설정 → 아티팩트에서 «디자인 시스템»을 켜야 합니다.
· 출력(Output)에 디자인이 없다 / 아티팩트 탭이 없다 — 설정 → Capabilities 의 «Cloud code execution and file creation»이 켜져 있는지 봅니다. 기관 계정은 관리자가 Design 템플릿을 꺼 두었을 수 있습니다. 그때는 12차시나 4차시 방법으로 코워크에서 문서 활동지를 만듭니다.
· 색·글꼴이 디자인 시스템과 다르게 나온다 — 4단계에서 디자인 시스템을 골랐는지 봅니다. «'○○중 수업자료' 디자인 시스템의 색 값·글꼴과 다른 곳을 찾아 고쳐 주세요»라고 부탁합니다.
· 댓글이 반영되지 않는다 — 도움말이 밝힌 알려진 문제입니다. 같은 내용을 대화창에 붙여 넣습니다. 캔버스에 댓글이 안 보이면 댓글 보기에서 찾습니다.
· «chat upstream error» 가 뜬다 — 도움말은 같은 프로젝트에서 새 채팅 탭을 열어 다시 해 보라고 안내합니다.
· 사용 한도에 닿았다 — 한도가 초기화될 때까지 클로드 디자인을 쓸 수 없습니다. 고칠 점을 하나씩 보내지 말고 여러 개를 묶어 한 번에 말하면 덜 씁니다.
· 지도가 어색하다 — «대륙은 빼고 위선·경선 격자와 점만 남겨 주세요»라고 단순하게 바꾸거나, 저작권을 확인한 지도 그림을 올려 그 위에 점을 찍게 합니다.
· 예전 독립 화면(claude.ai/design)에서 만든 디자인 시스템이 있다 — 2026년 12월 14일에 닫히기 전에 옮깁니다. 사이드바 아래 Design 탭의 배너에서 «Move team design systems» 를 누르면 대화에서 쓸 수 있는 아티팩트가 됩니다.
