듣고, 따라 말하고, 글로도 연습하는 생활영어 트레이너

최신 판을 확인하는 중…

어떤 앱인가요?

여행 · 일상 생활 · 사교 · 직장 · 학교 · 문화생활의 61개 상황을 초급 · 중급 · 고급 대화 183개로 연습해요. 대화마다 원어민 음성과 한국어 뜻 음성이 들어 있어요.

🎤 말하기집에서 — 따라 말하고, 음성 인식으로 확인해요
💬 채팅버스 · 사무실에서 — 말 대신 글로 연습해요
🎧 듣기걸으며 — 화면을 꺼도 이어서 들어요

기본 연습은 인터넷 없이도 되고 돈이 들지 않아요. 학습 기록은 휴대폰 안에만 저장돼요.

🤖 AI 자유대화 (고르면 쓰는 기능) — 큐웬 · 업스테이지 · 제미나이 · 오픈AI 중 한 곳의 키를 설정 → 🤖 AI 에 넣으면, AI 가 상대 역할을 맡아 대화하고 끝난 뒤 내 문장을 고쳐 줘요. 고친 대화는 카드 · «내가 만든 상황» 으로 저장해 연습해요.

📥 자료로 학습 만들기 — 공부하고 싶은 글을 붙여넣거나, 워드(DOCX) · 한글(HWPX) 파일 · 메뉴판 같은 사진을 넣으면 AI 가 대화 · 카드 · 퀴즈로 만들어 줘요. 다른 앱에서 [공유] → Daily Talk 로 글을 보낼 수도 있어요.

AI 요금은 키를 만든 회사에서 각자 내요(쓴 만큼). 회사 콘솔에서 월 사용 한도를 꼭 걸어 두세요. 키는 휴대폰 안에만 저장되고 백업 파일에도 들어가지 않아요.

휴대폰에 설치하기

안드로이드 (크롬)

  1. 크롬으로 앱 주소를 엽니다.
  2. 처음 안내에서 공부할 영역과 수준을 고릅니다.
  3. 크롬 메뉴(⋮) → «앱 설치» 또는 «홈 화면에 추가» 를 누릅니다.
  4. 홈 화면의 Daily Talk 아이콘으로 엽니다. 아이콘을 길게 누르면 «대화 듣기» 로 바로 갈 수 있어요.

아이폰 (사파리)

  1. 사파리로 앱 주소를 엽니다.
  2. 아래 공유 단추(□↑) → «홈 화면에 추가».

아이폰은 음성 인식이 잘 안 될 수 있어요. 그럴 땐 💬 채팅 모드로 연습하세요.

앱 열기

새 판은 앱 안에서 받아요

고쳐진 새 판이 나오면 앱을 지우고 다시 설치할 필요가 없어요.

  1. 앱의 설정(⚙ — 새 판이 있으면 빨간 점이 찍혀요) → 맨 아래 ⬆ 업그레이드
  2. [🔎 새 판이 있는지 확인] → [⬆ 지금 받기] → [🔄 새 판으로 다시 시작]

학습 기록 · 카드 · 오답노트는 그대로 남아요. 받기 전에 휴대폰 안에 자동으로 백업하고, 바로 이전 판으로 되돌릴 수도 있어요. 연습하는 중에 저절로 바뀌지 않아요 — «다시 시작» 을 눌러야 바뀌어요.

인터넷으로 못 받을 때 — 업그레이드 꾸러미

아래 꾸러미(zip)를 받아 두었다가, 앱의 설정 → ⬆ 업그레이드 → [📁 파일로 업그레이드] 로 고르세요. 꾸러미 안의 파일을 하나하나 확인한 뒤 설치해요.
