이렇게 사용해요

AI와 대화하기 (교사·학생) — 브라우저에서 AI 채팅 주소에 접속해 로그인하고 Qwen과 대화합니다. 로그인 방법은 담당자가 안내합니다. 설치는 4단계와 5단계입니다.
노트북에서 코드를 쓰고 GPU 학습 맡기기 (학생) — 팀 계정으로 학습 노트북에 접속해 코드를 쓰고, 학습 작업을 GPU 작업 큐에 제출합니다. 학생이 GPU를 직접 잡지 않고 서버가 순서대로 한 번에 하나씩 실행합니다. 설치는 10단계와 11단계입니다.
학습한 모델 호출하기 (학생·교사) — 학습이 끝나면 모델이 자동으로 서빙 게이트웨이에 등록되고, 팀 주소로 요청을 보내 이미지를 받습니다. 설치는 12~14단계입니다.
웹앱 올리기 (해커톤 학생) — 팀 저장소에 git push를 하면 자동으로 빌드·배포되어 팀 주소에서 바로 열립니다. 설치는 6~8단계이며, 해커톤을 하지 않는 학기에는 건너뛰어도 됩니다.

알아 두기

  • GPU가 한 개라서 학습은 한 번에 1팀씩 진행됩니다. 이미지 생성도 한 번에 하나의 요청씩 처리되며, 1장은 보통 수 초~수십 초 걸려서 여러 명이 짧게 기다렸다가 순서대로 받는 정도로 체감됩니다.
  • 채팅 모델은 VRAM 32GB에 여러 개를 동시에 올리면 빠듯합니다. 평소에는 범용 모델 하나만 쓰고, 해커톤 당일에는 코딩 모델로 바꿔 쓰기를 권장합니다.

1Windows 기본 설정

1-1. Windows Update

  1. 설정 → Windows Update → 업데이트 확인 → 전부 설치 후 재부팅

1-2. 절전 모드 끄기

  1. 설정 → 시스템 → 전원 및 절전 → '화면', '절전' 모두 '안 함'으로 변경
  2. 설정 → 시스템 → 전원 → 전원 모드를 '최고의 성능'으로 변경

1-3. 고정 IP 설정

관리자 권한 PowerShell에서:

PowerShell (관리자 권한)
ipconfig /all

'IPv4 주소', '서브넷 마스크', '기본 게이트웨이', 'DNS 서버'를 메모한 뒤:

  1. 설정 → 네트워크 및 인터넷 → 이더넷 → IP 할당 '편집' → '수동'
  2. 메모한 값과 같은 정보를 입력하되, IP 마지막 자리는 전산 담당자가 확인해준 미사용 번호로 설정 (예: 192.168.10.50)
  3. 저장 후 재부팅, ipconfig로 IP 유지 확인
주의 — 서버IP란?이후 문서에서 "[서버IP]"는 이 고정 IP를 뜻합니다. 고정 IP로 쓸 번호는 반드시 전산 담당자에게 확인받으세요.

3NVIDIA 드라이버

Docker 컨테이너와, 뒤에서 설치할 Python 서비스들이 GPU를 쓰려면 드라이버와 연동 패키지가 필요합니다.

3-1. NVIDIA 드라이버 설치

  1. nvidia.com/drivers 접속 → RTX 5090용 최신 드라이버(Game Ready 또는 Studio) 다운로드·설치
  2. 설치 후 재부팅
  3. 확인:
PowerShell
nvidia-smi

GPU 이름과 드라이버 버전이 출력되면 성공.

3-2. NVIDIA Container Toolkit (Docker가 GPU를 인식하게 함)

Docker Desktop의 WSL2 백엔드는 최신 버전에서 GPU 지원이 내장되어 있습니다. 아래로 확인:

PowerShell
docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi

컨테이너 안에서도 GPU 정보가 출력되면 성공입니다. 출력되지 않으면 Docker Desktop을 최신 버전으로 업데이트한 뒤 재시도하세요.

import os, uuid, threading, queue, subprocess, time, json
from fastapi import FastAPI, UploadFile, File, Form
from fastapi.responses import JSONResponse
import uvicorn

JOBS_DIR = r"C:\server\gpu-queue\jobs"
os.makedirs(JOBS_DIR, exist_ok=True)

app = FastAPI()
job_queue = queue.Queue()
jobs = {}  # job_id -> {"status": ..., "log": ..., "team": ...}
lock = threading.Lock()

def worker_loop():
    while True:
        job_id = job_queue.get()
        with lock:
            jobs[job_id]["status"] = "running"
        job_dir = os.path.join(JOBS_DIR, job_id)
        log_path = os.path.join(job_dir, "log.txt")
        try:
            with open(log_path, "w", encoding="utf-8") as logf:
                proc = subprocess.run(
                    ["docker", "run", "--rm", "--gpus", "all",
                     "-v", f"{job_dir}:/workspace",
                     "gpu-trainer:latest",
                     "python", "/workspace/train.py"],
                    stdout=logf, stderr=subprocess.STDOUT, timeout=3600
                )
            with lock:
                jobs[job_id]["status"] = "done" if proc.returncode == 0 else "failed"
        except Exception as e:
            with lock:
                jobs[job_id]["status"] = "failed"
            with open(log_path, "a", encoding="utf-8") as logf:
                logf.write(f"\n[오류] {e}\n")
        job_queue.task_done()

threading.Thread(target=worker_loop, daemon=True).start()

@app.post("/submit")
async def submit(team: str = Form(...), train_script: UploadFile = File(...)):
    job_id = str(uuid.uuid4())[:8]
    job_dir = os.path.join(JOBS_DIR, job_id)
    os.makedirs(job_dir, exist_ok=True)
    content = await train_script.read()
    with open(os.path.join(job_dir, "train.py"), "wb") as f:
        f.write(content)
    with lock:
        jobs[job_id] = {"status": "queued", "team": team}
    job_queue.put(job_id)
    return {"job_id": job_id, "status": "queued", "queue_position": job_queue.qsize()}

@app.get("/status")
def status():
    with lock:
        return jobs

@app.get("/jobs/{job_id}")
def job_status(job_id: str):
    with lock:
        info = jobs.get(job_id)
    if not info:
        return JSONResponse({"error": "no such job"}, status_code=404)
    log_path = os.path.join(JOBS_DIR, job_id, "log.txt")
    log = ""
    if os.path.exists(log_path):
        with open(log_path, "r", encoding="utf-8", errors="ignore") as f:
            log = f.read()[-4000:]
    return {**info, "log_tail": log}

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=9000)

@app.post("/models/{team}/upload")
async def upload_model(team: str, file: UploadFile = File(...)):
    team_dir = os.path.join(MODELS_DIR, team)
    os.makedirs(team_dir, exist_ok=True)
    content = await file.read()
    with open(os.path.join(team_dir, "lora.safetensors"), "wb") as f:
        f.write(content)
    return {"status": "uploaded", "team": team}

class GenerateRequest(BaseModel):
    prompt: str
    steps: int = 25

@app.post("/{team}/generate")
def generate(team: str, req: GenerateRequest):
    global current_lora_team
    lora_path = os.path.join(MODELS_DIR, team, "lora.safetensors")
    if not os.path.exists(lora_path):
        return JSONResponse({"error": f"{team} 모델이 아직 업로드되지 않았습니다."}, status_code=404)

    with gpu_lock:  # GPU는 한 번에 1개 요청만 처리 (단일 GPU 제약)
        if current_lora_team != team:
            pipe.unload_lora_weights()
            pipe.load_lora_weights(lora_path)
            current_lora_team = team
        image = pipe(req.prompt, num_inference_steps=req.steps).images[0]

    buf = io.BytesIO()
    image.save(buf, format="PNG")
    buf.seek(0)
    return StreamingResponse(buf, media_type="image/png")

@app.get("/status")
def status():
    return {"current_loaded_team": current_lora_team,
            "available_teams": os.listdir(MODELS_DIR)}
