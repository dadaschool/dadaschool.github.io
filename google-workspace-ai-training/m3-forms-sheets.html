설문·데이터

수합·채점·집계를 한 번 만들어 두고 해마다 복사해서 씁니다

수합·집계 업무는 한 번 만들어 두면 다음 학기에 사본 만들기로 그대로 다시 쓸 수 있습니다. 이 모듈에서 AI는 주로 문항 초안과 Sheets 수식을 만듭니다. 수식은 AI가 틀리기 쉬운 부분이므로 반드시 가상 데이터로 실행해 보고 씁니다.
흐름: ① Forms로 받는다 → ② Sheets로 모은다 → ③ AI가 준 수식으로 표시한다 → ④ 가상 데이터로 결과를 확인한다.

시작하기 전에

  • 연수연습 폴더
  • 가상 샘플 데이터 — Sheets에서 파일 → 가져오기 → 업로드로 엽니다.
    • 사례 4: quiz-accuracy.csv
    • 사례 5: student-roster.csv, consent-responses.csv
    • 사례 6: afterschool-applications.csv, afterschool-capacity.csv
    • 사례 7: submission-status.csv
이 페이지의 수식과 코드 표시 — 모든 수식·코드에는 "예시 — 실행 전 확인" 표시를 달았습니다. 수식의 계산 논리는 위 가상 데이터로 미리 따져 보았지만, 실제 학교 계정의 Sheets에서 실행해 검증한 것은 아닙니다. 내 시트 이름·열 위치에 맞게 바꾼 뒤 가상 데이터로 먼저 실행해 보세요.

준비물
단원 수업자료(본인이 만든 Docs·PDF), 오답 분석용 samples/quiz-accuracy.csv
🔍 Forms의 "Help me create"(Gemini로 양식 만들기) — 2026-10-14 확인
  • 프롬프트나 Drive 파일(Docs·Sheets·Slides·PDF)을 근거로 설문·퀴즈 초안을 만들고, 퀴즈는 정답과 배점까지 표시합니다.
  • 여러 섹션 양식 만들기와 기존 양식 편집은 지원하지 않습니다. 컴퓨터(웹)에서만 됩니다.
  • 한국어는 2025-11 언어 확대 때 포함되었습니다.
  • 2026-04 안내 기준 교육 쪽 대상은 Education Plus, Teaching & Learning, Google AI Pro for Education입니다(2026-07 퀴즈 만들기 안내도 같음). 기본 계정(Education Fundamentals)에는 없으므로 이 연수는 방법 A(Classroom Gemini → Forms 내보내기)로 진행합니다.

🤖 방법 A · Classroom Gemini로 퀴즈 만들고 Forms로 내보내기 추천 ✅ 기본 계정

  1. classroom.google.com 왼쪽 메뉴에서 Gemini를 누르고, 교사용 도구 중 퀴즈(문항 만들기) 도구를 고릅니다. 도구 이름은 화면 문구를 따릅니다.
  2. 학년·교과·주제를 고르고, 아래 요청 예시의 조건(문항 수, 정답·해설, 오개념 보기)을 입력합니다. 수업 자료를 근거로 하고 싶으면 글이나 Drive 파일로 문항을 만드는 도구를 고르고 단원 자료를 지정합니다.
  3. 결과를 읽고 고친 뒤 Google Forms로 내보내기를 누릅니다.
  4. 내보낸 양식의 설정에서 퀴즈로 만들기가 켜져 있는지 봅니다. 문항마다 답안을 눌러 정답·배점(20점)이 맞게 지정되었는지 확인하고, 비어 있으면 직접 지정합니다. 해설은 답변 의견 추가에 넣습니다.
  5. 응답 탭에서 Sheets에 연결을 눌러 응답 스프레드시트를 만듭니다.

Classroom Gemini에서 퀴즈 초안을 만들고 Forms로 내보내는 기능은 구글이 Classroom의 추가 비용 없는 AI 도구로 안내했습니다(2025). 정답·배점이 Forms에 그대로 넘어오는지는 공식 문서로 확인하지 못했으니 4단계에서 꼭 확인합니다. Classroom Gemini 탭이 막혀 있으면 방법 B로 합니다.

요청 예시 · 형성평가 (Classroom Gemini·Gemini 앱 공통)
중학교 2학년 정보 교과 '알고리즘' 단원 형성평가를 만들어 주세요.
- 객관식 4문항(4지선다), 단답형 1문항
- 각 문항에 정답과 해설 한 줄
- 성취기준 수준에 맞게, 학생 오개념(순서도 방향, 조건 비교 오류)을 유도하는 오답 보기를 포함
- 점수는 문항당 20점

⬆️ 참고 · Forms 안 Gemini로 만들기 ⬆️ 상위 에디션

Education Plus·Teaching & Learning·Google AI Pro for Education 학교에서만 보입니다. 기본 계정이면 건너뜁니다.

  1. 새 양식을 만들고 Gemini로 만들기("Help me create a form" 계열) 버튼을 누릅니다.
  2. 아래 요청 예시를 입력합니다. 단원 자료 Docs·PDF를 근거 파일로 지정할 수 있습니다.
  3. 미리보기에서 문항·정답·배점을 고친 뒤 양식에 넣습니다. 요청은 방법 A의 요청 예시를 그대로 씁니다.
  4. 설정 탭에서 퀴즈로 만들기가 켜져 있는지, 점수 공개 시점(제출 직후/검토 후)을 확인합니다.
  5. 응답 탭에서 Sheets에 연결을 눌러 응답 스프레드시트를 만듭니다.

⌨️ 방법 B · Gemini 앱에서 문항을 만든 뒤 Forms에 직접 입력

  1. 위 요청 예시를 Gemini 앱에 넣어 문항·정답·해설을 받습니다.
  2. 새 양식 → 설정 → 퀴즈로 만들기를 켭니다.
  3. 문항을 하나씩 붙여넣고, 각 문항 아래 답안을 눌러 정답과 배점(20점)을 지정합니다. 해설은 답변 의견 추가에 넣습니다.
  4. 응답 → Sheets에 연결을 누릅니다.

🔁 방법 C · 문항이 많을 때 (AI가 코드 작성)

  1. Gemini 앱에 아래 요청을 넣어 퀴즈 양식을 만드는 Apps Script를 받습니다.
  2. 새 스프레드시트에서 확장 프로그램 → Apps Script를 열고 붙여넣어 실행합니다.
  3. 실행 기록에 출력된 양식 주소를 열어 문항·정답·배점을 확인합니다.

✅ 확인 포인트 테스트로 한 번 제출하면 점수가 자동으로 표시되고, 연결한 응답 시트에 새 행이 생기면 성공입니다.
🧪 AI 결과 검수
  • 정답이 틀리게 지정된 문항이 없는지 교사가 직접 풀어 봅니다. 특히 "옳지 않은 것은?" 문항의 정답 지정이 뒤집히는 경우가 있습니다.

⚠️ 주의 오답 분석에 학생 이름·이메일이 든 응답 시트를 통째로 AI에 넣지 않습니다. 문항별 정답률처럼 집계된 숫자만 넣습니다. 🔍 Help me create는 여러 섹션 양식과 기존 양식 편집을 지원하지 않으니, 섹션이 필요하면 초안을 받은 뒤 직접 나눕니다.

5 사례 5. 가정통신문 회신·동의서 수합 (미제출자 확인)

이런 때 씁니다
체험학습·개인정보 수집 동의서, 가정통신문 확인 회신을 받고 미제출자만 다시 안내할 때
쓰는 도구
FormsSheetsGemini 앱✅ 모든 교육 에디션
준비물
samples/student-roster.csv(가명 명단 25명), samples/consent-responses.csv(가상 응답 23건)

🤖 방법 A · AI에게 시키기 추천

  1. Gemini 앱으로 가정통신문 초안과 동의서 양식 문항을 받습니다(프롬프트 모음의 학부모 소통 참고).
  2. Forms를 만듭니다: 제목, 동의 문항(객관식), 학생 번호(단답형, 숫자 검증), 보호자 확인 문항.
  3. 연습: 새 스프레드시트에 시트 두 개를 만들고 이름을 명단, 설문 응답으로 바꾼 뒤 각각 CSV를 가져옵니다. 실제로는 Forms의 응답 시트가 설문 응답 자리에 옵니다.
  4. 아래 요청으로 수식을 받아 명단 시트 C열에 넣고 아래로 채웁니다.
  5. 데이터 → 필터 만들기로 C열에서 미제출만 남겨 개별 안내합니다.
요청 예시 · 미제출 표시 수식
Sheets '명단' 시트에 A열: 학생 번호, B열: 학생 이름이 있습니다.
'설문 응답' 시트의 C열에 응답한 학생 번호가 들어옵니다.
명단의 C열에 제출 여부("제출"/"미제출")를 표시하는 수식을 알려 주세요.
그리고 미제출만 보여 주는 필터 방법도 알려 주세요.
예시 — 실행 전 확인 · 명단!C2에 넣고 아래로 채우기
=IF(COUNTIF('설문 응답'!C:C, A2)>0, "제출", "미제출")

시트 이름은 실제 이름으로 바꿔야 합니다. 시트 이름에 띄어쓰기가 있으면 작은따옴표로 감쌉니다. 가상 데이터로 실행하면 4, 9, 17, 22번이 미제출로 나와야 합니다.

중복 제출·번호 오타 잡기 (조건부 서식)

응답 시트에 수식 열을 추가하면 새 응답이 들어올 때 수식이 따라 채워지지 않을 수 있습니다. 그래서 조건부 서식으로 표시합니다. 설문 응답 시트에서 C2:C를 선택하고 서식 → 조건부 서식 → 맞춤 수식에 넣습니다.

예시 — 실행 전 확인 · 중복 제출(노랑)
=COUNTIF($C$2:$C, $C2)>1
예시 — 실행 전 확인 · 명단에 없는 번호(빨강)
=AND($C2<>"", COUNTIF(INDIRECT("명단!A:A"), $C2)=0)

조건부 서식의 맞춤 수식은 다른 시트를 바로 참조하지 못해 INDIRECT로 감쌉니다. 가상 데이터에서는 12번(중복)과 52번(명단에 없음)이 표시되어야 합니다.

⌨️ 방법 B · 직접 하기

  1. 응답 시트를 학생 번호 순으로 정렬하고, 명단과 나란히 놓고 눈으로 대조합니다.
  2. 대조한 결과를 명단 옆 칸에 직접 적습니다. 학급 단위에서는 가능하지만 학년 단위에서는 실수가 늘어납니다.
✅ 확인 포인트 명단 옆 C열에 제출/미제출이 표시되고, 필터로 미제출 4명만 남으면 성공입니다.
🧪 AI 결과 검수
  • 학생 번호 중복 제출, 번호 오타를 잡아내는지 샘플 데이터(12번 중복, 52번 오타)로 확인합니다.
  • 응답 시트의 학생 번호가 숫자인지 텍스트인지에 따라 COUNTIF가 못 찾는 경우가 있습니다. 양식의 학생 번호 문항에 응답 확인 → 숫자를 걸어 둡니다.
  • AI가 한국어 화면과 다른 영어 메뉴 이름으로 설명하면 화면의 실제 메뉴를 찾아 대응시킵니다.
⚠️ 주의
  • 학부모는 구글 계정이 없는 경우가 많습니다. 설정 → 응답에서 로그인이 필요한 옵션(예: 응답 1회로 제한, 이메일 수집 중 로그인 방식)을 켜면 응답이 막힐 수 있습니다. 학생 번호를 입력받는 방식으로 설계합니다.
  • 응답 시트는 담당 교사만 볼 수 있게 공유합니다(사례 1의 제한됨).
  • 법적 동의가 필요한 사안은 학교 방침(서면·정식 시스템)을 먼저 확인합니다. 구글 양식 응답을 NEIS 등 공식 절차의 대체로 쓰지 않습니다.
변형 아이디어

  • 학부모 상담 희망 조사
  • 학급 물품 신청
  • 수련활동 참가 조사
  • 가정통신문 확인 회신(읽음 확인)

🔍 Forms의 응답 수 제한 (2026-10-14 확인) Forms에는 2026-01부터 양식 전체를 날짜·시간이나 응답 수에 따라 자동으로 닫는 설정이 있습니다(게시 후 응답 받기의 마감일·응답 수 한도 설정). 같은 순간에 여러 명이 제출하면 한도를 넘어 받을 수 있다고 안내되어 있습니다. 선택지(프로그램)별 정원 제한 기능은 구글 공식 도움말에서 확인되지 않았습니다. 이 기능을 주는 Marketplace 부가기능이 있지만 학교 관리자가 설치를 막았을 수 있습니다. 그래서 이 사례는 시트에서 정원을 계산합니다.

🤖 방법 A · AI에게 시키기 추천

  1. 프로그램 목록·정원을 가상 데이터로 준비합니다(위 준비물).
  2. Forms에 학생 번호(단답형)와 프로그램 선택(객관식) 문항을 만듭니다.
  3. 응답 시트를 그대로 쓰지 말고, 응답을 복사해 둔 작업 시트를 만듭니다. 연습: 새 스프레드시트에 신청 시트를 만들어 신청 CSV를 가져오고, D1:E6에 정원 CSV를 붙여넣습니다.
  4. A열(타임스탬프) 기준 오름차순 정렬(데이터 → 범위 정렬) 후, AI에게 받은 수식으로 순번과 대기 여부를 표시합니다.
요청 예시 · 정원 수식
Sheets에서 A열 타임스탬프, B열 학생 번호, C열 신청 프로그램입니다.
별도 표에 프로그램별 정원(D2:E6)이 있습니다.
각 신청 행에 같은 프로그램의 신청 순번을 계산하고, 정원을 넘으면 "대기"로 표시하는 수식을 알려 주세요.
같은 학생이 두 번 신청하면 첫 신청만 인정하고 나중 신청은 순번에서 빼 주세요.
예시 — 실행 전 확인 · F2, G2, H2에 넣고 아래로 채우기
F2 (중복 확인)  =IF(COUNTIF($B$2:B2, B2)>1, "중복", "첫 신청")
G2 (순번)       =IF(F2="중복", "", COUNTIFS($C$2:C2, C2, $F$2:F2, "첫 신청"))
H2 (결과)       =IF(F2="중복", "제외", IF(G2>VLOOKUP(C2, $D$2:$E$6, 2, FALSE), "대기", "확정"))

각 줄의 =부터 끝까지를 해당 칸에 넣습니다. 가상 데이터로 실행하면 코딩 대기 5건, 보드게임 대기 2건, 중복 제외 2건이 나와야 합니다.

⌨️ 방법 B · 직접 하기

  1. 타임스탬프 순으로 정렬한 뒤 데이터 → 필터 만들기로 프로그램별로 걸러 봅니다.
  2. 정원 수만큼 위에서부터 세어 확정 표시를 하고, 나머지는 대기로 적습니다.

🔁 방법 C · 정원이 차면 선택지를 자동으로 막아야 할 때 (AI가 코드 작성)

  1. Gemini 앱에 "Forms 응답이 들어올 때마다 프로그램별 신청 수를 세어 정원이 찬 선택지를 양식에서 지우는 Apps Script를 한국어 주석과 함께 만들어 줘. 정원 표는 시트 D2:E6에 있어."라고 요청합니다.
  2. 강사가 연수 전 가상 양식에서 실행해 검증한 뒤 씁니다. 동시 제출 시 정원을 넘을 수 있다는 한계는 그대로 남습니다.
✅ 확인 포인트 정원을 넘은 신청 행의 H열이 대기로, 같은 학생의 두 번째 신청이 제외로 표시되면 성공입니다.
🧪 AI 결과 검수
  • 같은 학생의 중복 신청 처리 기준(첫 신청 우선, 마지막 신청 우선 등)을 먼저 정하고 AI 요청에 적습니다. 기준 없이 받은 수식은 중복을 그대로 셉니다.
  • 정렬하지 않은 상태에서 순번을 매기면 선착순이 틀어집니다. 수식 전에 정렬했는지 확인합니다.
  • VLOOKUP의 마지막 인수가 FALSE(정확히 일치)인지 봅니다. 빠지면 엉뚱한 정원을 가져올 수 있습니다.
⚠️ 주의 신청 결과를 학생에게 공개할 때는 학생 번호 대신 접수 번호를 쓰거나, 개인별로 안내합니다. 확정 명단 시트를 "링크가 있는 모든 사용자"로 공유하지 않습니다.
변형 아이디어
  • 동아리 가입 신청(1~3지망)
  • 학급 역할(1인 1역) 신청
  • 수업 도우미 모집
  • 체육대회 종목 신청
  • 독서 프로그램·도서관 행사 신청

7 사례 7. 과제 제출 현황 시트와 조건부 서식 (미제출 강조)

이런 때 씁니다
수행평가 제출·점수 현황을 한눈에 보고, 미제출 학생과 기준 미달 학생을 바로 찾을 때
쓰는 도구
SheetsGemini 앱문서 안 Gemini✅ Gemini 앱: 모든 교육 에디션⬆️ Sheets 안 Gemini: 기본 계정 없음
준비물
samples/submission-status.csv(번호, 가명, 1~4차 제출 여부, 총점 — 25명)

🤖 방법 A · AI에게 시키기 추천

  1. 가상 데이터 시트를 가져옵니다(A열 번호, B열 이름, C~F열 1~4차, G열 총점).
  2. Gemini 앱에 아래 요청을 넣어 조건부 서식 규칙과 수식을 받습니다.
  3. 서식 → 조건부 서식에서 규칙을 입력합니다: 미제출 칸 연한 빨강, 60점 미만 노랑.
  4. H열에 제출 횟수, I열에 학생별 제출률, 맨 아래에 전체 제출률을 넣습니다.
요청 예시 · 조건부 서식
Sheets에서 C~F열은 1~4차 제출 여부("제출"/"미제출")이고 G열은 총점(100점 만점)입니다.
- "미제출"인 칸은 연한 빨강
- G열이 60 미만이면 노랑
- 각 학생 행에 제출 횟수와 전체 제출률(%)을 구하는 수식
'서식 → 조건부 서식'에 어떻게 입력하는지 단계별로 알려 주세요.
예시 — 실행 전 확인 · 수식
H2 (제출 횟수)        =COUNTIF(C2:F2, "제출")
I2 (학생별 제출률)    =H2/4
I28 (전체 제출률)     =COUNTIF(C2:F26, "제출")/COUNTA(C2:F26)

I열은 서식 → 숫자 → 퍼센트로 바꿉니다. 가상 데이터의 전체 제출률은 86%, 60점 미만은 2, 14, 24번이어야 합니다.

예시 — 실행 전 확인 · 조건부 서식 규칙
규칙 1  범위: C2:F26   형식 규칙: 텍스트가 정확하게 일치함   값: 미제출   서식: 연한 빨강 채우기
규칙 2  범위: G2:G26   형식 규칙: 맞춤 수식                값: =$G2<60   서식: 노랑 채우기

⌨️ 방법 B · 직접 하기

  1. C2:F26을 선택하고 서식 → 조건부 서식을 엽니다.
  2. 형식 규칙에서 텍스트가 정확하게 일치함을 고르고 미제출을 입력, 서식 스타일에서 채우기 색을 고릅니다.
  3. 다른 규칙 추가로 G열 규칙도 같은 방법으로 만듭니다(형식 규칙 목록의 "미만" 계열 조건 사용 가능).

🔁 방법 C · Sheets 안 Gemini가 보일 때 ⬆️ 상위 에디션

  1. Sheets 오른쪽 위 Gemini 아이콘으로 사이드 패널을 열고, "미제출 칸을 빨갛게 표시하는 조건부 서식을 추가해 줘"라고 요청합니다.
  2. 적용된 규칙을 서식 → 조건부 서식에서 열어 범위가 맞는지 확인합니다. 2026-02 안내에서 Sheets의 Gemini는 교육 에디션에 "앞으로 몇 달 안에" 일부 제공 예정이라고만 되어 있어, 학교 계정에서 보이는지 확인이 필요합니다.
✅ 확인 포인트 미제출 칸이 빨갛게, 60점 미만 총점이 노랗게 보이고, 칸 하나를 "미제출"에서 "제출"로 바꾸면 색이 바로 사라지면 성공입니다.
🧪 AI 결과 검수
  • AI가 준 수식의 함수 이름(한국어/영어)과 구분자(, / ;)가 내 시트 설정에 맞는지 직접 입력해 확인합니다. 한국 지역 설정에서는 쉼표(,)를 씁니다.
  • 맞춤 수식에서 $G2처럼 열에만 $가 붙었는지 봅니다. $G$2로 쓰면 모든 행이 2행 기준으로 칠해집니다.
  • "제출 "처럼 뒤에 공백이 들어간 값은 정확히 일치하지 않습니다. 입력은 드롭다운(삽입 → 드롭다운)으로 통일합니다.
⚠️ 주의 실제 점수 시트는 교사만 보는 폴더에 두고, 학생에게 보여 줄 때는 본인 행만 보이게 따로 안내합니다. 시트를 통째로 AI에 넣지 않습니다.
변형 아이디어
  • 수업 태도·참여 누가기록(관찰 기호만)
  • 독서 기록 현황(권수 기준 색 표시)
  • 체력 측정 현황(기준 미달 강조)
  • 학급 청소 당번표(오늘 당번 강조)
  • 학부모 상담 진행 현황(미완료 강조)
