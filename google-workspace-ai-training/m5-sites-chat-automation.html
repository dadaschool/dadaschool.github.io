업무 효율화 — Sites·Chat·자동화

안내 페이지, 협의 정리, 응답 알림처럼 반복되는 업무를 줄입니다

이 모듈의 세 사례는 모두 공개 범위와 자동으로 나가는 정보를 다룹니다. 사이트는 누구에게 보이는지, Chat 스페이스에는 무엇을 올리는지, 자동 메일에는 무엇이 들어가는지를 먼저 정하고 AI에게 맡깁니다.
흐름: ① AI로 구성·문구·코드 초안을 받는다 → ② 공개 범위·내용을 교사가 정한다 → ③ 다른 계정이나 테스트 응답으로 확인한다.

시작하기 전에

11 사례 11. 학급·동아리 포트폴리오 Sites

이런 때 씁니다
학급 안내 페이지, 동아리 활동 기록, 학생 성장 포트폴리오를 한곳에 모을 때
쓰는 도구
SitesGemini 앱✅ 모든 교육 에디션
준비물
동아리 이름과 활동 목록(가상), 사이트에 넣을 Docs·Slides·Forms 파일 1개씩

🤖 방법 A · AI에게 시키기 추천

  1. Gemini 앱에 아래 요청으로 사이트 구성안(메뉴, 페이지별 내용)과 소개 문구를 받습니다.
  2. sites.google.com에서 새 사이트를 만들고, 오른쪽 페이지 탭에서 메뉴대로 페이지를 만듭니다.
  3. 오른쪽 삽입 탭에서 Docs·Slides·Forms를 넣습니다. 원본 파일의 공유 권한도 함께 확인합니다.
  4. 게시할 때 공개 범위를 학교 구성원 또는 특정 사용자로 제한합니다. 게시 후에는 공유 화면의 게시된 사이트 항목에서 제한됨 또는 학교 도메인을 고를 수 있습니다.
요청 예시 · 사이트 구성
중학교 정보 동아리의 활동 기록 사이트를 만들려고 합니다.
- 메뉴 구성 5개 이내
- 각 페이지에 들어갈 내용 3줄 설명
- 동아리 소개 문구(학생 눈높이, 5문장)
- 활동 기록 작성 양식(학생이 쓰는 항목 5개)

⌨️ 방법 B · 직접 하기

  1. Sites의 템플릿(예: 프로젝트, 포트폴리오 계열)에서 시작해 제목과 소개를 직접 씁니다.
  2. 활동 기록은 Docs 하나에 날짜순으로 쓰고 사이트에 삽입해, 사이트를 고치지 않아도 내용이 갱신되게 합니다.
✅ 확인 포인트 게시된 주소를 로그아웃 상태(또는 다른 브라우저·시크릿 창)에서 열었을 때 로그인 요구 화면이 나오고, 학교 계정으로 로그인하면 열리면 의도대로 제한된 것입니다.
🧪 AI 결과 검수
  • AI가 만든 소개 문구에 실제와 다른 활동·수상 내역이 섞이지 않았는지 확인합니다.
  • AI가 "누구나 볼 수 있게 공개"를 권하면, 사이트 목적에 비춰 정말 필요한지 다시 판단합니다.
  • 활동 기록 양식 항목에 학생 연락처·주소 같은 불필요한 개인정보 칸이 없는지 봅니다.
⚠️ 주의 사이트 게시 범위를 공개로 두면 학생 작품·사진이 인터넷에 노출됩니다. 검색엔진 비노출 옵션은 요청일 뿐 보장이 아니라고 구글 도움말에 안내되어 있습니다. 학생 얼굴·실명 게시 전에는 동의를 확인합니다. 사이트에 삽입한 Docs·Forms의 원본 공유 권한이 사이트보다 넓지 않은지도 봅니다.
변형 아이디어
  • 학급 시간표·공지 사이트
  • 교과 자료실(차시별 학습지)
  • 학생 e-포트폴리오(학생별 페이지는 번호로)
  • 학부모 안내 사이트(학교 도메인 밖 공개 여부 신중히)
  • 학교 행사·축제 안내

12 사례 12. 교과협의회·업무 공유 Chat 스페이스 + AI 정리

이런 때 씁니다
학년·교과 협의 뒤 결정사항과 후속 업무를 정리해 공유할 때
쓰는 도구
Chat 스페이스Gemini 앱🔍 학교 계정 Chat 사용 확인⬆️ Chat 안 Gemini: 기본 계정 없음
준비물
가상 협의회 메모 samples/meeting-memo.txt, 함께 실습할 동료 1명
🔍 확인한 범위 (2026-10-14)
  • Google Chat은 관리자 콘솔에서 조직 전체 또는 조직 단위·그룹별로 켜고 끕니다. 교육 에디션에는 학생이 대화를 만들거나 구성원을 관리하는 것을 제한하는 설정이 따로 있습니다. 학교 계정에서 chat.google.com이 열리는지 확인하세요.
  • Chat 안의 Gemini 요약(읽지 않은 대화 요약 등)은 구글 교육용 기능표에서 Google AI Pro for Education 추가 라이선스 대상으로 안내됩니다. 대부분의 학교 계정에서는 보이지 않을 수 있어, 이 사례는 Gemini 앱으로 정리합니다.

🤖 방법 A · AI에게 시키기 추천

  1. Chat에서 새 채팅 → 스페이스 만들기로 스페이스를 만듭니다. 이름 규칙(예: 2026_2학년_정보_교과협의회)을 정하고 구성원을 학교 계정으로 지정합니다. 협의 자료 폴더는 스페이스에 링크로 공유합니다.
  2. 협의 내용을 정리한 메모에서 학생 개인정보를 뺀 뒤, 아래 요청과 함께 Gemini 앱에 넣어 결정사항 / 할 일 / 담당 / 기한 표를 받습니다. 연습은 meeting-memo.txt로 합니다.
  3. 표를 확인·수정해 스페이스에 올리고, 날짜가 정해진 일은 Calendar 일정으로 만듭니다.
요청 예시 · 회의록 정리
아래는 교과협의회 메모입니다(개인정보 없음).
결정사항, 해야 할 일(담당자·기한 포함), 아직 정해지지 않은 사항으로 나누어 표로 정리해 주세요.
메모에 없는 내용은 추측하지 말고 "미정"으로 표시하세요.
[메모 붙여넣기]

⌨️ 방법 B · 직접 하기

  1. 협의 중에 Docs 표(결정사항 / 할 일 / 담당 / 기한)를 함께 열어 두고 바로 채웁니다.
  2. 협의가 끝나면 그 문서 링크를 스페이스에 올립니다.

🔁 방법 C · Chat이 막혀 있을 때

  1. Chat 대신 공유 드라이브 폴더 + Docs 협의록 + Gmail 그룹 메일로 같은 흐름을 만듭니다.
  2. 회의록 정리는 똑같이 Gemini 앱으로 합니다.
✅ 확인 포인트 스페이스에 올린 표를 동료가 보고, 담당자·기한이 메모와 같으며 메모에 없던 항목은 "미정"으로 표시되어 있으면 성공입니다. 가상 메모에서는 검토 순서, 컴퓨터실 연락 담당, 안내문 날짜, 다음 협의회 요일이 "미정"이어야 합니다.
🧪 AI 결과 검수
  • AI가 담당자·기한을 임의로 채우지 않았는지 메모와 한 줄씩 대조합니다("미정" 지시가 지켜졌는지).
  • 결정사항과 논의만 한 사항이 섞이지 않았는지 봅니다.
  • 날짜가 있으면 요일을 달력으로 확인합니다.
⚠️ 주의 스페이스에 학생 개인정보(성적, 상담 내용, 생활지도 사안)를 올리지 않습니다. 외부 사용자를 스페이스에 초대하지 않습니다.
변형 아이디어
  • 학년 업무 공지 스페이스
  • 행사 준비 스페이스(체육대회·축제)
  • 평가 계획 협의 정리
  • 담임 소통방(개인정보 없는 공지만)
  • 시험 출제·검토 일정 협의

13 사례 13. Forms 응답 시 담당자에게 알림 메일 자동 발송 (Apps Script + AI)

이런 때 씁니다
신청서가 들어올 때마다 담당 교사 메일로 알림을 받거나, 응답 요약을 메일로 받고 싶을 때
쓰는 도구
FormsApps ScriptAI가 코드 작성✅ 기본 Workspace 기능🔍 관리자 정책으로 Apps Script·메일 제한 가능
준비물
연습용 양식 1개(학생 번호, 신청 내용 문항)와 연결된 응답 스프레드시트
코딩 없이 되는 방법을 먼저 확인하세요. 알림만 필요하다면 방법 B(Forms 기본 이메일 알림)로 충분합니다. 메일 제목·본문을 바꾸거나 요약을 넣고 싶을 때 방법 A를 씁니다.

🤖 방법 A · AI에게 시키기 추천

  1. Gemini 앱에 아래 요청으로 코드를 받습니다.
  2. 양식의 응답 스프레드시트를 열고 확장 프로그램 → Apps Script에 붙여넣고 저장합니다.
  3. 왼쪽 시계 모양 트리거 → 트리거 추가에서 실행할 함수를 고르고, 이벤트 소스 스프레드시트에서, 이벤트 유형 양식 제출 시를 선택합니다(설치형 트리거). 권한 승인 화면에서 요청 권한을 읽고 승인합니다.
  4. 양식에서 테스트 응답을 한 번 제출하고 메일이 오는지 확인합니다.
  5. Gemini 앱에 "이 코드를 한 줄씩 설명해 줘"라고 요청해 이해한 뒤 씁니다.
요청 예시 · 알림 메일 코드
Google Forms 응답이 들어올 때마다 담당 교사(내 메일)에게 알림 메일을 보내는 Google Apps Script를 만들어 주세요.
- 폼에 연결된 스프레드시트에서 실행
- 메일 제목: [신청] 새 응답이 도착했습니다
- 본문: 제출 시각과 응답 항목 요약 (학생 이름은 본문에 넣지 않고 번호만)
- 설치형 트리거 설정 방법도 단계별로 알려 주세요.
- 코드 각 부분에 한국어 주석을 달아 주세요.
예시 — 실행 전 확인 · Apps Script 참고 답안
// 양식에 연결된 스프레드시트의 Apps Script에 붙여넣습니다.
// 트리거: 이벤트 소스 '스프레드시트에서', 이벤트 유형 '양식 제출 시'로 연결해야 동작합니다.
function notifyOnFormSubmit(e) {
  var to = Session.getEffectiveUser().getEmail(); // 트리거를 만든 교사 본인 메일
  var answers = e.namedValues;                      // { '질문 제목': ['응답'] }
  var lines = [];
  Object.keys(answers).forEach(function (question) {
    if (question.indexOf('이름') !== -1) return;    // '이름'이 들어간 문항은 본문에서 뺍니다
    lines.push('- ' + question + ': ' + answers[question].join(', '));
  });
  var sentAt = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm');
  var body = '제출 시각: ' + sentAt + '\n\n' + lines.join('\n') +
             '\n\n전체 내용은 응답 시트에서 확인하세요.';
  MailApp.sendEmail(to, '[신청] 새 응답이 도착했습니다', body);
}

문법 검사만 거친 예시입니다. 편집기에서 ▶ 실행을 직접 누르면 e가 없어서 오류가 나는 것이 정상이며, 실제 동작은 테스트 응답 제출로 확인합니다. 강사가 연수 전에 학교 계정에서 검증한 뒤 쓰세요.

⌨️ 방법 B · 직접 하기 (코딩 없이)

  1. 양식 편집 화면의 응답 탭에서 더보기(⋮)를 누릅니다.
  2. 새 응답에 대한 이메일 알림 받기를 켭니다. 양식 소유자·편집자 본인 메일로 알림이 옵니다.
  3. 테스트 응답을 제출해 메일이 오는지 확인합니다.
✅ 확인 포인트 테스트 응답을 제출한 직후 알림 메일이 도착하고, 본문에 학생 이름 없이 번호와 응답 요약만 있으면 성공입니다.
🧪 AI 결과 검수
  • Apps Script는 하루 메일 발송(수신자 수) 한도가 있습니다. 구글 공식 할당량 표 기준 Google Workspace 계정은 하루 1,500명 수준, 개인 계정은 100명이며, 구글은 이 값이 예고 없이 바뀔 수 있다고 밝힙니다. 대량 응답이 예상되면 응답마다 보내지 말고 하루 한 번 요약으로 바꿉니다. 남은 한도는 MailApp.getRemainingDailyQuota()로 확인합니다.
  • AI 코드가 학생 이름·전화번호 문항까지 본문에 넣지 않는지 문항 이름으로 확인합니다. 이름 문항 제목이 "성명"이면 걸러지지 않으니 코드를 고칩니다.
  • 트리거가 설치형으로 한 번만 등록되었는지 확인합니다. 두 번 등록하면 메일이 두 통씩 옵니다.
⚠️ 주의
  • 처음 실행하면 권한 승인 화면이 나옵니다. 요청 권한(메일 보내기, 스프레드시트 보기 등)을 읽어 보고 본인 계정에서만 쓰는 스크립트인지 확인합니다. 출처를 모르는 스크립트는 붙여넣지 않습니다.
  • 메일 본문에 학생 개인정보·성적을 넣지 않습니다. 학생·학부모에게 자동 메일을 보내는 기능은 학교 방침을 먼저 확인합니다.
변형 아이디어
  • 제출 확인 메일(교사 본인에게 하루 요약)
  • 상담 신청 알림
  • 특별실·시설 사용 신청 알림
  • 분실물 접수 알림
  • 학부모 문의 접수 알림
