문서·슬라이드

한 파일을 여럿이 함께 쓰고, 누가 무엇을 했는지 기록으로 확인합니다

Docs와 Slides는 여러 사람이 한 파일을 동시에 편집하고, 그 과정이 버전 기록에 남습니다. AI는 빈 화면을 채우는 틀과 개요를 만드는 데 쓰고, 내용과 평가는 학생과 교사가 맡습니다.
흐름: ① AI로 틀·개요를 받는다 → ② 공유해서 함께 쓴다 → ③ 버전 기록·댓글로 과정을 확인한다.

시작하기 전에

  • 연수연습 폴더(모듈 1에서 만든 것)
  • 모둠원 역할을 할 동료 1~2명 또는 교사의 다른 브라우저 창
  • Docs 오른쪽 위 Gemini 아이콘이 보이는지 확인(연수 전 점검 4번). 보이지 않아도 Gemini 앱으로 모두 진행할 수 있습니다.
🔍 내 Docs에 Gemini가 있나요? 문서 오른쪽 위에 Gemini 아이콘이 있으면 문서 안 Gemini(사이드 패널)를 쓸 수 있습니다. 없으면 Gemini 앱으로 같은 실습을 합니다.

제공 대상: Education Plus 또는 Teaching and Learning 라이선스, 만 18세 이상(2026-02 안내). 아이콘이 없어도 Gemini 앱의 Canvas로 만든 슬라이드는 Slides로 내보낼 수 있습니다.

🤖 방법 A · AI에게 시키기 추천

  1. 교사: Gemini 앱에 아래 요청으로 모둠 보고서 틀(목차, 역할 칸)을 받아 Docs에 붙여넣습니다. [주제]는 바꿉니다.
  2. 교사: 연수연습 안에 모둠 폴더를 만들고, 문서를 모둠원(연습에서는 동료)에게 편집자로 공유합니다.
  3. 학생(연습에서는 동료가 대신): 각자 자기 역할 칸에 작성합니다.
  4. 교사: 파일 → 버전 기록 → 버전 기록 보기를 열어, 작성자별 색으로 표시된 수정 내역을 확인합니다.
  5. 교사: 버전 기록에서 본 내용을 학생 이름 없이 학생A/B/C로 바꿔 Gemini 앱에 붙여넣고, 기여 내용 요약 정리를 맡깁니다.
요청 예시 · 보고서 틀
중학교 2학년 정보 교과 모둠 보고서 틀을 만들어 주세요.
주제: [주제]
포함: 문제 정의, 조사 내용, 해결 방법, 결과, 모둠원별 역할 표, 느낀 점
조건: 각 항목 아래 학생이 쓸 수 있도록 안내 문장 1줄씩, 중학생 수준
형식: 제목과 표가 있는 문서 초안
요청 예시 · 기여 요약 (이름 없이)
아래는 모둠 보고서의 편집 기록을 정리한 메모입니다. 학생 이름은 학생A, B, C로 바꿨습니다.
학생별로 어느 항목을 작성·수정했는지 표로 정리해 주세요.
메모에 없는 내용은 추측하지 말고, 평가나 점수는 매기지 마세요.

메모 만들기와 실습용 가상 메모

실제 문서에서는 버전 기록을 가장 오래된 버전부터 하나씩 눌러, 강조된 부분을 보고 시각 / 편집자 / 항목 / 한 일(작성·수정·삭제) / 분량을 한 줄씩 적습니다. 이름은 학생A/B/C로 바꾸고, 글 원문은 옮기지 않습니다. 연습에서는 아래 가상 메모를 위 요청 예시의 [메모 붙여넣기] 자리에 넣습니다.

가상 메모 · version-history-memo.txt 내려받기

학생B조사 내용, 결과없음
학생C해결 방법결과 (표의 숫자 1곳)
확인 불가느낀 점 (익명 사용자)—

대조할 때 볼 것: ① '느낀 점'을 학생 중 누군가에게 붙였는지(추측 금지) ② "성실함", "기여도 높음" 같은 평가어나 점수가 들어갔는지 ③ 메모에 없는 항목을 만들어 냈는지

⌨️ 방법 B · 직접 하기

  1. Docs에서 새 문서를 만들고 서식 → 단락 스타일로 항목 제목을 제목 1/제목 2로 지정합니다. 왼쪽 개요에 목차가 생깁니다.
  2. 삽입 → 표로 모둠원별 역할 표를 넣습니다.
  3. 각 항목 아래 안내 문장을 직접 적습니다.

🔁 방법 C · 문서 안 Gemini가 보일 때 ⬆️ 상위 에디션

  1. 문서 오른쪽 위 Gemini 아이콘을 눌러 사이드 패널을 엽니다.
  2. 이 문서의 항목별 안내 문장을 더 쉽게 고쳐 줘라고 요청하고, 제안을 읽어 본 뒤 필요한 부분만 넣습니다.

같이 해 볼 기능

  • 댓글: 문장을 선택하고 Ctrl+Alt+M — 교사 피드백을 남기고 학생이 해결 표시
  • 제안 모드: 오른쪽 위 연필 아이콘에서 제안으로 바꾸면 원문이 지워지지 않고 수정 제안으로 남음
  • 현재 버전 이름 지정: 파일 → 버전 기록 → 현재 버전 이름 지정(예: 중간점검_10월) — 나중에 그 시점으로 돌아가 비교
  • 스마트 칩: @를 입력해 사람·파일·날짜를 넣기 — 역할 표에 마감일 칩
✅ 확인 포인트 버전 기록 오른쪽 패널에 서로 다른 사용자 이름과 색이 표시되고, 각 버전을 누르면 그 사람이 쓴 부분이 같은 색으로 강조되면 성공입니다.
🧪 AI 결과 검수
  • 버전 기록은 편집 이력이지 노력의 양이 아닙니다. 말로 아이디어를 낸 학생, 다른 학생 기기로 함께 쓴 경우는 기록에 남지 않습니다. 기여도 평가는 버전 기록 하나만으로 하지 말고 학생 면담·자기평가와 함께 봅니다.
  • AI가 만든 틀의 항목이 수행평가 안내문의 평가 요소와 맞는지 대조합니다.
  • 기여 요약에서 AI가 메모에 없는 "적극적", "소극적" 같은 평가어를 붙였는지 확인하고 지웁니다.
⚠️ 주의 AI에 학생 이름이나 학생이 쓴 글 원문을 그대로 넣지 않습니다. 기여 요약을 맡길 때는 이름을 학생A/B/C로 바꾸고 편집 항목만 넣습니다.
변형 아이디어
  • 독서 활동 기록(한 권을 나눠 읽고 장별 요약)
  • 과학 실험 보고서(가설·과정·결과를 역할 분담)
  • 프로젝트 학습 일지(날짜별 진행 기록)
  • 진로 활동 보고서(직업 탐색 결과 공유)
  • 국어 모둠 토론 개요서(찬반 근거 정리)

3 사례 3. 모둠 발표용 공동 Slides + AI로 시각 자료 만들기

이런 때 씁니다
모둠 발표 자료를 한 파일에서 동시에 만들 때, 교사 수업 슬라이드를 빠르게 만들 때
쓰는 도구
SlidesGemini 앱(Canvas)Classroom Gemini✅ Gemini 앱·Classroom: 모든 교육 에디션⬆️ Slides 안 Gemini: 기본 계정 없음
준비물
수업 단원 이름과 핵심 개념 메모(개인정보 없음), 모둠 수(연습: 3모둠)

🤖 방법 A · AI에게 시키기 추천

  1. 먼저 아래 요청으로 개요(슬라이드 제목 목록)만 받습니다. 교사가 순서와 내용을 고칩니다.
  2. 고친 개요로 슬라이드를 만듭니다. 두 가지 길이 있습니다.
    • Classroom의 Gemini 탭: 슬라이드 덱 관련 시작 프롬프트(예: 프레젠테이션 만들기, 파일을 Google 슬라이드로 변환)를 고릅니다. 2026-06 안내 기준 이 프롬프트들은 Gemini의 Canvas 도구를 씁니다. 화면의 한국어 문구는 계정에서 확인하세요.
    • Gemini 앱: 입력창 아래 도구에서 Canvas를 고르고 "발표 자료를 만들어 줘"라고 요청한 뒤, Canvas의 공유·내보내기 메뉴에서 Slides로 내보내기를 누릅니다.
  3. 이미지가 필요하면 Classroom Gemini 탭의 인포그래픽 만들기, 만화 그리기 같은 이미지 생성 시작 프롬프트를 씁니다. 글자·수치는 반드시 직접 확인합니다.
  4. 만든 슬라이드를 모둠에 편집자로 공유하고, 모둠별로 슬라이드 번호를 나눠 맡겨 동시에 편집합니다(예: 1모둠 2~4번, 2모둠 5~7번).
요청 예시 · 수업 슬라이드 개요
중학교 2학년 정보 교과 '인공지능과 윤리' 단원 도입 수업용 슬라이드 개요를 만들어 주세요.
- 10장 이내, 장별 제목과 핵심 문장 2개
- 마지막 장은 학생 토의 질문 3개
- 쉬운 예시(교실·학교 생활)로
표가 아니라 번호 목록으로 출력해 주세요.
요청 예시 · 인포그래픽
중학교 2학년이 볼 인포그래픽을 만들어 주세요.
주제: 인공지능이 학교생활에서 쓰이는 예 4가지
조건: 글자는 한국어로 짧게(한 칸에 10자 이내), 사람 얼굴은 넣지 않음, 실제 회사 로고·상표 사용 금지

⌨️ 방법 B · 직접 하기

  1. Slides에서 새 프레젠테이션을 만들고 테마를 고릅니다.
  2. 첫 장에 모둠별 담당 슬라이드 번호 표를 넣고, 모둠 수만큼 빈 슬라이드를 미리 만들어 둡니다.
  3. 각 슬라이드 발표자 노트에 "이 장에서 말할 것"을 적게 합니다.

🔁 방법 C · Classroom Gemini 탭이나 Canvas 내보내기가 막혀 있을 때

  1. Gemini 앱에서 개요만 텍스트로 받습니다.
  2. Slides에서 제목만 있는 레이아웃 슬라이드를 개요 수만큼 만들고, 각 제목 칸에 개요를 붙여넣습니다.
  3. 이미지는 학교에서 허용한 무료 이미지나 직접 그린 도형을 씁니다.
✅ 확인 포인트 한 슬라이드 파일을 두 사람 이상이 동시에 열었을 때 오른쪽 위에 서로의 프로필 아이콘이 보이고, 각자 맡은 슬라이드에서 편집이 바로 반영되면 성공입니다.
🧪 AI 결과 검수
  • AI가 만든 통계·날짜·인용은 출처를 확인하기 전에는 쓰지 않습니다. "~에 따르면" 문장은 특히 의심합니다.
  • 생성 이미지 속 글자가 깨지거나 철자가 틀리는 경우가 많습니다. 확대해서 한 글자씩 봅니다.
  • 개요가 성취기준 범위를 넘는지(예: 고등학교 수준 알고리즘 용어) 확인합니다.
⚠️ 주의 학생 얼굴 사진·실명이 들어간 이미지를 AI 도구에 올리지 않습니다. 모둠 발표 자료에 학생 사진을 넣을 때는 학교의 초상권·개인정보 동의 방침을 먼저 확인합니다.
변형 아이디어
  • 학급 회의 안건 슬라이드(안건별 한 장)
  • 학부모 총회 학급 소개 자료
  • 동아리 활동 결과 보고 발표
  • 수업 정리 카드(차시별 핵심 한 장)
  • 사회·과학 개념 인포그래픽 갤러리 워크

잘 안 될 때

이런 증상이면이렇게 해 보세요
버전 기록에 이름이 "익명 사용자"로 나옴로그인하지 않은 상태로 편집한 경우입니다. 학교 계정 사용자에게만 편집 권한을 주고 링크 공유는 제한합니다.
버전 기록이 너무 잘게 쪼개져 보기 어려움중간점검 시점마다 현재 버전 이름 지정을 해 두면, 버전 기록 패널에서 이름이 지정된 버전만 골라 볼 수 있습니다(보기 옵션 위치는 화면에 따라 다를 수 있음).
Canvas에 Slides로 내보내기 메뉴가 없음관리자 설정 때문일 수 있습니다. 방법 C로 개요를 복사해 직접 만듭니다.
동시 편집 중 내용이 덮어써짐같은 슬라이드를 둘이 함께 고치지 않도록 슬라이드 번호를 나눠 맡기고, 실수하면 버전 기록에서 이전 버전을 복원합니다.
