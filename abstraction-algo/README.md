# 추상화와 알고리즘

중학교 정보 **Ⅲ. 알고리즘과 프로그래밍** 2차시 수업용 웹앱입니다.

👉 **https://dadaschool.github.io/abstraction-algo/**

## 무엇인가

“문제를 푼다”는 말을 학생이 **손으로 만져 보게** 만든 실험실 두 개와, 그에 맞춘 학습지입니다.
정답을 알려 주지 않습니다. **틀리면 왜 틀렸는지 화면이 직접 보여 줍니다.**

| 차시 | 실험실에서 하는 일 | 무엇을 알게 되나 |
|---|---|---|
| **1차시** | 초기·목표 상태를 정하고 **작업 순서를 짜서 분리배출 로봇을 실행**시킨다 | 문제를 정의하는 일이 곧 기계의 명령어를 쓰는 일이다 |
| | 스마트워치 화면(6칸)에 정보를 골라 올리고 **2초 테스트**로 확인한다 | 추상화는 ‘목적에 필요한 것만 남기는 일’이다 |
| **2차시** | 블록을 쌓으면 **의사코드와 순서도가 동시에** 만들어지고 응급차가 그대로 달린다 | 순차·선택·반복, 그리고 알고리즘의 5조건 |
| | 알고리즘 **A(거리)·B(시간)를 나란히 주행**시키고 모든 길을 펼쳐 본다 | ‘최적’은 기준이 정한다 · 탐욕 방법의 한계 |

## 화면

| 주소 | 내용 |
|---|---|
| `/` | 홈 — 차시 고르기 |
| `/lesson1.html` | 1차시 실험실 — 분리배출 구조화 · 스마트워치 디자이너 |
| `/worksheet1.html` | 1차시 학습지 12문항 (자동 채점 8) · PDF 제출 |
| `/lesson2.html` | 2차시 실험실 — 조감도→노선도 · 알고리즘 조립기 · 효율성 실험실 |
| `/worksheet2.html` | 2차시 학습지 17문항 (자동 채점 13) · PDF 제출 |
| `/teacher.html` | 선생님용 — 45분 운영안 · 정답/해설 · 제출물 정리 · 루브릭 |

### 학습지는 이렇게 진행됩니다

1. 학생이 문항을 작성합니다.
2. **「PDF로 저장」** → 답이 잠기고 **점수 없는 제출본** PDF 가 떨어집니다.
3. 수업 끝에 선생님이 **정답 코드**를 칠판에 적어 줍니다.
4. 코드를 넣으면 **채점 결과와 문항별 해설**이 한꺼번에 열리고, **채점본 PDF** 를 받을 수 있습니다.

정답과 해설은 이 저장소에 **암호문(AES-GCM 256)으로만** 들어 있습니다.
소스를 아무리 뒤져도 읽을 수 없고, 코드를 넣어야 열립니다 — 그래서 제출 전에 답을 볼 수 없습니다.
브라우저에 들어 있는 Web Crypto 만 쓰므로 **외부 라이브러리는 여전히 0개**입니다.

> 선생님용 화면(`/teacher.html`)의 정답표는 학생용과 **다른 코드**로 잠겨 있습니다.
> 이 저장소를 그대로 쓰실 분은 **정답 원문과 코드 생성 도구가 저장소에 없다**는 점을 알아 두세요
> (`tools/` 폴더는 일부러 올리지 않았습니다). 직접 문항을 만들어 쓰시려면 이슈로 문의해 주세요.

## 성취기준 (2022 개정 교육과정)

- **[9정03-01]** 문제의 상태를 정의하고 수행 가능한 형태로 구조화한다
- **[9정03-02]** 문제 해결을 위한 추상화의 중요성을 이해하고, 핵심요소를 중심으로 알고리즘을 표현한다
- **[9정03-03]** 알고리즘의 중요성을 이해하고, 문제를 해결하는 다양한 알고리즘을 비교·분석한다
- **[9정03-04]** 사례를 중심으로 문제 해결에 적합한 전략을 선택하여 알고리즘을 설계한다

응급차 지도는 **동아출판 정보 교과서 108쪽 「배달 로봇」** 문제의 구조를 빌려 응급차 상황으로 바꾼 것입니다.

## 개인정보

- 학년·반·학번·이름은 **PDF를 만드는 순간에만** 입력받아 **PDF 안(과 파일 이름)에만** 들어갑니다.
- 학생 페이지는 이름·학번을 기기에 저장하지 않습니다. 서버로 보내지도 않습니다.
- 선생님용 화면은 제출된 PDF의 **파일 이름만** 읽습니다. 파일 내용을 열지 않고, 어디에도 보내지 않습니다.
- `sessionStorage` 에는 **실험 진행 상태와 학습지 답안 글**만 임시로 담깁니다(탭을 닫으면 사라집니다).

## 실행

**설치할 것이 없습니다.**

| 방법 | 어떻게 |
|---|---|
| 웹 | 위 주소를 연다 |
| 더블클릭 | `index.html` 을 연다 (인터넷 없이도 모든 기능이 동작합니다) |
| 로컬 서버 | `python server.py` 또는 `로컬서버_실행.bat` → `http://localhost:8400/` |

외부 패키지·CDN·빌드 도구를 **하나도 쓰지 않습니다.** 캔버스와 SVG 그리기, 계산뿐이라 필요가 없고,
교실 PC에서 설치가 막혀 앱이 안 켜지는 사고를 피하기 위해서입니다.

## 고칠 때 알아 두면 좋은 것

- **응급차 지도의 숫자(`js/map2.js`)는 함부로 바꾸지 마세요.** 알고리즘 A·B 비교와 탐욕 방법의 한계가
  동시에 성립하도록 고른 값이라, 하나만 바꿔도 수업의 결론이 무너집니다.
- **`js/spec1.js` · `js/spec2.js` · `js/locked.js` 는 자동 생성 파일입니다.** 직접 고치지 마세요.
  원문과 생성 도구는 `tools/` 에 있고, 정답이 들어 있어 저장소에 올리지 않았습니다.
- `로컬서버_실행.bat` 은 **CP949(ANSI) + CRLF** 로 저장되어 있습니다(한국어 Windows `cmd.exe` 요구사항).
  `.gitattributes` 가 이 파일의 줄바꿈 변환을 막고 있습니다.

자세한 개발 메모는 [`CLAUDE.md`](CLAUDE.md) 에 있습니다.
