새 코드로 다시 잠그기

수업마다 정답 코드를 바꾸면 지난 반이 알려 준 코드로는 열리지 않습니다. 교사 코드는 그대로 두어도 됩니다.

바꾼 것을 반영하기

  1. 위에서 받은 locked.js 를 abstraction-algo/js/locked.js 에 덮어씁니다.
  2. 웹에 올려 둔 것도 바꾸려면 아래 두 줄을 실행합니다. 
    cd C:\project_AI\abstraction-algo
git add js/locked.js && git commit -m "정답 코드 변경" && git push
  3. 1~2분 뒤 GitHub Pages 에 반영됩니다. 새 코드를 적어 두세요.
Node 가 있다면 한 줄로도 됩니다
node tools/make-locked.js <1차시코드> <2차시코드> <교사코드>
이쪽은 문항을 고쳤을 때도 함께 반영됩니다(이 브라우저 도구는 코드만 바꿉니다).
