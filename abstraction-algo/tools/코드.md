## 코드 바꾸는 방법 — 두 가지

### ① 브라우저만으로 (권장 · Node 필요 없음)

`tools/lock-maker.html` 을 더블클릭 → 지금 교사 코드로 열기 → 새 코드 세 개 입력 →
「다시 잠그기」 → `locked.js` 내려받아 `js/locked.js` 에 덮어쓰기.

### ② 명령 한 줄 (Node 가 있을 때)

```
cd C:\project_AI\abstraction-algo
node tools/make-locked.js <1차시코드> <2차시코드> <교사코드>
```

**문항이나 해설을 고쳤을 때는 반드시 이쪽을 써야 합니다.**
`tools/spec1.src.js` · `spec2.src.js` 를 고친 뒤 이 명령을 돌리면
`js/spec1.js` · `js/spec2.js` · `js/locked.js` 가 한꺼번에 다시 만들어집니다.
(브라우저 도구는 코드만 바꾸고 문항은 건드리지 않습니다)

### 바꾼 뒤 웹에도 반영하기

```
cd C:\project_AI\abstraction-algo
git add js/locked.js && git commit -m "정답 코드 변경" && git push
```

1~2분 뒤 GitHub Pages 에 반영됩니다. **바꾼 값을 이 표에 다시 적어 두세요.**
