복잡한 세상을, 컴퓨터가 풀 수 있는 문제로

쓰레기 분리배출과 응급차 길 찾기 — 둘 다 우리 주변의 문제입니다. 이 문제를 정리하고(구조화), 꼭 필요한 것만 남기고(추상화), 순서대로 풀어내는 방법(알고리즘)을 실험실에서 직접 만들어 봅니다.

🧪 1차시 · 45분

문제를 컴퓨터의 말로

“알아서 잘 해”는 로봇이 못 알아듣습니다. 문제를 기계가 읽을 수 있게 다시 쓰는 시간입니다.

  • ♻️ 분리배출 구조화 — 초기 상태·목표 상태·수행 작업을 정하면 로봇이 그대로 실행합니다
  • ⌚ 스마트워치 디자이너 — 정보 12개 중 무엇을 남길지 고르고 픽토그램으로 바꿉니다
  • ⏱️ 2초 테스트 — 추상화가 정말 빠른지 점수로 확인합니다
