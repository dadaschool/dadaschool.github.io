1Claude Desktop 설치 및 계정 설정

이 연수는 웹 브라우저가 아니라 Claude Desktop 앱으로 진행합니다. 먼저 앱을 설치한 뒤 로그인하세요. 연수용 계정은 미리 안내된 계정을 활용합니다.

실습 순서 · ① Claude Desktop 앱 설치 (컴퓨터마다 한 번만)
  1. 웹 브라우저에서 claude.com/download 에 접속해 Windows 버전을 내려받습니다. (Windows 10 이상)
  2. 내려받은 설치 파일을 실행해 설치를 마칩니다.
  3. 시작 메뉴에서 Claude를 찾아 실행합니다.

설치가 잘 안 되면 공식 안내(영문): Claude Desktop 설치 안내

실습 순서 · ② 앱에서 로그인
  1. 앱 화면에서 안내된 이메일 주소로 로그인합니다.
  2. 가입 시 등록한 이메일로 인증 코드가 전송되면, 그 코드를 로그인 화면에 입력해 인증을 완료합니다.
  3. 로그인 후 채팅창이 보이면 준비 완료입니다. 이후 이 매뉴얼의 모든 실습은 이 앱의 채팅창에서 진행합니다.
학교 컴퓨터에서 설치가 막힐 때 — 보안 프로그램이나 관리자 권한 때문에 설치가 안 될 수 있습니다. 이 경우 정보부서(담당 선생님)에 문의하세요. 관리자 권한이 없으면 코워크(A-3) 같은 일부 기능이 제한될 수 있습니다. 앱 설치가 끝내 어렵다면 웹(claude.ai)에서 같은 계정으로 로그인해 채팅·스킬·클로드 디자인 실습을 이어갈 수 있지만, 컴퓨터 폴더를 직접 정리하는 코워크는 앱에서만 쓸 수 있습니다.
⚠️ 계정 공유 금지
Claude는 동시 접속에 민감합니다. 같은 계정에 여러 사람이 동시에 접속하면 계정이 손상되거나 로그아웃될 수 있으니, 반드시 본인 계정으로만 사용하세요. 여러 사람이 함께 쓰는 컴퓨터에서는 실습이 끝난 뒤 앱에서 반드시 로그아웃하세요.

알아두면 좋은 기본 기능

브랜치(Branch) — 대화가 엉뚱한 방향으로 흘러갈 때, 대화 중간의 특정 시점에서 새로운 갈래로 나누어 이어갈 수 있는 기능입니다. 기존 대화를 지우지 않고도 "다른 방향"을 시도해볼 수 있습니다.
프로젝트(Project) — 장기적으로 이어가는 주제(예: '2학기 생활기록부', '동아리 운영')별로 대화와 참고 파일을 한 곳에 모아 관리하는 기능입니다. 지침과 자료 파일을 미리 등록해두면 매번 설명하지 않아도 됩니다.
사용량 절약 팁 — 하나의 대화가 길어질수록 더 많은 토큰(사용량)을 소비합니다. 주제가 바뀌면 새 채팅을 시작하는 습관을 들이면 사용량을 아낄 수 있습니다.

2-3. Claude를 쓰는 세 가지 방식 — 채팅 · 코워크 · 코드

Claude Desktop 앱 하나에서 여러 방식으로 일을 시킬 수 있습니다. 가장 큰 차이는 Claude가 대화만 하는지, 내 컴퓨터의 파일을 직접 다루는지입니다.

채팅 (Chat)

질문에 답해주는 똑똑한 조수
  • 질문, 글쓰기·요약·번역, 아이디어 정리
  • 파일·이미지를 첨부해 분석
  • 스킬을 켜서 한글·PPT 같은 문서 생성
  • 내가 주고받는 대화가 중심

코워크 (Cowork)

내 컴퓨터 폴더를 열어 일을 대신하는 동료
  • 여러 단계의 일을 스스로 계획하고 실행
  • 허용한 폴더의 파일을 읽고 쓰며 정리·분석·자료 종합
  • 터미널 없이 사용 (Claude Code와 같은 에이전트 방식)

코드 (Code)

프로그램을 만들어주는 개발자용 도구
  • 프로그램 코드를 읽고 수정하고 명령을 실행
  • 터미널, VS Code 등 개발 도구, 데스크톱 앱, 웹에서 사용
  • 프로그래밍 작업을 하는 사람이 주 대상

2-4. Claude의 능력을 넓혀주는 4가지 — 스킬 · 커넥터 · MCP · 플러그인

이 넷은 서로 비슷해 보이지만 역할이 다릅니다. 핵심은 스킬은 '어떻게 할지'를 알려주고, 커넥터·MCP는 '어디에 접근할지'를 열어주며, 플러그인은 그것들을 한 상자에 묶은 것이라는 점입니다.

스킬 (Skill)

업무 매뉴얼
  • Claude에게 특정 작업의 방법과 형식을 알려주는 지침·자료 폴더
  • 관련 작업을 요청하면 Claude가 필요한 스킬만 자동으로 불러와 적용
  • 예: 워드(docx)·PPT(pptx)·PDF·한글(hwpx) 문서 만들기
  • 설치와 활용은 3장에서 다룹니다

커넥터 (Connector)

외부 서비스로 통하는 문
  • Claude가 구글 드라이브·Gmail·캘린더 같은 외부 서비스의 자료를 읽고 작업하도록 연결
  • 설정의 Connectors 메뉴나 채팅창의 + 버튼에서 켜고 끔
  • 연결할 때 해당 서비스에 로그인하고 권한을 허용해야 함

MCP

연결을 위한 공통 규격
  • Model Context Protocol의 약자로, AI가 외부 도구·데이터와 연결하는 방법을 정한 개방형 표준(Anthropic이 만듦)
  • 커넥터는 이 MCP 방식으로 만들어진 연결입니다
  • 서비스 회사가 MCP로 문을 만들어 두면 Claude가 그 문을 사용

② 실습 A · brainstorm-and-plan 스킬 설치하기 (코드 탭에서 Claude에게 맡기기)

brainstorm-and-plan 스킬은 막연한 아이디어를 질문과 선택지로 정리해 단계별 계획을 세우고, 그 계획을 CLAUDE.md 파일 하나로 폴더에 저장해 이어서 작업하게 해 줍니다. 계획 세우기부터 만들기까지 코드 탭에서 이어지므로 코드 탭에 설치합니다.

실습 순서 (한 번만)
  1. 바탕화면에 새 폴더 스킬실습을 만듭니다. 아래 링크에서 brainstorm-and-plan.skill 파일을 내려받아 이 폴더에 넣습니다. (내려받은 파일은 보통 '다운로드' 폴더에 저장되니 옮겨 주세요.)
    brainstorm-and-plan.skill 바로 내려받기 (안 받아지면 구글 드라이브에서 열기)
  2. Claude Desktop 앱에서 Code를 누르고, 작업 폴더로 방금 만든 스킬실습 폴더를 고릅니다. 바탕화면 전체를 고르지 마세요. 처음 쓰는 컴퓨터는 로그인이나 폴더 권한 확인 창이 뜰 수 있습니다.
  3. 아래 설치 요청 문장을 복사해 붙여넣고 엔터를 칩니다. Claude가 "실행할까요?"라고 물으면 어디에 무엇을 쓰려는지 읽어 보고 예를 누릅니다.
    설치 요청 (코드 탭에 입력)
    이 폴더에 있는 brainstorm-and-plan.skill 파일을 내 사용자 폴더의 .claude\skills 안에 설치해줘. .skill 파일은 zip 압축 파일이고 안에 brainstorm-and-plan 폴더가 이미 들어 있으니, 풀어서 결과가 .claude\skills\brainstorm-and-plan\SKILL.md 경로가 되게 해줘. 폴더가 한 겹 더 생기면 안 돼. 이미 같은 이름의 폴더가 있으면 덮어쓰기 전에 알려줘. 다 끝나면 그 경로에 SKILL.md가 있는지 확인해서 알려줘.
  4. Claude가 SKILL.md가 들어갔는지 확인해서 알려주면 설치가 끝난 것입니다.
  5. Claude 앱을 완전히 종료했다가 다시 실행합니다. 창만 닫으면 안 됩니다. 새 스킬은 앱을 켤 때 읽힙니다.
  6. 코드 탭에서 스킬실습 폴더를 다시 열고, 아래 써 보기 문장을 입력합니다. Claude가 선택지를 주며 질문하기 시작하면 성공입니다.
    써 보기 (앱을 다시 켠 뒤 코드 탭에 입력)
    다음 주 수업에 쓸 퀴즈를 만들고 싶은데 어떻게 시작할지 모르겠어요
알아두세요 — 이 방법은 이 컴퓨터의 코드 탭에 설치하는 것이라 다른 컴퓨터에서는 다시 설치해야 하고, 채팅 화면에서는 이 스킬이 나타나지 않습니다. 승인하기 전에는 아무것도 만들지 않으니, 질문이 시작된 것만 확인하고 멈춰도 됩니다. 이 스킬을 실제로 사용하는 방법은 B-4 · 코드로 시뮬레이터 만들기에서 이어집니다.

② 실습 B · 한글(hwpx) 스킬 등 채팅용 스킬 올리기 (내 계정에 업로드)

채팅에서 쓰는 스킬은 내 계정에 올려서 설치합니다. 한글(hwpx) 스킬 파일 바로 내려받기 (안 받아지면 구글 드라이브에서 열기)

한글(hwpx) 스킬은 어디에 설치하느냐에 따라 쓰임새가 다릅니다. 계정에 올리면 웹·앱의 채팅에서 hwpx 양식 작업을, Claude Code에 설치하면 내 컴퓨터의 hwpx 파일을 직접 여는 작업을 할 수 있습니다. 자세한 비교는 A-1의 '어디에 설치할까요?'를 보세요.
업로드 전에 확인하세요
① 설정의 기능(Capabilities) 메뉴에서 '코드 실행 및 파일 생성'이 켜져 있어야 스킬을 쓸 수 있습니다. Team·Enterprise 계정은 관리자가 조직 설정에서 켜야 합니다.
② 올리는 zip 파일은 열었을 때 스킬 이름의 폴더가 맨 위에 하나 있고, 그 안에 SKILL.md가 있어야 합니다. 폴더 안의 파일만 묶거나 압축을 풀어서 올리면 오류가 납니다.
실습 순서 (스킬마다 한 번만)
  1. 연수에서 나눠 준 스킬 파일을 내려받습니다.
  2. Claude Desktop 앱의 설정에서 Customize(맞춤 설정) → Skills(웹에서 바로 열기)로 이동해 + 버튼 → 스킬 만들기 → 스킬 업로드를 누르고, 내려받은 파일을 풀지 말고 그대로 올립니다.
  3. 올린 스킬 이름 옆의 스위치가 켜짐인지 확인합니다.
  4. 새 채팅에서 /(슬래시)를 입력해 목록에 새 스킬이 보이는지 확인합니다. 이후로는 관련 작업을 요청할 때 Claude가 자동으로 적용합니다.
파일 확장자가 .skill이라 업로드가 안 되면 .zip으로 바꿔 다시 올려 보세요(내부가 zip 형식입니다). 확장자가 보이지 않으면 탐색기의 보기 → 표시 → 파일 확장명을 체크하세요. 그래도 오류 메시지가 나오면 화면을 캡처해 연수 담당자에게 문의하세요. 메뉴 이름과 위치는 앱 버전에 따라 조금 다를 수 있습니다. 목록에 안 보이면 아래 설치 확인 프롬프트(이 장 끝)로 물어볼 수 있습니다.

docx·pptx·xlsx·pdf는 기본으로 켜져 있는 경우가 많아 설치가 필요 없고, 나머지는 선택입니다. 쓰고 싶은 스킬은 위 ③ 방법으로 내 계정에 올립니다.

docx — 워드 문서를 만들고 편집합니다. 지도안, 가정통신문, 공문 기반 계획서, 상담 기록지 등 학교에서 가장 자주 쓰는 문서 형식입니다. (기본 제공되는 경우가 많음)
pptx — 파워포인트 슬라이드를 만들고 편집합니다. 수업 자료, 학부모총회 자료, 발표 자료 제작에 사용합니다. (기본 제공되는 경우가 많음)
xlsx — 엑셀(스프레드시트)을 만들고 편집합니다. 성적·출결 정리, 설문 결과 집계, 통계표 작성에 활용합니다. (기본 제공되는 경우가 많음)
pdf — PDF 문서를 다룹니다. 가정통신문을 PDF로 변환하거나, 여러 시험지를 하나로 합치거나, 스캔한 문서를 검색 가능한 파일로 바꿀 때 사용합니다. (기본 제공되는 경우가 많음)
canvas-design — 포스터나 안내 이미지(PNG·PDF)를 디자인합니다. 행사 포스터, 게시판용 안내 이미지 제작에 활용합니다. (공식 저장소: skills/canvas-design)

문서 업무 자동화 기초

1차 연수에서는 교사가 매일 다루는 세 가지 파일 작업 — 한글 문서, PPT, 그리고 컴퓨터 속 파일 정리 — 을 Claude로 자동화하는 방법을 다룹니다.

A-1한글(HWPX) 파일 만들기·읽기

한글(HWP)은 독자적인 문법 체계를 사용해 외부 프로그램과의 호환성이 낮습니다. Claude가 자동으로 문서를 만들 때는 개방형 포맷인 hwpx를 사용합니다. 기존에 쓰던 hwp 파일이 있다면, 한글 프로그램에서 열어 '다른 이름으로 저장' → hwpx로 한 번 바꿔두면 이후 작업이 편해집니다.

실습 순서 (모두 화면 클릭·입력만으로 진행)
  1. 연수에서 나눠 준 한글(hwpx) 스킬 파일을 내려받습니다.
  2. 내려받은 파일을 풀지 말고 그대로 3장 ② 실습 B의 방법(Customize → Skills → 스킬 업로드)으로 내 계정에 올립니다.
  3. 채팅창에 슬래시(/)를 입력하면 업로드한 스킬 목록이 뜹니다. 원하는 스킬을 선택합니다.
  4. 양식과 함께, 채워 넣을 내용을 채팅으로 알려줍니다.
  5. Claude가 만들어 준 .hwpx 파일을 내려받아 한글 프로그램에서 최종 확인합니다.

한글 MCP로 한글 파일 읽고 요약하기 — 업무 실습

앞에서는 스킬로 한글 문서를 만들었다면, 여기서는 3장에서 설치한 한글 MCP로 학교에서 실제로 받는 한글 문서(공문·계획서·안내문·양식)를 읽고 정리하고 고치는 실습을 합니다. 한글 MCP는 코드 탭에서 사용합니다.

먼저 확인하세요 — 한글 MCP는 3장의 설치 실습에서 설치합니다. 코드 탭에서 "한글 MCP 도구 뭐 있는지 알려줘"라고 입력해 도구 8개가 나오면 준비가 끝난 것입니다.
실습 순서
  1. 연습용 한글 파일을 준비합니다. 공문, 작년 계획서, 안내문처럼 개인정보(학생 이름·연락처·성적)가 없는 것으로 고르고, 원본은 따로 보관한 채 사본을 씁니다.
  2. 사본 파일을 새 폴더(예: 한글실습)에 넣고, 코드 탭에서 그 폴더를 작업 폴더로 엽니다.
  3. 아래 프롬프트에서 [ ] 부분을 내 파일 이름과 내용으로 바꿔 입력합니다. 권한을 묻는 창이 뜨면 무엇을 하려는지 읽어 보고 예를 누릅니다.
  4. 결과의 날짜·금액·마감일·인원 같은 숫자와 고유명사를 원문과 대조합니다.
  5. 새 파일이 만들어졌다면 한글 프로그램에서 직접 열어 확인합니다. Claude는 결과 파일이 한글에서 잘 열리는지 확인할 수 없습니다.

A-2내 스타일대로 PPT 만들기

Claude는 슬라이드 내용의 품질은 우수하지만 기본 디자인은 다소 획일적입니다. 브랜드 디자인 스타일과 폰트를 직접 지정하면 훨씬 완성도 높은 PPT를 만들 수 있습니다.

실습 순서
  1. 참고하고 싶은 디자인 사이트에서 색상 코드와 레이아웃을 확인합니다. 색상 코드는 Windows 캡처 도구의 '색깔 따오기(스포이드)' 기능으로 쉽게 추출할 수 있습니다.
  2. 저작권 안전 폰트를 명시적으로 지정합니다(아래 표 참고).
  3. 먼저 2장만 초안으로 요청해 방향을 확인합니다.
  4. 검수 체크리스트 프롬프트로 전체 슬라이드를 확인한 뒤 완성합니다.

복사해서 바로 써보는 프롬프트

프롬프트 1 · 서식 유지 요청
첨부한 파일의 테마(색상·폰트·마스터·푸터)는 그대로 유지해줘. 단, 슬라이드 레이아웃은 텍스트 틀에 얽매이지 말고 내용 성격에 맞는 도식으로 구성해줘 — 순서/절차는 플로우, 비교는 표나 카드, 수치는 차트, 항목 나열은 아이콘 카드. 한 슬라이드에 주제는 하나씩만 넣어줘. 먼저 첫 2페이지만 샘플로 만들어서 보여줘.
프롬프트 2 · 콘텐츠 원칙 + 검수 체크리스트
슬라이드 1장 = 1개 메시지. 텍스트는 최소화하고, 가능하면 불릿 목록보다 차트·도식(diagram)을 우선 사용. 완성 전 슬라이드별로 다음을 확인 — 텍스트 잘림 여부 / 요소 겹침 여부 / 여백 부족 여부(안전 여백 0.5인치, 요소 간 0.2인치) / 색상·폰트 일관성(지정 팔레트 5색·폰트 3종 외 사용 여부) / 제목 글자 수 18자 이내 / 시각 요소 최소 1개 포함 여부.
프롬프트 3 · 디자인 스타일 따오기
업로드한 디자인 참고 이미지(또는 md 파일)의 색상 코드와 레이아웃 특징을 분석해서, 그 느낌으로 PPT용 디자인 시스템을 만들어줘.
프롬프트 4 · 표·수치를 차트로 변환
지금 슬라이드에 있는 표를 막대그래프로 바꿔줘. 제목·범례는 간결하게, 색상은 지정한 팔레트 안에서만 써줘.
프롬프트 5 · 학부모 대상 보고용 PPT
이번 학기 학급 운영 결과를 학부모총회에서 발표할 PPT로 만들어줘. 학급 목표, 주요 활동 사진 설명, 다음 학기 계획 순서로 4장 구성해줘.

클로드 디자인으로 수업자료 만들기

B-0클로드 디자인이란?

클로드 디자인은 활동지, 포스터, 웹페이지, 프레젠테이션처럼 눈에 보이는 결과물을 만드는 데 특화된 기능입니다. 코워크가 '내 컴퓨터 파일을 정리·관리'하는 데 초점이 있다면, 클로드 디자인은 '새로운 시각 자료를 처음부터 만드는' 데 초점이 있습니다. 한 번 만든 디자인(색상·폰트·레이아웃 규칙)은 '디자인 시스템'으로 저장해 이후 모든 자료에 재사용할 수 있습니다.

B-1활동지 만들기

교과 단원 하나를 정해, 학생 활동지를 클로드 디자인으로 만들어 봅니다. 빈칸 채우기, 서술형 질문, 그림 붙이기 칸 등을 배치할 수 있습니다.

실습 순서
  1. Claude Desktop 앱에서 Design(클로드 디자인) 모드를 선택해 대화를 시작합니다.
  2. 단원명, 학습목표, 활동지에 넣고 싶은 항목(빈칸, 질문, 그림칸 등)을 구체적으로 알려줍니다.
  3. 완성된 결과를 보고 배치나 문항을 수정 요청합니다.
  4. 최종본을 파일로 내려받아 인쇄하거나 학생들에게 배포합니다.

B-2나만의 디자인 시스템 만들기

학교 로고 색상, 자주 쓰는 폰트를 클로드에게 알려주고, 이후 모든 자료에 재사용할 수 있는 디자인 시스템(색상 팔레트, 폰트, 레이아웃 규칙)을 만듭니다. 한 번 만들어두면 활동지·PPT·안내장을 매번 새로 디자인할 필요가 없습니다.

실습 순서
  1. 학교 상징색(교표색)과 로고 파일을 준비합니다.
  2. 제목용 폰트, 본문용 폰트를 저작권 안전 폰트 중에서 하나씩 정합니다.
  3. 아래 프롬프트로 디자인 시스템을 만들어 달라고 요청합니다.
  4. 이후 다른 자료를 만들 때 "저번에 만든 디자인 시스템을 적용해줘"라고 요청하면 같은 스타일이 재사용됩니다.

우리 학교 상징색은 남색(#1F3B57)과 하늘색(#2E6F8E)이야. 제목용 폰트와 본문용 폰트를 각각 하나씩 정해서, 앞으로 내가 만드는 활동지·PPT·안내장에 일관되게 쓸 수 있는 디자인 시스템을 만들어줘.
프롬프트 2 · 로고 반영
첨부한 학교 로고 이미지를 참고해서, 로고와 어울리는 보조 색상 2~3개를 추천하고 디자인 시스템에 추가해줘.
프롬프트 3 · 학급/동아리용 별도 시스템
학교 전체 디자인 시스템과는 별도로, 우리 반 전용 포인트 컬러를 하나 추가한 '우리 반' 디자인 시스템을 만들어줘. 학급 게시물에 쓸 예정이야.
프롬프트 4 · 기존 자료에서 스타일 추출
첨부한 기존 가정통신문 파일의 색상과 폰트를 분석해서, 그 스타일을 그대로 재사용할 수 있는 디자인 시스템으로 정리해줘.
프롬프트 5 · 디자인 시스템 재사용
저번에 만든 우리 학교 디자인 시스템을 그대로 적용해서 이번 자료를 만들어줘.

코드로 시뮬레이터 만들기 — 브레인스토밍 스킬로 계획부터

시뮬레이터는 여러 단계로 나누어 차근차근 만드는 것이 좋아서 코드(Claude Code)를 씁니다. 다만 초보자는 "무엇을 어떻게 만들지" 정하는 데서 막히기 쉽습니다. 그래서 연수에서 제공하는 brainstorm-and-plan 스킬로 먼저 계획을 세우고, 그 계획을 CLAUDE.md 파일 하나에 담아 같은 폴더에서 이어서 만듭니다. 계획 세우기부터 만들기까지 모두 코드 탭의 같은 폴더에서 진행하며, 화면 클릭과 입력만으로 쓰고 터미널은 사용하지 않습니다.

① 코드 탭에서 계획 세우기

brainstorm-and-plan 스킬
  • 목표·대상·조건·완료 기준을 질문과 선택지로 정리
  • 만드는 방법 2~3개를 비교하고 추천안 제시
  • 단계별 계획과 단계마다의 완료 확인 방법 작성
  • 승인하면 작업 폴더에 CLAUDE.md 파일 하나로 저장

② 같은 폴더에서 한 단계씩 만들기

저장된 CLAUDE.md를 따라서
  • 폴더를 열면 CLAUDE.md를 자동으로 읽음
  • "1단계부터 시작해 줘"로 시작
  • 한 단계가 끝날 때마다 멈추고 결과를 보고
  • 내가 확인하고 "다음 단계 진행해"라고 말하면 이어감
먼저 확인하세요 — brainstorm-and-plan 스킬은 3장 ② 실습 A에서 코드 탭에 설치합니다. 아직 설치하지 않았다면 3장에서 먼저 설치하고 앱을 다시 켠 뒤 아래 단계를 시작하세요. 채팅 화면에서는 이 스킬이 나타나지 않으니 코드 탭에서 진행합니다.

1단계 · 코드 탭에서 계획 세우기

실습 순서
  1. 컴퓨터에 새 빈 폴더를 만듭니다(예: 진자시뮬레이터). 바탕화면이나 다운로드 같은 기존 폴더는 쓰지 않습니다. 참고할 자료(교과서 쪽 사진, 단어 목록, 기존 학습지 등)가 있다면 이 폴더에 함께 넣어 둡니다.
  2. Claude Desktop 앱의 Code에서 그 폴더를 작업 폴더로 선택합니다. 권한은 매번 확인을 묻는 방식(Manual)으로 두고 시작하세요.
  3. 아래 프롬프트처럼 만들어 보고 싶은 것을 말합니다. 스킬 이름을 부르지 않아도 "만들어 보고 싶어", "계획 세워 줘" 같은 말에 스킬이 자동으로 적용됩니다.
    계획 시작 · 코드 탭
    중학교 과학 수업용으로 진자 운동 시뮬레이터를 만들어 보고 싶어. 어떻게 시작할지 모르겠으니 같이 계획을 세워 줘.
  4. Claude가 질문을 한 번에 하나씩, 선택지와 함께 물어봅니다. 번호로 고르면 되고, 잘 모르면 "모르겠어요"라고 하면 기본값을 제안해 줍니다. 참고 자료가 있느냐고 물으면 폴더에 넣어 둔 파일 이름을 알려줍니다.
  5. 정리된 요약을 보고 "맞아요" 또는 고칠 점을 말합니다.
  6. 추천안과 함께 나온 단계별 계획을 읽고 고칠 점을 말한 뒤, 마음에 들면 "좋아요, 진행해"라고 승인합니다. 승인하기 전에는 결과물을 만들지 않습니다.
  7. Claude가 CLAUDE.md를 그 폴더에 바로 저장합니다. 화면에 파일 내용이 길게 보일 수 있지만 복사할 필요는 없습니다. 폴더에 CLAUDE.md 파일이 생겼는지 확인하세요.

2단계 · 같은 폴더에서 한 단계씩 만들기

실습 순서
  1. 계획이 저장된 같은 폴더에서 아래 첫 시작 프롬프트를 입력합니다.
    코드 탭 · 첫 시작
    1단계부터 시작해 줘
  2. 한 단계가 끝나면 Claude가 한 일을 요약하고 완료 확인 결과를 알려줍니다. 결과 파일(html)을 더블클릭해 브라우저로 열어 직접 확인한 뒤, 괜찮으면 다음 단계 프롬프트를 입력합니다.
    코드 탭 · 다음 단계로
    다음 단계 진행해
  3. 다음 날 이어서 할 때는 같은 폴더를 다시 열고 "이어서 해 줘"라고 입력합니다. 폴더의 CLAUDE.md가 자동으로 읽힙니다.
    코드 탭 · 다음 날 이어서 하기 (폴더를 열고 입력)
    이어서 해 줘
  4. 계획을 바꾸고 싶을 때는 아래 계획 바꾸기 프롬프트를 입력하고, 바꿀 내용을 말합니다.
    코드 탭 · 계획 바꾸기
    계획 수정하자

CLAUDE.md에는 무엇이 들어 있나요?

항목내용
작업 규칙 (맨 위)한 번에 한 단계만 진행하고, 끝나면 요약·확인 결과를 보고한 뒤 멈춘다. 계획에 없는 일은 먼저 제안하고 승인받는다.
목표 · 대상과 조건완성되면 무엇이 손에 남는지, 누가 쓰는지, 기한과 환경, 꼭 지킬 것
참고 자료받은 자료의 파일 이름, 검토해서 알아낸 내용, 쓰는 단계
정한 방향 · 하지 않을 것고른 방법과 이유, 이번 범위에서 뺀 것

전체 완료 기준 · 진행 기록성공 여부를 판단할 기준, 단계를 마칠 때마다 남기는 한 줄 기록
⚠️ 이 실습에서 꼭 지킬 것
① 새 빈 폴더에서만 작업하세요. 코드는 열어 둔 폴더의 파일을 실제로 만들고 바꿉니다.
② 개인정보: 학생 이름·연락처·성적이 들어 있는 자료는 그대로 넣지 말고, 지운 사본을 사용하세요. 스킬은 CLAUDE.md에 개인정보를 옮겨 적지 않고 "몇 쪽 표에 있음"처럼 위치만 적지만, 원본 파일을 폴더에 넣으면 소용이 없습니다.
③ 내용 확인: 공식·단위·수치가 들어가는 교과 자료는 계획에 확인 단계가 들어가지만, 최종 검토는 선생님이 교과서와 대조해 주세요.
④ 스킬 추천: 계획에 "사용할 스킬"이 나오면 Anthropic 공식 출처의 것만 추천되고, 설치 여부는 내가 결정합니다. 필수가 아니므로 설치하지 않아도 진행할 수 있습니다.

수업·평가 설계 — 단원 수업안, 수행평가 계획처럼 여러 단계로 나뉘는 설계를 질문을 따라가며 정리할 수 있습니다.
문서·보고서 작성 — 가정통신문, 계획서, 보고서를 쓰기 전에 목적·대상·구성을 먼저 정리할 수 있습니다.

간단 버전 · 바이브 코딩으로 채팅에서 바로 시뮬레이터 만들기

바이브 코딩은 코드를 직접 작성하지 않고, 원하는 동작을 대화하듯 설명하면 Claude가 코드를 대신 작성해주는 방식입니다. 교과 수업에서 학생이 값을 직접 바꿔보며 결과를 확인할 수 있는 시뮬레이터를 이 방식으로 만들 수 있습니다. 초보자용으로, 결과물은 항상 html 파일 1개로만 요청합니다. 별도 프로그램 설치나 서버 실행 없이, 받은 파일을 더블클릭하기만 하면 바로 웹 브라우저에서 열립니다.

실습 순서 (모두 화면 클릭·입력만으로 진행, 터미널 사용 안 함)
  1. 학생이 값을 직접 조작하며 이해하면 좋을 개념을 정합니다(수치를 바꾸면 결과가 달라지는 내용).
  2. 어떤 값을 슬라이더나 입력창으로 조절하고 싶은지, 화면에 무엇이 보여야 하는지 구체적으로 설명합니다.
  3. "결과는 설치 없이 바로 열리는 html 파일 하나로만 줘"라고 명확히 요청합니다.
  4. 받은 html 파일을 더블클릭해 브라우저로 열어 직접 조작해보고, 수정이 필요한 부분을 요청합니다.
앞의 코드로 시뮬레이터 만들기(스킬로 계획 → 코드로 제작)가 기본 방법입니다. 아래는 간단한 시뮬레이터를 계획 없이 채팅에서 곧바로 만들어 보는 방법입니다.
왜 html 파일 하나로 요청해야 하나요? 설치 프로그램이나 서버, 터미널 명령 없이 더블클릭만으로 실행되고, 학생들에게 배포할 때도 파일 하나만 전달하면 되기 때문입니다. Claude가 여러 파일로 나누어 만들었다면 "파일 하나로 합쳐줘"라고 요청하세요.

복사해서 바로 써보는 프롬프트

프롬프트 1 · 과학 - 진자 운동 시뮬레이터
중학교 과학 수업용으로, 진자의 추 길이를 슬라이더로 조절하면 흔들리는 주기가 실시간으로 바뀌는 시뮬레이터를 만들어줘. 설치 없이 더블클릭으로 바로 열리는 html 파일 하나로만 줘.
프롬프트 2 · 수학 - 일차함수 그래프 시뮬레이터
중학교 수학 수업용으로, 기울기와 y절편 값을 슬라이더로 조절하면 그래프가 실시간으로 움직이는 일차함수 시뮬레이터를 만들어줘. html 파일 하나로만 줘.
프롬프트 3 · 과학 - 화학 반응속도 시뮬레이터
온도와 농도 값을 조절하면 반응 속도가 어떻게 달라지는지 애니메이션으로 보여주는 시뮬레이터를 만들어줘. 값을 바꿀 수 있는 입력창을 넣고, html 파일 하나로만 줘.
프롬프트 4 · 수학 - 도형 넓이·부피 시뮬레이터
원기둥의 밑면 반지름과 높이를 슬라이더로 조절하면, 겉넓이와 부피가 실시간으로 계산되고 도형 모양도 함께 바뀌는 시뮬레이터를 만들어줘. html 파일 하나로만 줘.
프롬프트 5 · 사회 - 인구 변화 시뮬레이터
출생률과 사망률 값을 조절하면 시간에 따라 인구 그래프가 어떻게 변하는지 보여주는 시뮬레이터를 만들어줘. 연도를 재생 버튼으로 넘길 수 있게 하고, html 파일 하나로만 줘.

활용 분야

실험 대체·보완 자료 — 실제로 하기 어렵거나 위험한 실험을 화면 안에서 안전하게 대신 체험할 수 있습니다.
수학 개념 시각화 도구 — 함수, 도형처럼 수치가 바뀌면 결과가 달라지는 개념을 직접 조작하며 이해할 수 있습니다.

B-5애니메이션 자료 만들기

개념을 움직임으로 보여주면 이해가 쉬운 주제를 짧은 애니메이션으로 만들어 봅니다.

실습 순서
  1. 움직임으로 설명하면 좋을 개념을 정합니다(과정, 순환, 변화 등).
  2. 디자인 시스템을 적용해 애니메이션을 요청합니다.
  3. 재생해보고 속도나 순서를 조정 요청합니다.

복사해서 바로 써보는 프롬프트

프롬프트 1 · 물의 순환
물의 순환 과정(증발-응결-강수-흐름)을 보여주는 간단한 애니메이션을 만들어줘. 화살표와 아이콘으로 순환 흐름이 한눈에 보이게 해줘.
프롬프트 2 · 광합성 과정
식물의 광합성 과정을 보여주는 애니메이션을 만들어줘. 햇빛, 이산화탄소, 물이 들어가서 산소와 포도당이 나오는 흐름을 화살표로 표현해줘.
프롬프트 3 · 지진 발생 원리

G자주 묻는 질문(FAQ)

Q1. 한글 프로그램이 꼭 설치되어 있어야 하나요?

hwpx 파일을 만들고 확인하려면 한글 프로그램이 있는 것이 좋습니다. 다만 만드는 과정 자체는 Claude Desktop 앱의 채팅창에서 이루어지므로, 최종 확인 단계에서만 한글 프로그램이 필요합니다. 3장의 한글 MCP로 파일을 읽는 경우에는 한글 프로그램 없이도 내용을 읽을 수 있습니다.

Q2. 무료 계정으로도 이 매뉴얼의 실습을 할 수 있나요?

스킬 업로드, 코워크(Cowork), 클로드 디자인 등 일부 기능은 유료 계정에서 원활하게 사용할 수 있습니다. 학교에서 안내받은 연수용 계정으로 진행하시는 것을 권장합니다.

Q3. 만든 스킬이나 디자인 시스템을 다른 선생님과 나눌 수 있나요?

네. 스킬은 '다운로드' 버튼으로 파일을 받아 전달할 수 있고, 디자인 시스템도 대화나 파일로 공유해 다른 선생님이 그대로 적용할 수 있습니다.

Q4. 결과물이 마음에 안 들면 처음부터 다시 요청해야 하나요?

아니요. "이 부분만 이렇게 바꿔줘"처럼 구체적으로 수정을 요청하면 됩니다. 대화가 너무 길어졌다면 새 채팅에서 이전 결과물을 첨부해 이어가는 것이 더 효율적입니다.

Q5. 학생 개인정보가 들어간 자료도 만들어도 되나요?

이름 등 최소한의 정보는 상황에 따라 가능하지만, 주민등록번호 등 민감한 개인정보는 입력하지 않는 것이 원칙입니다. 걱정되는 경우 가명이나 익명으로 처리한 뒤 작업하세요.

Q6. 코워크와 클로드 디자인 중 무엇을 먼저 배워야 하나요?

순서는 무관합니다. 다만 이 매뉴얼처럼 문서 자동화(1차)를 먼저 익히고, 시각 자료 제작(2차)으로 넘어가면 실습 난이도가 자연스럽게 올라갑니다.

Q7. 만든 웹사이트나 애니메이션을 학생들에게 어떻게 보여주나요?

완성된 결과물은 파일로 내려받거나 링크 형태로 공유할 수 있습니다. 교실 화면에 띄우거나, 학급 단체방에 링크를 공유하는 방식으로 활용하시면 됩니다.

Q8. 프롬프트를 꼭 이 매뉴얼 그대로 써야 하나요?

아닙니다. 예시 프롬프트는 출발점입니다. 대괄호 [ ] 안의 내용이나 과목·학년·주제를 자유롭게 바꿔서 사용하세요.

Q9. Claude Desktop 앱 대신 웹(claude.ai)으로 해도 되나요?

같은 계정이므로 채팅, 스킬, 클로드 디자인 실습은 웹에서도 이어갈 수 있고 대화 내용도 함께 보입니다. 다만 컴퓨터 폴더에 접근하는 코워크(A-3)는 앱에서만 사용할 수 있으므로, 연수는 앱 기준으로 안내합니다.

Q10. 학교 컴퓨터에 앱이 설치되지 않아요.

보안 프로그램이나 관리자 권한 때문에 설치가 막히는 경우입니다. 정보부서(담당 선생님)에 설치를 요청하거나, 임시로 웹(claude.ai)에서 같은 계정으로 실습을 진행하세요. 관리자 권한이 없으면 코워크 같은 일부 기능은 제한될 수 있습니다.

검수 체크리스트
슬라이드 1장 = 1개 메시지. 텍스트는 최소화하고 차트·도식을 우선 사용. 완성 전 텍스트 잘림, 요소 겹침, 여백, 색상·폰트 일관성, 제목 글자 수, 시각 요소 포함 여부를 확인해줘.
