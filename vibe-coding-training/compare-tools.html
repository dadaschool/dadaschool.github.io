클로드 코드 vs 코덱스, 뭐가 다를까?

읽는 데 약 10분  |  설치는 별도 문서(설치 따라하기)를 참고하세요

이 문서는 클로드 코드(Claude Code)와 코덱스(Codex), 두 AI 코딩 도구가 무엇이 다른지 감을 잡기 위한 자료입니다.
둘 다 "AI에게 말로 시키면 파일을 직접 만들고 고쳐준다"는 점은 같고, 일하는 방식도 생각보다 비슷합니다. 실제로 갈리는 것은 계정·요금 구조와 화면 구성입니다.
둘 다 설치할 필요는 없습니다. 이미 쓰고 있는 계정이 있는 쪽 하나면 연수 실습에 충분합니다. 이 문서를 먼저 읽고 클로드 코드 설치 따라하기 또는 코덱스 설치 따라하기 문서로 넘어가시면 됩니다.

1 한눈에 보는 비교표

비교 항목클로드 코드코덱스
만든 곳 Anthropic OpenAI
로그인 계정 Claude 계정 (Pro 이상 유료 플랜) ChatGPT 계정 (요금제별 사용량 차등)
일하는 방식 앱·터미널에서는 내 컴퓨터의 파일·git·터미널을 직접 조작. 웹에서는 클라우드 작업도 가능 앱·터미널에서는 내 컴퓨터의 파일을 직접 조작. 웹에서는 클라우드에서 작업한 뒤 결과를 검토·반영
승인 방식 파일을 바꾸거나 명령을 실행하기 전에 승인 요청 (모드로 조절) 어디까지 묻지 않고 해도 되는지 권한 설정에서 선택
사용 창구 터미널(CLI), 데스크톱 앱, IDE 플러그인, 웹 터미널(CLI), 데스크톱·모바일 앱, IDE 확장, 웹
확장 기능 플러그인 마켓플레이스, MCP 서버, 세분화된 훅(Hook) 플러그인, MCP 서버 연결 등
⚠️ 가격·버전 수치는 이 표에 넣지 않았습니다.
두 회사 모두 요금제와 사용 한도를 자주 조정하기 때문에, 정확한 숫자는 claude.com/pricing과 chatgpt.com/pricing에서 연수 직전에 다시 확인해 주세요.

2 도구보다 중요한 것: AI가 "어디서" 일하는가

두 도구 모두 일하는 자리가 두 곳입니다. 어느 도구를 쓰느냐보다, 지금 AI가 어느 자리에서 일하고 있는지를 아는 것이 더 중요합니다.

내 컴퓨터에서 일할 때
  1. 앱이나 터미널에서 폴더 하나를 골라 엽니다
  2. AI가 그 폴더의 파일을 바로 읽고 고칩니다
  3. 파일을 바꾸거나 명령을 실행하기 전에 승인을 묻습니다
클라우드에 맡길 때
  1. 웹에서 GitHub 저장소를 연결하고 요청을 보냅니다
  2. AI가 회사 쪽 컴퓨터에서 작업합니다
  3. 끝나면 변경 내용을 검토하고 반영 여부를 정합니다

3 고를 때 실제로 따져 볼 것

따져 볼 것클로드 코드코덱스
이미 갖고 있는 계정 Claude 유료 플랜이 있으면 바로 사용 ChatGPT 계정이 있으면 바로 사용 (요금제별 사용량 차등)
터미널 없이 쓸 수 있나요? 데스크톱 앱의 Code 탭에서 가능 ChatGPT 데스크톱 앱의 Codex 모드에서 가능
실수하면 되돌릴 수 있나요? 둘 다 승인 단계에서 막을 수 있고, git으로 저장해 둔 지점까지는 언제든 되돌릴 수 있습니다. 되돌릴 수 있느냐는 도구가 아니라 저장 습관이 정합니다.

자주 묻는 질문

질문답변
둘 다 무료로 쓸 수 있나요? 클로드 코드는 무료 플랜으로는 사용할 수 없고 Pro 이상이 필요합니다. 코덱스는 요금제에 따라 사용량이 달라지니, 실습 전 chatgpt.com/pricing에서 확인하세요.
둘 다 설치해야 하나요? 아니요. 하나면 충분합니다. 두 도구의 차이가 궁금하면 나중에 같은 요청을 각각 시켜 보세요.
제 컴퓨터 파일이 AI에게 그대로 넘어가나요? 연 폴더 안에서, 작업에 필요한 파일의 내용이 그 회사 서버로 전송됩니다. 학생 자료나 개인정보가 든 폴더에서는 열지 마세요. 실습은 새로 만든 빈 폴더에서 합니다.
더 헷갈리면 어떻게 하나요? 연수 담당 채팅방에 질문을 남겨주시면 됩니다.
