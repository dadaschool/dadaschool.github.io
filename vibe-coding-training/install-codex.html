코덱스(Codex) 설치 따라하기

윈도우 · macOS 공통  |  소요 시간 약 15분

코덱스(Codex)는 오픈AI가 만든 AI 코딩 도구로, ChatGPT 계정으로 로그인해서 파일을 직접 만들고 고쳐줍니다.
설치 방법은 두 가지입니다. 어느 쪽으로 설치하든 결과는 같으니, 편한 쪽 하나만 골라 따라 하시면 됩니다.
🖱️ 방법 A · 앱 다운로드 추천

설치 파일을 받아 더블클릭. 터미널을 전혀 쓰지 않습니다.
⌨️ 방법 B · 터미널(CLI)

명령어 한 줄을 붙여넣어 설치. 터미널에 익숙한 분께 맞습니다.
⚠️ 설치는 연수 전에, 집이나 개인 인터넷에서 미리 해 오세요.
학교망에서는 설치 명령이 인증서 오류로 멈추는 경우가 있습니다. 문서 아래 학교망에서 막힐 때를 참고하세요.

시작하기 전에

  • 운영체제: Windows 또는 macOS (둘 다 지원)
  • ChatGPT 계정이 필요합니다. 참고 요금제에 따라 코덱스를 쓸 수 있는지와 사용량이 달라집니다. 내 요금제에서 되는지는 실습 전 chatgpt.com/pricing에서 확인해 주세요. (방법 A·B 모두 동일하게 필요합니다)
  • 윈도우라면 Git for Windows도 함께 설치해 두세요. 뒤의 GitHub에 올리기 실습에 꼭 필요합니다.

A 앱 다운로드로 설치하기

1. 설치 파일 받기

브라우저에서 chatgpt.com/download로 이동해서, 내 컴퓨터 운영체제(윈도우 또는 macOS)에 맞는 다운로드 버튼을 눌러주세요.
이 앱은 ChatGPT 데스크톱 앱이며, 그 안에 코덱스 기능이 포함되어 있습니다.

2. 설치 및 로그인

다운로드된 파일을 더블클릭해서 설치를 진행하세요. (macOS는 앱을 Applications 폴더로 드래그하면 설치가 끝납니다)
설치가 끝나면 앱을 실행하고, 평소 쓰던 ChatGPT 계정으로 로그인하세요.

3. 작업할 폴더 열기

처음 화면(Choose where to work)에서 "open a folder"를 선택해, 실습에 쓸 폴더(예: 바탕화면에 새로 만든 빈 폴더)를 선택합니다.
앱 위쪽의 모드 전환에서 Chat이 아니라 Codex를 선택해야 폴더 안의 파일을 실제로 만들고 고칩니다. (Chat은 대화, Work는 여러 앱에 걸친 업무용, Codex가 코딩용입니다)
⚠️ Codex 모드나 폴더 선택 옵션이 안 보인다면
앱이 예전 판이거나 요금제에서 지원하지 않는 경우입니다. 앱을 최신으로 업데이트하고, 내 요금제에서 코덱스를 쓸 수 있는지 확인하세요.
앱 화면 구성은 자주 바뀝니다. 메뉴 이름이 이 문서와 다르면 코딩용 모드를 찾으시면 됩니다.

4. 첫 실행 확인

대화창에 아래 문장을 그대로 붙여넣고 보내보세요.

첫 시도
지금 폴더에 hello.txt 파일을 만들고 "안녕하세요"라고 써줘
작업을 진행해도 될지 물어보면 승인(Approve)을 눌러주세요.
선택한 폴더 안에 hello.txt 파일이 생겼다면 성공입니다.

B 터미널(CLI)로 설치하기

1. 터미널 열기

🪟 윈도우

키보드에서 Windows 키를 누른 뒤 "PowerShell"이라고 입력하고, 나오는 Windows PowerShell을 클릭해서 여세요.
관리자 권한으로 실행할 필요는 없습니다.

🍎 macOS

Command(⌘) + Space를 눌러 스포트라이트를 연 다음, "터미널"이라고 입력하고 엔터를 누르세요.

2. 설치 명령어 붙여넣기

내 컴퓨터에 맞는 명령어의 복사 버튼을 누른 다음, 방금 연 터미널에 붙여넣고 엔터를 치세요.

🪟 윈도우

설치 명령 · Windows
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

🍎 macOS

설치 명령 · macOS
curl -fsSL https://chatgpt.com/codex/install.sh | sh
⚠️ 설치는 30초~1분 정도 걸립니다.
화면에 글자가 올라가는 동안 기다려 주세요. 중간에 창을 닫지 마세요.
윈도우에서 보안 경고(Windows Defender SmartScreen 등)가 뜨면, "추가 정보" → "실행" 순서로 눌러 진행하시면 됩니다. 공식 주소(chatgpt.com)에서 받는 정상적인 설치 파일입니다.

3. 설치 확인

같은 터미널에 아래 명령을 붙여넣어 보세요.

버전 확인
codex --version

버전 번호가 표시되면 설치 성공입니다.

4. 로그인하기

실행
codex
실행하면 코덱스가 켜지면서 웹 브라우저 창이 자동으로 열립니다.
"Sign in with ChatGPT"를 선택하고, 평소 쓰던 ChatGPT 계정으로 로그인한 뒤 연결 허용을 눌러주세요.
로그인이 끝나면 터미널로 돌아와 코덱스 화면이 뜨는지 확인하세요.
⚠️ 브라우저가 저절로 안 열릴 때도 있습니다.
이럴 때는 터미널에 함께 표시되는 주소(URL)를 직접 복사해서 브라우저 주소창에 붙여넣고 이동하면 됩니다.

5. 잘 깔렸는지 실제로 써보기

로그인이 끝나면 코덱스 입력창에 아래 문장을 그대로 붙여넣고 엔터를 쳐보세요.

첫 시도
지금 폴더에 hello.txt 파일을 만들고 "안녕하세요"라고 써줘
작업을 진행해도 될지 물어보는 화면이 뜨면 승인(Approve)을 선택해 주세요.
코덱스도 클로드 코드와 마찬가지로, 내 컴퓨터의 파일을 실제로 바꾸기 전에 먼저 확인을 받도록 되어 있습니다.

실행 후 폴더 안에 hello.txt 파일이 새로 생겼다면 설치와 실행 모두 정상입니다.

잘 안 될 때

이런 증상이면이렇게 해보세요
(방법 A) Codex 모드/폴더 선택이 안 보임 앱을 최신으로 업데이트하고, 내 요금제에서 코덱스를 쓸 수 있는지 확인하세요.
(방법 A) 다운로드 페이지에 내 운영체제가 안 보임 페이지를 새로고침하거나 다른 브라우저로 다시 접속해 보세요.
(방법 B) PowerShell에서 스크립트를 실행할 수 없습니다 명령어 맨 앞의 powershell -ExecutionPolicy ByPass -c 부분이 빠지지 않았는지 확인하고, 복사 버튼으로 통째로 다시 붙여넣어 보세요.
(방법 B) macOS에서 command not found: codex 터미널 창을 완전히 닫았다가 새로 열고 설치 확인 명령을 다시 실행해 보세요.
사용량이 금방 초과됐다는 안내가 뜸 ChatGPT 요금제에 따른 정상적인 한도입니다. chatgpt.com/pricing에서 현재 요금제의 한도를 확인하세요.
그래도 안 될 때 화면을 캡처해서 연수 담당 채팅방에 올려주세요.

학교망에서 막힐 때

⚠️ self-signed certificate, SSL, 인증서라는 말이 보이면 내 실수가 아닙니다.
학교·교육청 망의 보안 장비가 암호화된 연결을 중간에서 열어 보기 때문에 생기는 일입니다. 브라우저는 멀쩡한데 터미널 명령만 막히는 것이 특징입니다.
  • 가장 빠른 길: 휴대전화 테더링처럼 다른 인터넷으로 바꿔 설치만 끝냅니다. 설치가 끝나면 학교망으로 돌아와도 됩니다.
  • 방법 A(앱 다운로드)는 브라우저로 받기 때문에 이 문제를 덜 겪습니다.
  • 학교망에서 계속 써야 한다면 전산 담당 선생님께 학교 보안 인증서 설정을 문의하세요.
명령어는 항상 복사 버튼으로 통째로 붙여넣어 주세요. 따옴표나 기호 하나가 빠지면 설치가 되지 않습니다.
