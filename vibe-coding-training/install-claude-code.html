클로드 코드 설치 따라하기

윈도우 · macOS 공통  |  소요 시간 약 15분

클로드 코드(Claude Code)는 AI에게 내 컴퓨터의 파일을 직접 만들고 고치게 시킬 수 있는 도구입니다.
설치 방법은 두 가지입니다. 어느 쪽으로 설치하든 결과는 같으니, 편한 쪽 하나만 골라 따라 하시면 됩니다.
🖱️ 방법 A · 앱 다운로드 추천

설치 파일을 받아 더블클릭. 터미널을 전혀 쓰지 않습니다.
⌨️ 방법 B · 터미널(CLI)

명령어 한 줄을 붙여넣어 설치. 터미널에 익숙한 분께 맞습니다.
⚠️ 설치는 연수 전에, 집이나 개인 인터넷에서 미리 해 오세요.
학교망에서는 설치 명령이 인증서 오류로 멈추는 경우가 있습니다. 문서 아래 학교망에서 막힐 때를 참고하세요.

시작하기 전에

  • 운영체제: Windows 10(2019년 이후 업데이트) 이상, 또는 macOS 13 이상
  • Claude 계정: Pro, Max, Team, Enterprise 중 하나. 주의 claude.ai 무료 계정으로는 클로드 코드를 쓸 수 없습니다. 계정이 없다면 claude.ai에서 먼저 유료 플랜에 가입해 주세요. (방법 A·B 모두 동일하게 필요합니다)

A 앱 다운로드로 설치하기

1. 설치 파일 받기

아래 링크에서 내 컴퓨터에 맞는 설치 파일을 받으세요.
🪟 윈도우: Windows용 다운로드
🍎 macOS: macOS용 다운로드

2. 설치 및 로그인

다운로드된 파일을 더블클릭해서 설치를 진행하세요.
설치가 끝나면 (윈도우) 시작 메뉴 또는 (맥) Applications 폴더에서 Claude 앱을 실행하고, Anthropic(Claude) 계정으로 로그인하세요.

3. Code 탭 열고 폴더 선택

앱 위쪽 가운데의 Code 탭을 클릭하세요.
Local을 선택한 뒤, Select folder를 눌러 실습에 쓸 폴더(예: 바탕화면에 새로 만든 빈 폴더)를 선택합니다.
⚠️ Code 탭을 눌렀는데 업그레이드 안내가 뜬다면
Claude 계정이 무료 플랜이라는 뜻입니다. Pro 이상 유료 플랜 가입이 필요합니다.

4. 첫 실행 확인

화면 아래 입력창에 아래 문장을 그대로 붙여넣고 보내보세요.

첫 시도
지금 폴더에 hello.txt 파일을 만들고 "안녕하세요"라고 써줘
변경 사항을 적용해도 될지 물어보면(Manual 모드인 경우) Accept(승인)를 눌러주세요.
선택한 폴더 안에 hello.txt 파일이 생겼다면 성공입니다.

B 터미널(CLI)로 설치하기

1. 터미널 열기

🪟 윈도우

키보드에서 Windows 키를 누른 뒤 "PowerShell"이라고 입력하고, 나오는 Windows PowerShell을 클릭해서 여세요.
관리자 권한으로 실행할 필요는 없습니다. 일반 실행이면 충분합니다.

🍎 macOS

Command(⌘) + Space를 눌러 스포트라이트를 연 다음, "터미널"이라고 입력하고 엔터를 누르세요.
창 맨 앞부분이 PS C:\...로 시작하면 PowerShell, C:\...이면 CMD입니다. 이 문서의 윈도우 명령은 PowerShell 기준이니, CMD 창이 열렸다면 PowerShell을 다시 열어주세요.

2. 설치 명령어 붙여넣기

내 컴퓨터에 맞는 명령어의 복사 버튼을 누른 다음, 방금 연 터미널에 붙여넣고 엔터를 치세요.

🪟 윈도우 (PowerShell)

설치 명령 · Windows
irm https://claude.ai/install.ps1 | iex

🍎 macOS

설치 명령 · macOS
curl -fsSL https://claude.ai/install.sh | bash
⚠️ 설치는 30초~1분 정도 걸립니다.
화면에 글자가 주르륵 올라가는 동안 기다려 주세요. 중간에 창을 닫지 마세요.
윈도우에서 "게시자를 확인할 수 없는 스크립트를 실행하시겠습니까"류의 보안 문구가 뜨면, 공식 설치 주소(claude.ai)에서 받는 것이 맞으니 계속 진행을 선택하시면 됩니다.
윈도우에서는 Git for Windows를 함께 설치해 두세요. 클로드 코드 자체는 없어도 켜지지만, 뒤의 GitHub에 올리기 실습에는 git이 꼭 필요합니다. (방법 A로 설치한 분도 마찬가지입니다)

3. 설치 확인

같은 터미널에 아래 명령을 붙여넣어 보세요.

버전 확인
claude --version

2.1.211 (Claude Code)처럼 버전 번호가 나오면 설치 성공입니다.

4. 로그인하기

실행
claude
명령을 실행하면 클로드 코드가 켜지면서 웹 브라우저 창이 자동으로 열립니다.
브라우저에서 Claude 계정으로 로그인하고, 권한 허용(Authorize) 버튼을 눌러주세요.
로그인이 끝나면 터미널로 돌아와 안내를 따라 진행하시면 됩니다.
⚠️ 브라우저가 저절로 안 열릴 때도 있습니다.
이럴 때는 터미널에 함께 표시되는 주소(URL)를 직접 복사해서 브라우저 주소창에 붙여넣고 이동하면 됩니다.

5. 잘 깔렸는지 실제로 써보기

로그인이 끝나면 터미널 맨 아래 입력창에 아래 문장을 그대로 붙여넣고 엔터를 쳐보세요.

첫 시도
지금 폴더에 hello.txt 파일을 만들고 "안녕하세요"라고 써줘
"이 작업을 진행할까요?" 같은 확인 창이 뜨면 "예(Yes)"를 선택해 주세요.
클로드 코드는 내 컴퓨터의 파일을 실제로 바꾸기 전에 항상 먼저 물어보게 되어 있습니다.

실행 후 폴더 안에 hello.txt 파일이 새로 생겼다면 설치와 실행 모두 정상입니다.

잘 안 될 때

이런 증상이면이렇게 해보세요
(방법 A) Code 탭에서 업그레이드 안내 Claude 계정이 무료 플랜입니다. Pro 이상 유료 플랜으로 로그인했는지 확인하세요.
(방법 A) 로그인 후 403 오류 앱을 완전히 종료했다가 다시 켠 뒤 재로그인해 보세요.
(방법 B) PowerShell에서 스크립트를 실행할 수 없습니다 PowerShell을 관리자 권한 없이 새로 열고 설치 명령을 다시 붙여넣어 보세요.
(방법 B) macOS에서 command not found: claude 터미널 창을 완전히 닫았다가 새로 열고 설치 확인 명령을 다시 실행해 보세요.
로그인 화면에서 "사용 권한이 없습니다" Claude 계정이 무료 플랜인 경우입니다. Pro 이상 유료 플랜으로 로그인했는지 확인하세요.
그래도 안 될 때 화면을 캡처해서 연수 담당 채팅방에 올려주세요.

학교망에서 막힐 때

⚠️ self-signed certificate, SSL, 인증서라는 말이 보이면 내 실수가 아닙니다.
학교·교육청 망의 보안 장비가 암호화된 연결을 중간에서 열어 보기 때문에 생기는 일입니다. 브라우저는 멀쩡한데 터미널 명령만 막히는 것이 특징입니다.
  • 가장 빠른 길: 휴대전화 테더링처럼 다른 인터넷으로 바꿔 설치만 끝냅니다. 설치가 끝나면 학교망으로 돌아와도 됩니다.
  • 방법 A(앱 다운로드)는 브라우저로 받기 때문에 이 문제를 덜 겪습니다.
  • 학교망에서 계속 써야 한다면 전산 담당 선생님께 학교 보안 인증서 설정을 문의하세요.
명령어는 항상 복사 버튼으로 통째로 붙여넣어 주세요. 띄어쓰기나 기호 하나가 빠지면 설치가 되지 않습니다.
